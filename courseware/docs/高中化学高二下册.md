# 高中化学高二下册课程讲义
课程编号：senior_chemistry_g11s2　适用学段：高中　年级：高二　学期：下学期

本册讲义对应人教版高中化学选择性必修3《有机化学基础》。有机化学的核心是"官能团决定化学性质"，本册从有机物分类与命名、同分异构入手，系统学习烷、烯、炔、芳香烃及卤代烃、醇、酚、醛、羧酸、酯等衍生物的性质，最终落脚于官能团转化、有机合成路线设计与有机推断，为高考有机综合题打下坚实基础。

## 第一章 有机化学基础

> 本章核心：有机物的分类与系统命名法、同分异构体的书写、各类有机反应类型的辨析。

### 1.1 有机物的分类与命名

有机物按碳骨架分为链状化合物（脂肪烃）与环状化合物（脂环烃、芳香烃）；按官能团分为烷烃、烯烃、炔烃、芳香烃、卤代烃、醇、酚、醛、羧酸、酯等。

常见官能团：碳碳双键 C=C、碳碳三键 C≡C、卤原子（-X）、羟基（-OH，醇类与酚类的差别在于羟基是否直接连在苯环上）、醛基（-CHO）、羰基（>C=O）、羧基（-COOH）、酯基（-COOR）、氨基（-NH₂）、酰胺基（-CONH₂）。

**烷烃系统命名法**（选主链、编号、写名称）：①选最长的碳链为主链，按碳原子数称"某烷"；②从离支链最近的一端开始编号；③相同支链合并，用"二、三"等表示数目，位置号之间用逗号，位置号与名称之间用短线。例：2,3-二甲基丁烷；3-甲基戊烷。

烯烃、炔烃命名：选含双键（三键）的最长链为主链，编号从离双键（三键）最近的一端开始。苯的同系物命名：以苯环为母体，如甲苯、乙苯、邻二甲苯（1,2-二甲苯）等。

### 1.2 同分异构现象

化合物具有相同的分子式而结构不同的现象叫同分异构现象，产生的同分异构体彼此互为同分异构体。常见类型：①碳链异构（碳骨架不同）；②位置异构（官能团位置不同）；③官能团异构（类别异构，如 C₂H₆O 可表示 CH₃CH₂OH 和 CH₃OCH₃；C₃H₆O₂ 可表示羧酸和酯）。

书写同分异构体的有序方法：先写碳链异构（主链由长到短，支链由整到散，位置由边到中），再考虑官能团位置异构，最后考虑官能团类别异构。常用"减碳法"保证不重不漏。

典型数目：丁烷（C₄H₁₀）有 2 种同分异构体（正丁烷、异丁烷）；戊烷（C₅H₁₂）有 3 种；C₄H₈（烯烃）有 3 种（1-丁烯、2-丁烯、2-甲基丙烯），环烷烃类另有环丁烷、甲基环丙烷 2 种（合计 5 种）；分子式 C₄H₁₀O 的醇有 4 种，醚有 3 种。

### 1.3 有机反应类型

- **取代反应**：有机物分子中的某些原子或原子团被其他原子或原子团所替代。如烷烃与卤素单质光照（CH₄ + Cl₂ 光照 CH₃Cl + HCl）、苯的硝化（C₆H₆ + HNO₃ 浓硫酸加热 C₆H₅NO₂ + H₂O）、卤代烃水解、酯化反应。
- **加成反应**：不饱和键断裂与其他原子或原子团结合。如烯烃、炔烃与 H₂、X₂、HX、H₂O 加成，苯与 H₂ 加成生成环己烷，醛、酮与 H₂ 加成生成醇。
- **消去反应**：有机物在一定条件下脱去小分子（H₂O、HX 等）生成不饱和键。如 CH₃CH₂OH 浓硫酸 170℃ CH₂=CH₂↑ + H₂O；CH₃CH₂Br + NaOH 醇溶液加热 CH₂=CH₂↑ + NaBr + H₂O。卤代烃消去、醇消去的共同条件要求 β 碳上有氢。
- **氧化反应**：有机物的燃烧；烯烃、醇、醛等被 KMnO₄ 酸性溶液氧化；醇催化氧化（2CH₃CH₂OH + O₂ 铜催化加热 2CH₃CHO + 2H₂O）。
- **还原反应**：如醛、酮加氢（CH₃CHO + H₂ 催化剂加热 CH₃CH₂OH）、硝基苯还原为苯胺。
- **加聚反应**：单体通过加成聚合，如 n CH₂=CH₂ 催化剂 [CH₂—CH₂]n（聚乙烯）；n CH₂=CHCl → 聚氯乙烯。
- **缩聚反应**：单体间脱去小分子（H₂O 等）聚合，如己二酸与己二胺缩聚生成尼龙-66、氨基酸缩聚成蛋白质。酚醛树脂由苯酚与甲醛缩聚而成。

### 例题

**题目**：某烷烃的结构简式为 (CH₃)₂CHCH₂C(CH₃)₃，写出其系统名称，并判断其一氯代物有几种。

**解析**：最长碳链含 5 个碳原子，命名为 2,2,4-三甲基戊烷。分子中碳原子等效氢情况：—CH₃ 共四类位置（编号 1 上的三个甲基等效、2 上的两个甲基等效、4 上的两个甲基等效、3 位的 CH 一个），等效氢有 4 种，故一氯代物有 4 种。系统命名步骤必须"先选最长链、后编号"，避免因支链位置号最小原则出错。

## 本章小结与常见错误

1. 常见错误：命名时主链选择或编号方向错误。烷烃必须选最长碳链为主链；烯炔编号须使官能团位置号最小。
2. 常见错误：把官能团异构漏算。书写同分异构体时类别异构（醇/醚、羧酸/酯、醛/酮）常被忽略，需按"碳链异构→位置异构→类别异构"顺序依次考虑。
3. 常见错误：混淆取代与加成。加成反应不饱和键断裂且无小分子生成，取代反应"上一下一"有副产物（HX、H₂O 等）。
4. 常见错误：把乙醇与 NaOH 水溶液、NaOH 醇溶液的反应弄混。前者是取代（水解生成乙醇），后者是消去（生成乙烯）。

## 第二章 烃及其衍生物

> 本章核心：各类烃与烃的衍生物的典型性质，重点掌握烯烃、苯及醇、醛、羧酸、酯的代表反应与官能团转化。

### 2.1 烷烃、烯烃、炔烃与芳香烃

**烷烃**：只含 C—C 单键，通式 CₙH₂ₙ₊₂，性质稳定，不与强酸、强碱、KMnO₄ 反应，特征反应为取代（光照与 Cl₂、Br₂ 反应）、氧化（燃烧）。

**烯烃**：含 C=C，通式 CₙH₂ₙ，性质活泼：加成（与 Br₂/CCl₄ 褪色、H₂、HX、H₂O）、加聚、被 KMnO₄ 氧化（紫色褪去）。烯烃与 KMnO₄ 反应可用于鉴别饱和烃与不饱和烃。乙烯：CH₂=CH₂，无色稍有甜味的气体，实验室用乙醇与浓硫酸在 170 ℃ 脱水制取。

**炔烃**：含 C≡C，通式 CₙH₂ₙ₋₂。乙炔 CH≡CH 可由电石与水反应制取：CaC₂ + 2H₂O = Ca(OH)₂ + CH≡CH↑，易燃烧（氧炔焰温度高，用于焊接、切割金属），能使溴水、KMnO₄ 溶液褪色。

**芳香烃（苯及苯的同系物）**：苯分子是平面正六边形结构，碳碳键是介于单键与双键之间的特殊键，故苯**不能**使溴水、KMnO₄ 溶液褪色（分层现象：上层无色、下层橙黄色）。苯能发生：取代（与 Br₂ 铁屑催化、硝化、磺化）、加成（与 H₂ 催化加氢生成环己烷）、燃烧。苯的同系物（甲苯）因侧链受苯环影响，可被 KMnO₄ 酸性溶液氧化（苯环上无侧链的苯不能），且苯环上的取代更容易（邻、对位活化），如甲苯硝化生成 TNT（2,4,6-三硝基甲苯）。

### 2.2 卤代烃、醇与酚

**卤代烃**：官能团 -X。水解反应（取代，NaOH 水溶液加热）：CH₃CH₂Br + NaOH 水加热 CH₃CH₂OH + NaBr；消去反应（NaOH 醇溶液加热）：CH₃CH₂Br + NaOH 醇加热 CH₂=CH₂↑ + NaBr + H₂O。卤代烃是连接烃与醇的桥梁。

**醇**：官能团 -OH（羟基），乙醇 C₂H₅OH：①与 Na 反应放 H₂（2C₂H₅OH + 2Na = 2C₂H₅ONa + H₂↑，比水与 Na 反应缓和）；②催化氧化（Cu/Ag 催化，加热）生成醛：2CH₃CH₂OH + O₂ 铜催化加热 2CH₃CHO + 2H₂O；③消去生成烯（浓硫酸 170 ℃）；④酯化反应（与羧酸）；⑤燃烧。多元醇（乙二醇、甘油）分子间氢键更强，黏度大、沸点高。

**酚**：羟基直接连在苯环上，苯酚 C₆H₅OH：①弱酸性（酸性弱于碳酸，C₆H₅OH + NaOH = C₆H₅ONa + H₂O；苯酚钠溶液中通入 CO₂：C₆H₅ONa + CO₂ + H₂O = C₆H₅OH + NaHCO₃，生成 NaHCO₃ 而非 Na₂CO₃）；②与浓溴水反应生成 2,4,6-三溴苯酚白色沉淀（灵敏检验）；③遇 FeCl₃ 显紫色（检验方法）；④易被氧化（空气中变粉红）；⑤消毒杀菌、制酚醛树脂。

### 2.3 醛、羧酸与酯

**醛**：官能团 -CHO。乙醛 CH₃CHO：①银镜反应（与银氨溶液水浴加热）：CH₃CHO + 2Ag(NH₃)₂OH 水浴加热 CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O，试管内壁形成光亮银镜，可检验醛基；②与新制 Cu(OH)₂ 悬浊液加热生成砖红色 Cu₂O 沉淀：CH₃CHO + 2Cu(OH)₂ + NaOH 加热 CH₃COONa + Cu₂O↓ + 3H₂O；③与 H₂ 加成还原为醇；④催化氧化为羧酸。甲醛 HCHO 是气体，俗称蚁醛，35%~40% 水溶液叫福尔马林，用于浸制生物标本。

**羧酸**：官能团 -COOH，具有酸性（乙酸 CH₃COOH，K_a ≈ 1.8×10⁻⁵，酸性强于碳酸），与活泼金属、碱、盐反应；能发生酯化反应：CH₃COOH + C₂H₅OH 浓硫酸加热 CH₃COOC₂H₅ + H₂O（乙酸乙酯，有果香味）。酯化反应机理"酸脱羟基、醇脱氢"。甲酸 HCOOH 含醛基，有还原性（能发生银镜反应）。

**酯**：官能团 -COOR，能发生水解反应（酸催化可逆，生成酸与醇；碱催化完全，生成羧酸盐与醇）：CH₃COOC₂H₅ + NaOH 加热 CH₃COONa + C₂H₅OH。酯类可用作香料、溶剂等。

官能团间的转化链：卤代烃 ⇌ 醇 → 醛 → 羧酸 → 酯；烯烃 ↔ 醇、烷烃 → 卤代烃 → 醇等，构成有机化学的主干转化网络。

### 例题

**题目**：有机物 A 的分子式为 C₃H₆O₂，A 能发生银镜反应，又能与 NaHCO₃ 溶液反应放出气体。推断 A 的结构简式，并写出其与乙醇发生酯化反应的方程式。

**解析**：A 既能银镜反应（含 -CHO）又能与 NaHCO₃ 反应（含 -COOH），分子式为 C₃H₆O₂ 且同时含醛基和羧基，结构只能为 HOOC—CH₂—CHO（甲酰乙酸）。酯化反应发生在羧基上：HOOCCH₂CHO + C₂H₅OH 浓硫酸加热 C₂H₅OOCCH₂CHO + H₂O。注意酯化只发生在羧基上，醛基不参与酯化，反应后醛基仍保留，故产物仍能发生银镜反应。

## 本章小结与常见错误

1. 常见错误：认为苯含有 C=C 双键故能使溴水褪色。苯中碳碳键是介于单双键之间的特殊键，不与溴水、KMnO₄ 反应；烯烃才具有典型的加成与氧化性质。
2. 常见错误：苯酚钠溶液中通入 CO₂ 生成 Na₂CO₃。因苯酚酸性弱于碳酸而强于 HCO₃⁻，产物应为 NaHCO₃。
3. 常见错误：银镜反应或与新制 Cu(OH)₂ 反应中醛基用量算错。1 mol 醛基分别消耗 2 mol Ag(NH₃)₂OH、2 mol Cu(OH)₂；甲醛含两个醛基当量，计算时需×2。
4. 常见错误：酯化反应断键位置写反。正确机理是"酸脱羟基、醇脱氢"，生成的水中氧原子来自羧基。

## 第三章 有机合成与推断

> 本章核心：掌握常见官能团的转化关系与引入、消除方法，能设计简单有机合成路线，会解有机推断题（信息题）。

### 3.1 官能团转化关系

核心转化关系（"三角转化"）：醇 → 醛 → 羧酸 → 酯，以及烯烃 → 卤代烃 → 醇、烷烃 → 卤代烃 → 醇等。

- **引入碳碳双键**：卤代烃消去、醇消去。
- **引入羟基**：烯烃与水加成、卤代烃水解、醛/酮加氢、酯水解。
- **引入醛基**：伯醇氧化、烯烃氧化断链。
- **引入羧基**：醛氧化、醇氧化（CH₃CH₂OH 直接氧化得 CH₃COOH）、酯水解。
- **引入卤原子**：烷烃（或苯）光照/催化取代、烯炔加成、醇与 HX 取代。
- **增长碳链**：加聚、缩聚、炔钠与卤代烃取代等；**缩短碳链**：烃的催化裂化、氧化（如烯烃被 KMnO₄ 氧化断链）、脱羧。

### 3.2 有机合成路线设计

设计原则：①合成路线简短（步骤少、产率高）；②原料易得、条件温和；③副反应少、产物易分离；④符合官能团保护思想（如氧化醇时先保护碳碳双键或先氧化后加成，避免官能团互相干扰）。

合成思路分两种：**正向合成**（由原料出发，根据官能团转化逐步延伸）与**逆推法**（由目标产物倒推其前体，如酯由醇与酸合成、醛氧化为酸等），通常采用"逆推为主、正推验证"。

经典路线示例：由乙烯合成乙酸乙酯：CH₂=CH₂ + H₂O 催化剂加热 CH₃CH₂OH；CH₃CH₂OH 氧化（或 CH₂=CH₂ 氧化）得 CH₃CHO 再氧化为 CH₃COOH；CH₃COOH + CH₃CH₂OH 浓硫酸加热 CH₃COOC₂H₅ + H₂O。三步实现"烯→醇→醛→酸→酯"完整链条。

### 3.3 有机推断题方法

推断题解题"五步法"：①审题定"骨架"：由分子式（不饱和度 Ω = (2C + 2 + N - H - X)/2）、已知转化关系判断可能含的官能团；②抓特征反应定官能团：银镜/新制 Cu(OH)₂ 定醛基，FeCl₃ 显色或溴水白色沉淀定酚羟基，NaHCO₃ 放气定羧基，Na 放 H₂ 定羟基或羧基，卤代烃消去定卤原子邻位 H；③由反应条件反推结构：浓硫酸 170 ℃ 定醇消去、NaOH 醇溶液加热定卤代烃消去、催化剂加氢定烯/醛/酮；④由题给新信息套用新反应（信息迁移题），注意断键成键位置；⑤代入检验：把推断结果代回所有转化关系逐一验证，确保各步产物吻合。

有机物不饱和度计算：Ω = 1 可能有双键或环，Ω = 2 可能有三键或两个双键，苯环 Ω = 4。同分异构体书写要求"有序、不重不漏"，高考常限定条件（如含苯环、能发生银镜反应、峰面积比等）。

### 例题

**题目**：有机物 X 分子式为 C₈H₈O₂，能与 NaHCO₃ 反应放出 CO₂，其苯环上的一氯代物只有一种。写出 X 可能的结构简式。

**解析**：X 含羧基（与 NaHCO₃ 放气），且含苯环。设苯环上其余取代基为 C₂H₃O₂ 的基团（如 -CH₂COOH 或 -COOCH₃），但由于能与 NaHCO₃ 反应，必须含 -COOH：可能的母体为对苯二甲酸衍生物。逐一分析：若苯环上只有一个侧链 -CH₂COOH（苯乙酸），其一氯代物有苯环上 3 种，不符合"只有一种"；若两个相同侧链处于对位：两个 -CH₂COOH 对位（对苯二乙酸），苯环上 4 个 H 等效，一氯代物只有 1 种，符合。故 X 为对苯二乙酸：HOOCCH₂—C₆H₄—CH₂COOH（对位）。本题综合考查官能团性质与"等效氢"计数。

## 本章小结与常见错误

1. 常见错误：推断时忽略不饱和度信息。分子式相同但结构相差很大的情况，可先算 Ω 判断是否存在苯环、双键或环，避免写出不符合分子式的结构。
2. 常见错误：官能团转化的条件记混。醇氧化成醛需铜/银催化加热，消去需浓硫酸 170 ℃；卤代烃水解用 NaOH 水溶液、消去用 NaOH 醇溶液。
3. 常见错误：合成路线中不考虑官能团保护。当分子中同时存在多个官能团时，要合理安排先后顺序，防止目标官能团在合成过程中被破坏。
4. 常见错误：限定条件下同分异构体书写漏写。应先在限定条件（含苯环、能银镜等）下确定官能团组合，再按"苯环上取代基组合—位置异构"依次展开，并数清等效氢与核磁共振氢谱峰。
