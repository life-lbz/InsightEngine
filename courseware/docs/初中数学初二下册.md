## 第1章 二次根式

### 1.1 二次根式的概念与性质

- **二次根式**：一般地，形如 √a（a ≥ 0）的式子叫做二次根式，其中"√"叫做二次根号，a 叫做被开方数。二次根式的两个要素：有根号且根指数为 2；被开方数必须是非负数。
- 二次根式的双重非负性：(1) 被开方数 a ≥ 0；(2) 二次根式本身 √a ≥ 0。两个非负性常用于求值、判断。
- 基本性质：(√a)² = a（a ≥ 0）；√(a²) = |a| = a（a ≥ 0）或 -a（a < 0）。化简 √(a²) 时一定要先判断 a 的正负。
- 与算术平方根的关系：二次根式 √a 就是 a 的算术平方根，a 叫做被开方数，只有当 a ≥ 0 时 √a 才有意义。

### 1.2 二次根式的乘除

- **乘法法则**：√a · √b = √(ab)（a ≥ 0，b ≥ 0）。即两个二次根式相乘，把被开方数相乘，根指数不变。
- **除法法则**：√a ÷ √b = √(a/b)（a ≥ 0，b > 0）。即两个二次根式相除，把被开方数相除，根指数不变。
- **最简二次根式**：被开方数不含分母，且被开方数中不含能开得尽方的因数或因式。如 √8 = 2√2，√(1/2) = √2/2 都是化成最简的结果。
- 化简二次根式的一般方法：先把被开方数分解成完全平方数（或完全平方式）与其他因式的乘积，再利用 √(a²b) = a√b（a ≥ 0）化简。

### 1.3 二次根式的加减与混合运算

- **同类二次根式**：化简后被开方数相同的二次根式是同类二次根式，如 2√3 与 5√3。判断时先把二次根式化成最简，再看被开方数是否相同。
- **加减法则**：二次根式加减时，先把各个二次根式化成最简二次根式，再把同类二次根式合并，即"先化简，再合并"，类似于合并同类项。
- 混合运算顺序：先乘方、再乘除、最后加减，有括号先算括号；运算中注意运用乘法公式（平方差、完全平方）简化计算。
- 二次根式的乘法运算中常利用平方差公式：(√a + √b)(√a - √b) = a - b；分母有理化也常借助它进行。

### 例题

计算：(√24 - √(1/2)) - (√(1/8) + √6)。

解：原式 = (2√6 - √2/2) - (√2/4 + √6)

= 2√6 - √2/2 - √2/4 - √6

= (2√6 - √6) + (-√2/2 - √2/4)

= √6 - 3√2/4。

解析：先化简各项：√24 = 2√6，√(1/2) = √2/2，√(1/8) = √2/4；再去括号（注意第二个括号前是减号，去括号后各项变号）；最后合并同类二次根式。同类二次根式系数相加减，根号部分不变。

## 本章小结与常见错误

1. 忽略被开方数非负：化简 √(a²) 时直接写 = a，当 a < 0 时应为 -a；如 √((-2)²) = 2 而不是 -2。
2. 混淆 (√a)² 与 √(a²)：(√a)² 要求 a ≥ 0 且结果为 a；√(a²) 结果必须是非负的 |a|，两者条件不同。
3. 加减与乘除法则混淆：√a + √b ≠ √(a+b)，二次根式相加减必须先化成最简再合并同类二次根式；而 √a · √b = √(ab) 只在乘除时成立。
4. 最简二次根式判断失误：√(1/3)（分母含根号或根号内含分母）、√12（含能开尽的因数 4）都不是最简二次根式。

## 第2章 勾股定理

### 2.1 勾股定理

- **勾股定理**：直角三角形两直角边 a、b 的平方和等于斜边 c 的平方，即 a² + b² = c²。其中较短的直角边叫勾，较长的直角边叫股，斜边叫弦。
- 勾股定理揭示了直角三角形三边之间的数量关系，已知任意两边可求第三边：c = √(a² + b²)，a = √(c² - b²)，b = √(c² - a²)。
- 勾股定理只适用于直角三角形，使用前提必须先确认三角形是直角三角形并找准斜边（直角所对的边）。
- 常见的验证方法：我国古代数学家赵爽用"赵爽弦图"（四个全等直角三角形拼成正方形）证明了勾股定理；教材中还有毕达哥拉斯拼图等多种证法。

### 2.2 勾股定理的逆定理与勾股数

- **逆定理**：如果三角形的三边长 a、b、c 满足 a² + b² = c²，那么这个三角形是直角三角形，且 c 所对的角是直角。
- 利用逆定理判定直角三角形的步骤：先找出最大边（作为 c），再计算较小两边的平方和，与最大边的平方比较，相等即为直角三角形，且最大边所对角为直角。
- **勾股数**：能够成为直角三角形三条边长的三个正整数，称为勾股数，如 3、4、5；5、12、13；6、8、10；8、15、17 等。勾股数同时扩大（或缩小）相同的正整数倍，得到的仍是勾股数。
- 逆定理是判定直角三角形的重要工具，与全等三角形的 HL 判定、斜边中线性质等联系紧密。

### 2.3 勾股定理的实际应用

- 勾股定理常用于解决实际问题：求距离（如旗杆折断、梯子靠墙）、求高度与长度（如大树高度、斜坡长度）、最短路径问题（把立体图形展开成平面图形后求两点间距离）等。
- **折叠问题**：把矩形等图形折叠后，利用折叠前后对应线段相等、对应角相等，结合勾股定理列方程求解未知线段。
- 构造直角三角形的方法：对于非直角三角形问题，常作高线构造直角三角形，再利用勾股定理计算。
- 面积法：用"同一图形面积的不同表示方法相等"建立等量关系，也是勾股定理证明和应用中的常用技巧。

### 例题

在 Rt△ABC 中，∠C = 90°，AC = 6，BC = 8，求斜边 AB 上的高 CD 的长。

解：由勾股定理得 AB = √(AC² + BC²) = √(36 + 64) = √100 = 10。

由面积法，S△ABC = 1/2 × AC × BC = 1/2 × AB × CD，

即 1/2 × 6 × 8 = 1/2 × 10 × CD，24 = 5CD，解得 CD = 4.8。

答：斜边 AB 上的高为 4.8。

解析：先用勾股定理求斜边，再用"同一三角形面积的两种表示"（两直角边乘积的一半与斜边乘斜边高的一半）建立方程求高。面积法是勾股定理应用题中最常用的技巧之一。

## 本章小结与常见错误

1. 乱用勾股定理：勾股定理只适用于直角三角形，非直角三角形直接用 a² + b² = c² 必然出错；且斜边 c 是最大边，不能用错字母。
2. 平方计算后再开方丢解：由 c² = 25 得 c = 5，边长只能是正值，不能写成 ±5；但求平方根时的负数解在几何中应舍去。
3. 逆定理判断错误：最大边的平方等于另两边平方和才为直角三角形，常忽略"找最大边"这一关键步骤。
4. 勾股数误判：如 0.3、0.4、0.5 虽是满足 a² + b² = c² 的三数，但不是正整数，不是勾股数。

## 第3章 一次函数

### 3.1 函数与一次函数的概念

- **函数**：一般地，在一个变化过程中，如果有两个变量 x 与 y，并且对于 x 的每一个确定的值，y 都有唯一确定的值与其对应，那么就说 x 是自变量，y 是 x 的函数。
- 函数的表示方法：解析式法、列表法、图象法。判断两个变量是否构成函数关系，关键是看"对于每个 x 是否唯一对应一个 y"。
- **一次函数**：一般地，形如 y = kx + b（k、b 是常数，k ≠ 0）的函数叫做一次函数。当 b = 0 时，y = kx（k ≠ 0）叫做正比例函数，正比例函数是特殊的一次函数。
- 确定一次函数解析式需要两个条件（两个点的坐标），方法是**待定系数法**：设解析式 → 代入两点坐标列方程组 → 解出 k、b。

### 3.2 一次函数的图象与性质

- **图象**：一次函数 y = kx + b 的图象是一条直线，它由两点确定（通常取与 x 轴、y 轴的交点）。正比例函数 y = kx 的图象是过原点的一条直线。
- **画图步骤**：列表（取两个点的坐标）→ 描点 → 连线。k 决定直线的倾斜方向与程度，b 决定直线与 y 轴交点的位置（0，b）。
- **性质**：当 k > 0 时，y 随 x 的增大而增大，图象从左向右上升；当 k < 0 时，y 随 x 的增大而减小，图象从左向右下降。
- k 的绝对值越大，直线越"陡"；|k| 相同的两条直线平行（b 不同）。当 b > 0 时直线交 y 轴正半轴，b < 0 时交 y 轴负半轴。

### 3.3 一次函数与方程、不等式

- 一次函数 y = kx + b 的图象与 x 轴交点的横坐标，就是方程 kx + b = 0 的解；从"形"的角度看，是直线与 x 轴交点的横坐标。
- 二元一次方程与一次函数的关系：二元一次方程 kx - y + b = 0 的每一组解，都是直线 y = kx + b 上的点的坐标；两个一次函数图象交点的坐标，就是对应二元一次方程组的解。
- 一次函数与不等式：kx + b > 0 的解集，就是直线 y = kx + b 在 x 轴上方的部分对应的 x 的取值范围；kx + b < 0 则对应 x 轴下方的部分。
- 一次函数应用题：行程、销售、方案选择等问题，常通过建立一次函数模型，利用图象（如分段函数）或解析式进行比较与决策。

### 例题

已知一次函数 y = kx + b 的图象经过点 A(1，3) 和 B(-1，-1)。(1) 求这个一次函数的解析式；(2) 求该函数图象与 x 轴、y 轴围成的三角形的面积。

解：(1) 把 A、B 代入 y = kx + b，得 {k + b = 3, -k + b = -1}，

解得 k = 2，b = 1，所以 y = 2x + 1。

(2) 令 y = 0，得 2x + 1 = 0，x = -1/2，所以与 x 轴交于点 (-1/2，0)；

令 x = 0，得 y = 1，所以与 y 轴交于点 (0，1)。

三角形面积 S = 1/2 × |x 截距| × |y 截距| = 1/2 × (1/2) × 1 = 1/4。

答：解析式为 y = 2x + 1，围成的三角形面积为 1/4。

解析：第 (1) 问用待定系数法列方程组求 k、b；第 (2) 问先求图象与两坐标轴的交点，直角三角形的两直角边长分别是两个截距的绝对值，再用面积公式。

## 本章小结与常见错误

1. 一次函数定义漏条件：y = kx + b 中要求 k ≠ 0，如 y = 5（b = 5，k = 0）是常数函数，不是一次函数。
2. 待定系数法代入错误：设 y = kx + b 后，把点的横、纵坐标代反位置，导致方程组错误；应"x 代横坐标，y 代纵坐标"。
3. 图象性质记忆混乱：k > 0 时 y 随 x 增大而增大，k < 0 时减小；常与"b 的正负决定增减"混淆，b 只决定与 y 轴交点位置。
4. 由图象看不等式解集方向搞反：kx + b > 0 是直线在 x 轴上方的部分，若 k < 0，解集应在交点的左侧，要注意结合图象判断方向。
