# 高中化学高三上册课程讲义
课程编号：senior_chemistry_g12s1　适用学段：高中　年级：高三　学期：上学期

本讲义为高考化学一轮复习讲义，按"无机综合、原理综合、有机综合"三大板块展开。一轮复习的目标不是重复新课，而是把分散在各册的知识"网络化、系统化、方法化"，熟练运用守恒思想、平衡思想、结构决定性质思想解决综合问题。高三复习要重视回归教材，构建知识网络，规范化学用语，并通过典型例题总结通法。

## 第一章 无机综合复习

> 本章核心：建立元素化合物知识网络，掌握无机推断与工艺流程题的分析方法，形成"物质类别—化合价—性质"三维认知。

### 1.1 元素化合物知识网络

构建知识网络的两个维度：**物质类别**（单质、氧化物、酸/碱、盐）与**化合价**（价类二维图）。以硫为例：S（0）→ SO₂（+4）→ SO₃、H₂SO₄（+6）；S²⁻（-2）→ S（0）→ SO₂（+4）→ SO₄²⁻（+6），同价态间靠酸碱反应转化，不同价态间靠氧化还原转化。

主干知识链（必背）：

- 钠：Na → Na₂O/Na₂O₂ → NaOH → Na₂CO₃ ⇌ NaHCO₃，焰色反应（黄色）检验。
- 氯：Cl₂ → HCl/HClO → NaCl/NaClO/Ca(ClO)₂，氯水成分多、性质叠加。
- 硫：S → SO₂（漂白、还原性）→ SO₃ → H₂SO₄（浓：吸水性、脱水性、强氧化性）。
- 氮：N₂ → NH₃（碱性气体、喷泉实验）→ NO → NO₂ → HNO₃（强氧化性，浓稀产物不同）。
- 铁：Fe → FeO/Fe₂O₃/Fe₃O₄ → Fe(OH)₂/Fe(OH)₃ → Fe²⁺/Fe³⁺ 相互转化（加氧化剂/还原剂）。Fe³⁺ 检验：加 KSCN 溶液变红。
- 铝：Al → Al₂O₃/Al(OH)₃（两性）→ 铝盐/偏铝酸盐；Al(OH)₃ 受热分解 2Al(OH)₃ 加热 Al₂O₃ + 3H₂O。

复习要点：每个元素抓住"单质—氧化物—氢化物（水化物）—盐"主线，注意特殊反应条件（高温、放电、催化剂）与特殊现象（颜色、气味、沉淀），并会用离子方程式表达核心转化。

### 1.2 常见无机推断题方法

无机推断题的特点：以框图或文字形式给出物质转化，突破口常为"特征颜色、特征反应、特征数据、特征条件"。

常用突破口：

- 颜色：Fe³⁺ 黄色、Fe²⁺ 浅绿色、Cu²⁺ 蓝色、Fe(OH)₃ 红褐色、Cu(OH)₂ 蓝色、AgCl 白色、FeS 黑色等。
- 特征反应：使品红褪色且加热恢复（SO₂）；使湿润红色石蕊变蓝（NH₃）；与 AgNO₃ 生成不溶于稀硝酸的白色沉淀（Cl⁻）；焰色反应黄色（Na）、紫色（K）。
- 特征转化："连续氧化"关系：如 NH₃ → NO → NO₂；S → SO₂ → SO₃；C → CO → CO₂；Na → Na₂O → Na₂O₂。三角形转化：如 A、B、C 三种物质两两能反应（如 Na₂CO₃、CO₂、NaOH 之间的"三线"关系）。
- 特征条件："电解"（Al₂O₃ 熔融电解、NaCl 溶液电解）、"高温"（铝热反应、Fe₂O₃ 与 CO、SiO₂ 与 C）、"催化剂、加热"（NH₃ 催化氧化、SO₂ 催化氧化）、"放电"（N₂ 与 O₂）。

解题策略：先找"题眼"（特征物质/反应）确定若干确定物，再以此为起点向两端延伸，把框图中的"已知→推断→验证"三步走完，最后用产物代入检验是否符合全部转化关系。

### 1.3 工艺流程题解题策略

工艺流程题是高考热点，实质是"从原料到产品的化学分离提纯与转化"问题。解题"三读"：一读流程（原料→预处理→核心反应→分离提纯→产品），二读题干设问（目的、试剂、条件），三读隐含信息（产品纯度、环保、循环利用）。

常用方法归纳：

- 原料预处理：粉碎（增大接触面积）、酸浸/碱浸（溶解）、煅烧（分解、氧化）。
- 控制反应条件的目的：pH 调节（使某离子沉淀而分离，如加 NaOH 调 pH 使 Fe³⁺ 沉淀）、温度控制（防止分解或挥发、加快速率、平衡移动）、过量试剂（提高转化率、保证完全反应）。
- 分离提纯方法：过滤、蒸发结晶、冷却结晶（根据溶解度随温度变化）、洗涤（用冷水/乙醇，减少溶解损失、便于干燥）。
- 常考计算：利用率、产率、纯度；离子沉淀完全的 pH 计算（利用 Ksp）。
- 答题规范："循环利用"的物质要能回路（如母液、尾气回收）；"绿色化学"要点包括原子利用率高、无污染、原料可再生。

### 例题

**题目**：工业上用铝土矿（主要成分 Al₂O₃，含 Fe₂O₃、SiO₂ 杂质）制取 Al₂O₃ 的流程为：铝土矿 →加盐酸溶解→ 溶液 A →加过量 NaOH→ 沉淀 B 与溶液 C →通 CO₂→ 沉淀 D →灼烧→ Al₂O₃。指出沉淀 B、溶液 C 中主要物质及灼烧反应的化学方程式。

**解析**：加盐酸后 Fe₂O₃ 溶为 FeCl₃、Al₂O₃ 溶为 AlCl₃、SiO₂ 不溶（沉淀）——注意流程中"过滤"需在加盐酸后：沉淀为 SiO₂。滤液中加过量 NaOH：Fe³⁺ 生成 Fe(OH)₃ 沉淀（沉淀 B 为 Fe(OH)₃），Al³⁺ 生成 NaAlO₂（溶液 C 中主要含 NaAlO₂ 与 NaCl）。通 CO₂：2NaAlO₂ + CO₂ + 3H₂O = 2Al(OH)₃↓ + Na₂CO₃（沉淀 D 为 Al(OH)₃），灼烧 2Al(OH)₃ 加热 Al₂O₃ + 3H₂O。关键：利用 Al(OH)₃ 两性，用"酸溶、过量碱沉铁、CO₂ 沉铝"实现分离。

## 本章小结与常见错误

1. 常见错误：把 Al(OH)₃ 溶于过量的强碱当作"消失即分离"。偏铝酸盐需通入 CO₂（或滴加盐酸至适量）才能重新沉淀出 Al(OH)₃，且 CO₂ 过量时产物为 NaHCO₃。
2. 常见错误：离子检验顺序颠倒。如检验 Fe²⁺ 与 Fe³⁺ 混合液，先加 KSCN（检验 Fe³⁺），再用酸性 KMnO₄ 或加 KSCN+氯水检验 Fe²⁺，避免互相干扰。
3. 常见错误：工艺流程中"调 pH 除杂"选错试剂。除 Fe³⁺ 时常用对应金属氧化物或氢氧化物调 pH（不引入新杂质），不能直接用 NaOH 大量沉淀（会损失目标离子）。
4. 常见错误：忽略氧化还原与守恒关系。如 Fe₂O₃ 与 CO 反应、铝热反应中电子转移数计算，需先标价再算。

## 第二章 原理综合复习

> 本章核心：化学反应原理综合题的模型构建（能量、速率、平衡、电化学），平衡图像判读与 K、转化率计算，原电池与电解池的电极判断与定量计算。

### 2.1 化学反应原理综合题

原理综合题常以"某反应（多为可逆、放热）+ 平衡常数 + 图像 + 电化学"为载体设问。答题主线：

- 能量：ΔH 正负与大小（盖斯定律：目标反应可由已知反应相加减获得，ΔH 相应加减），热化学方程式书写要标状态与 ΔH 单位（kJ/mol）。
- 速率：影响速率因素；比较 v 大小看单位与系数（v(A)/a 比较法）。
- 平衡：K 表达式、Q 与 K 比较判方向、转化率与产率计算（三段式）。
- 条件选择：工业条件（如合成氨"高压、适当温度、催化剂"）要从速率与平衡两方面综合论证。

综合题常见陷阱：K 随温度升高增大则正反应吸热；等容充惰性气体平衡不移动；催化剂不改变 K 与平衡位置；平衡常数与浓度商勿混淆。

### 2.2 平衡图像与计算

图像题"三步读图法"：一看轴（横纵坐标含义与单位）、二看点（起点、拐点、终点、交点）、三看线（斜率、走向、有无平台）。常用结论：

- "先拐先平数值大"：先拐者温度高或压强大；温度升高含量增大则正反应吸热，压强增大含量增大则正反应气体分子数减小。
- 恒温线/恒压线：固定一个变量（如温度），看另一变量（压强）的影响，"定一议二"。
- 转化率随投料比变化图：m 点之后增加某种反应物，其自身转化率下降而另一种上升，注意对称性（两种原料按化学计量比投料时总转化率有极值）。

计算模板（三段式）：起始量—变化量—平衡量，注意气体用物质的量或浓度均可，但 K 表达式中必须用平衡浓度（mol/L）；若给的是物质的量与容器体积 V，先换算浓度再代入 K。涉及气体分压 Kp 时，pᵢ = p总 × nᵢ/n总。

### 2.3 电化学综合

**原电池**（化学能→电能）：负极失电子被氧化（电子流出），正极得电子被还原；电解质溶液中阳离子移向正极、阴离子移向负极。电极反应书写：先写总反应，再写较简单的一极，相减得另一极。

- 氢氧燃料电池（碱性介质）：负极 2H₂ + 4OH⁻ - 4e⁻ = 4H₂O；正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻；总反应 2H₂ + O₂ = 2H₂O。
- 锌锰干电池、铅蓄电池（放电时负极 Pb + SO₄²⁻ - 2e⁻ = PbSO₄）。
- 金属腐蚀与防护：钢铁吸氧腐蚀正极 O₂ + 2H₂O + 4e⁻ = 4OH⁻；牺牲阳极（连接更活泼金属）、外加电流阴极保护法。

**电解池**（电能→化学能）：阳极（接电源正极）失电子被氧化，阴极（接负极）得电子被还原。放电顺序：阳离子放电顺序（氧化性），阴离子放电顺序（还原性，S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根）。典型电解：

- 电解饱和食盐水：2NaCl + 2H₂O 电解 2NaOH + H₂↑ + Cl₂↑（阳极 Cl₂、阴极 H₂）。
- 电解 CuCl₂ 溶液：CuCl₂ 电解 Cu + Cl₂↑。
- 电解精炼铜：粗铜作阳极、精铜作阴极、CuSO₄ 溶液作电解质，阳极溶解的是粗铜中比铜活泼的杂质，金、银等沉为阳极泥。
- 电镀：镀件作阴极、镀层金属作阳极、含镀层金属离子的盐溶液作电解液。

定量关系（电子守恒）：通过的电量与电极产物物质的量的关系——每转移 2 mol e⁻，阳极生成 1 mol Cl₂、阴极生成 1 mol H₂ 或析出 1 mol Cu（2 价）、64 g Cu。串联电路中各电极转移电子数相等。

### 例题

**题目**：将两个铂电极插入 500 mL CuSO₄ 溶液中进行电解，一段时间后阴极质量增加 3.2 g（无气体逸出），求阳极产生的气体在标准状况下的体积及电解后溶液中 c(H⁺)（忽略体积变化）。

**解析**：阴极 Cu²⁺ + 2e⁻ = Cu，析出 3.2 g Cu 即 0.05 mol，转移电子 0.1 mol。阳极电解水放出 O₂：4OH⁻ - 4e⁻ = O₂↑ + 2H₂O（或 2H₂O - 4e⁻ = O₂↑ + 4H⁺），0.1 mol e⁻ 生成 O₂ 0.025 mol，体积 0.025 × 22.4 = 0.56 L。阳极同时生成 H⁺ 0.1 mol（2H₂O - 4e⁻ = O₂↑ + 4H⁺），c(H⁺) = 0.1/0.5 = 0.2 mol/L，pH = -lg 0.2 ≈ 0.7。本题关键是"电解硫酸铜溶液实质是电解水"，阳极产氧并生成酸。

## 本章小结与常见错误

1. 常见错误：电极反应书写不查电荷守恒与介质。燃料电池介质不同电极反应不同（碱性介质 OH⁻ 参与，酸性介质 H⁺ 参与），写完必须配平原子与电荷。
2. 常见错误：Kp 计算中分压取错。各组分分压 = 总压 × 该组分物质的量分数（或体积分数），代入表达式时注意指数与化学计量数一致。
3. 常见错误：电解精炼铜时误认为电解质中 Cu²⁺ 浓度不变。粗铜中的活泼杂质（Fe、Zn）也会溶解，而阳极泥（Ag、Au）不参与，Cu²⁺ 浓度基本不变但需定期补充。
4. 常见错误：忽略"先拐先平"与吸放热判断的方向性。图像中含量随温度升高而增大，只能说明平衡正向（吸热方向）移动，不能直接说正反应吸热（还要确认是温度条件改变所致）。

## 第三章 有机综合复习

> 本章核心：综合运用官能团性质解决推断与合成问题，掌握限定条件下同分异构体的有序书写，提高有机大题的信息迁移能力。

### 3.1 有机推断与合成综合

有机综合题常见信息与推断策略：

- 由分子式算不饱和度 Ω，先定性判断含苯环（Ω ≥ 4）、双键、三键、环、羰基。
- 由特征反应与现象定官能团（银镜→醛基；FeCl₃ 显紫→酚羟基；NaHCO₃ 放气→羧基；Na 放气→羟基/羧基；溴水褪色→碳碳不饱和键）。
- 由转化关系与条件反推：浓硫酸、170 ℃→醇消去；NaOH 醇溶液、加热→卤代烃消去；Cu/O₂、加热→醇氧化（伯醇→醛、仲醇→酮）；银氨溶液或新制 Cu(OH)₂→醛氧化为羧酸；酯化→含醇与羧基。
- 信息迁移题：认真读懂题给新反应（加成、氧化、环化等），明确断键成键位置与原子守恒，把新反应当作"新工具"套用到合成路线中。
- 合成路线设计：逆推法为主——目标产物由哪两个片段缩合/加成得到，逐级往前推至原料，再正写验证；注意官能团保护（如氧化时先保护双键、还原时先保护醛基）。

### 3.2 限定条件下同分异构体书写

书写步骤（"先定骨架，再定官能团，后定位置"）：

1. 由限定条件确定官能团组合：如"能与 NaHCO₃ 反应"→羧基；"能发生银镜反应"→醛基（或甲酸酯）；"水解产物之一能发生银镜"→甲酸酯或缩醛结构；"核磁共振氢谱峰面积比"→对称性要求。
2. 固定苯环时先排取代基种类与数目（1 个、2 个、3 个取代基分别对应邻/间/对、1,2,3-/1,2,4-/1,3,5- 等位置异构）。
3. 烃基部分再考虑碳链异构（由长到短）与位置异构。
4. 检查是否"不重不漏"：可用对称法去重，最后代回分子式核对氢数与不饱和度。

典型练习：C₇H₈O 的芳香族化合物：苯甲醇（C₆H₅CH₂OH）、邻/间/对甲基苯酚（3 种）、苯甲醚（C₆H₅OCH₃），共 5 种，其中能与 Na 反应放出 H₂ 的有 4 种（苯甲醇 + 3 种甲酚），遇 FeCl₃ 显紫色的为 3 种甲酚。

### 3.3 有机综合题解题策略与规范

解题策略：

- 通读全题，把已知条件标注在结构式或框图旁；把"小问"与"信息"对应起来。
- 每推出一层结构立即回填验证：分子式、不饱和度、反应条件、官能团特征是否全部吻合。
- 书写结构简式时注意规范：苯环画法、官能团连接方式（如 -CHO 不能写成 COH）、原子个数正确。
- 答题时写明"反应类型"（如取代反应、加成反应）、"试剂与条件"（如浓硫酸、加热），避免只写箭头不写条件。

常考陷阱：酯化反应条件是"浓硫酸、加热"而非"催化剂"；银镜反应必须水浴加热；卤代烃水解与消去试剂一字之差（NaOH 水溶液/NaOH 醇溶液）；"能与 Na 反应"既可能含羟基也可能含羧基，需结合其他条件二选一。

### 例题

**题目**：有机物 M 的分子式为 C₉H₁₀O₂，M 能与 NaHCO₃ 反应放出 CO₂，苯环上一氯代物只有两种。写出 M 的所有可能结构简式。

**解析**：M 含羧基（能与 NaHCO₃ 放气），分子式 C₉H₁₀O₂ 减去 -COOH（C₁H₁O₂）余 C₈H₉ 连在苯环上：即苯环上有一个取代基，取代基为 C₈H₉ 且含 -COOH，即 -C₃H₇ 侧链上加羧基。若羧基在侧链端，侧链为 -CH₂CH₂CH₂COOH（苯丁酸）或 -CH(CH₃)CH₂COOH、-CH(CH₂CH₃)COOH、-C(CH₃)₂COOH 等，需逐一核对"苯环上一氯代物只有两种"：苯环上单取代时一氯代物有邻、间、对 3 种位置，加上侧链取代，通常不止 2 种——因此 M 应为对位双取代，即苯环上有两个取代基且对位。两个取代基为 -COOH 与 C₃H₇（丙基，有正丙基、异丙基两种），对位取代均满足苯环上一氯代物只有 2 种（环上四个 H 等效分两组）。故 M 为对异丙基苯甲酸（4-异丙基苯甲酸）与对正丙基苯甲酸（4-正丙基苯甲酸），共 2 种。本题训练"由限定条件逐步缩小范围"的推断能力。

## 本章小结与常见错误

1. 常见错误：不饱和度计算错误导致官能团判断失误。C₉H₁₀O₂ 的 Ω = (2×9 + 2 - 10)/2 = 5，其中苯环占 4，说明苯环外还有 1 个双键（羧基），理解 Ω 的组成是关键。
2. 常见错误：书写同分异构体时"位置异构"遗漏或重复。固定取代基组合后，按对称性逐个标位，避免重复计数；苯环二取代的邻/间/对是高频考点。
3. 常见错误：有机合成中官能团顺序颠倒导致多步返工。应先氧化后取代或先保护后氧化，规划好保护与去保护步骤，并在最终答案中标明每步试剂与条件。
4. 常见错误：信息迁移反应照搬条件。新信息反应的催化剂、温度等条件必须原样套用，且要注意反应物中官能团是否会被新反应条件破坏。
