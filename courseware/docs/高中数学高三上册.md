# 高中数学高三上册课程讲义
课程编号：senior_math_g12s1　适用学段：高中　年级：高三　学期：上学期

本讲义为人教A版高中数学一轮复习专题讲义，按"函数与导数、三角函数与数列、几何"三大专题系统梳理高考核心考点。一轮复习的目标是把高一、高二所学知识网络化、方法体系化，重点突破函数零点与不等式、数列求和与证明、解析几何综合等高考解答题的常考模块。

## 第1章 函数与导数专题

### 1.1 函数性质综合复习

- **知识网络**：函数的三要素（定义域、对应关系、值域）与四性质（单调性、奇偶性、周期性、对称性）构成函数复习的主干。定义域优先是贯穿函数问题的第一原则。
- **单调性与奇偶性综合**：奇函数在对称区间上单调性相同，偶函数相反；抽象函数问题常通过赋值法、构造具体函数模型处理，如 f(x + y) = f(x) + f(y) 对应一次函数模型。
- **周期性与对称性**：若 f(x + a) = f(x)，则周期 T = a；若 f(a + x) = f(a − x)，则图象关于直线 x = a 对称；若 f(a + x) = −f(a − x)，则关于点 (a, 0) 对称。周期与对称性组合可以推出更复杂的周期（如两个对称轴推出周期）。
- **图象与变换**：平移、对称、翻折变换的法则必须熟练，如 y = |f(x)|（x 轴下方翻上来）与 y = f(|x|)（y 轴右侧对称到左侧）的区别。
- **比较大小问题**：利用单调性、奇偶性、周期性把自变量化归到同一单调区间内比较；指数、对数、幂的大小比较借助中间量 0、1 与图象。

### 1.2 导数工具的应用

- **导数的两大任务**：研究单调性与求极值最值。含参函数的单调性讨论是一轮复习的重点，分类讨论的依据（二次项系数、判别式、根的大小）要形成固定程序。
- **切线问题**："在点处"与"过点"的切线；两条曲线的公切线问题；利用切线条数求参数范围（转化为方程根的个数）。
- **最值与参数范围**：分离参数法（a ≥ f(x) 恒成立 ⟺ a ≥ f(x)_max）与直接讨论法；存在性问题与恒成立问题的最值方向区分是高频易错点。
- **利用导数研究抽象函数不等式**：如由 f'(x) > f(x) 构造 F(x) = f(x)/eˣ（其导数符号已知），由 f'(x) > x 构造 F(x) = f(x) − x²/2 等，构造函数是导数不等式题的核心技巧。
- **常用放缩工具**：ln x ≤ x − 1，eˣ ≥ x + 1，eˣ ≥ ex，ln x ≤ x/e 等，用于解决含指数、对数的混合不等式。

### 1.3 函数零点与方程根问题

- **零点存在定理**：f(x) 在 [a, b] 上连续且 f(a)·f(b) < 0，则 f(x) 在 (a, b) 内至少有一个零点。定理只保证存在性，不保证唯一性；唯一性需借助单调性。
- **零点个数问题的转化**：函数 f(x) 的零点个数 = 方程 f(x) = 0 的根的个数 = 两函数图象交点的个数。常通过分离常数化为"水平直线 y = a 与曲线 y = g(x) 的交点个数"。
- **已知零点个数求参数**：画出临界图象，找出相切（Δ = 0 或切线斜率相等）时刻的参数值，用数形结合确定范围。
- **零点与极值结合**：三次函数的零点个数由两个极值与 0 的大小关系决定；高次或含参函数的零点问题用导数研究单调性与极值后结合零点存在定理分段判断。
- **二分法**：求零点的近似解，也是体会极限思想、函数连续性的载体，高考中以选择题形式考查原理为主。

### 1.4 函数与不等式综合

- **不等式证明的构造策略**：证明 f(x) > g(x) 构造 h(x) = f(x) − g(x) 求最小值；含两个变量的不等式（如 x₁、x₂ 是 f 的两零点）常转化为单变量或利用均值不等式。
- **"双变量"问题**：极值点偏移问题的处理（对数平均不等式、构造对称函数）；f(x₁) = f(x₂) 型问题通过"同构"转化。
- **同构思想**：把不等式两边化成同一函数形式（如 eˣ − x 与 ln x + 1/x 的关系），利用函数单调性简化，如 e^x + x > ln x + 1/x 可同构为 e^x + x > −ln(1/x) + 1/x。
- **恒成立问题的端点效应**：f(x) ≥ 0 对 x ≥ 0 恒成立，先看 f(0) = 0，则需 f'(0) ≥ 0，可先猜参数范围再严格证明，作为"先猜后证"的策略。
- 高考中函数导数解答题通常两到三问：第（1）问求导与单调区间，第（2）问求参数或证明不等式，第（3）问零点、极值点偏移等综合问题，训练时注意分层得分。

### 例题

已知函数 f(x) = x² − 2ax + 2 ln x（a ∈ R）。

（1）讨论 f(x) 的单调性；（2）若 f(x) 在 (0, +∞) 上恒有 f(x) ≥ 0，求 a 的取值范围。

解：（1）定义域为 (0, +∞)，f'(x) = 2x − 2a + 2/x = 2(x² − ax + 1)/x。

令 x² − ax + 1 = 0，记判别式 Δ = a² − 4。

当 Δ ≤ 0，即 −2 ≤ a ≤ 2 时，x² − ax + 1 ≥ 0 恒成立，f'(x) ≥ 0，f(x) 在 (0, +∞) 上单调递增。

当 Δ > 0 时，分 a > 2 与 a < −2 讨论：

a > 2 时，方程两根 x = (a ± √(a² − 4))/2 均为正，设 x₁ = (a − √(a² − 4))/2，x₂ = (a + √(a² − 4))/2，则 f(x) 在 (0, x₁) 与 (x₂, +∞) 上单调递增，在 (x₁, x₂) 上单调递减。

a < −2 时，两根均为负，不在定义域内，x² − ax + 1 > 0 恒成立，f(x) 在 (0, +∞) 上单调递增。

（2）由 f(1) = 1 − 2a ≥ 0 得 a ≤ 1/2，这是必要条件。

当 a ≤ 1/2 时，f'(x) = 2x − 2a + 2/x ≥ 2x − 1 + 2/x ≥ 2√(2x · 2/x) − 1 = 4 − 1 > 0（由 2x + 2/x ≥ 4 且 −2a ≥ −1），故 f(x) 单调递增，f(x) ≥ f(1) = 1 − 2a ≥ 0。

综上，a 的取值范围为 (−∞, 1/2]。

解析：含参讨论单调性先定定义域、再分类；第（2）问先由端点 f(1) 得到必要条件缩小范围，再证明充分性，是"必要性探路 + 充分性证明"的经典操作，可避免繁重的分类讨论。

## 本章小结与常见错误

1. 讨论单调性不先求定义域：如含 ln x 的函数直接在 R 上讨论，导致单调区间包含负数部分而错误。
2. 零点存在定理使用条件遗漏：忘记验证函数在区间端点处异号，或未说明函数连续、未用单调性保证唯一性。
3. 恒成立问题端点探路只猜不证：由 f(0) = 0 推出参数范围后不再证明充分性，或必要性找错点（端点不是临界位置）。
4. 构造辅助函数单调性判断错误：构造函数后对其求导，因复合函数求导错误或忽视定义域导致单调区间判断错误。

## 第2章 三角函数与数列专题

### 2.1 三角函数图象与性质

- **核心模型**：y = A sin(ωx + φ) + B 的图象变换（先平移后伸缩与先伸缩后平移的顺序差异）与性质（单调区间、最值、对称性、周期）。
- **由图象求解析式**：A = (最大值 − 最小值)/2，B = (最大值 + 最小值)/2，周期 T 由相邻对称轴、零点、最值点间距确定，φ 用"五点法"对应关系或代入特殊点求（注意取舍）。
- **图象变换的两条路径**：由 y = sin x 到 y = sin(ωx + φ)：先平移 φ 个单位再横坐标伸缩 1/ω；或先伸缩 1/ω 再平移 φ/ω 个单位。顺序不同，平移量不同。
- **三角函数的零点与对称性**：正弦型函数在对称轴处取最值、在对称中心处取零，可用于检验解析式；相邻零点间距为半周期。
- **单调区间求法**：令 ωx + φ 整体落入正弦函数的单调区间解不等式，注意 ω < 0 时先利用诱导公式化为正数，避免单调区间方向搞反。

### 2.2 解三角形

- **正弦定理**：a/sin A = b/sin B = c/sin C = 2R（R 为外接圆半径），适用"已知两角一边"与"已知两边一角（注意解的个数讨论）"。
- **余弦定理**：a² = b² + c² − 2bc cos A 及其变形 cos A = (b² + c² − a²)/(2bc)，适用"已知三边"与"已知两边夹角"。
- **三角形面积公式**：S = 1/2 ab sin C = 1/2 bc sin A = 1/2 ca sin B。结合正弦定理可得 S = abc/(4R) = 2R² sin A sin B sin C。
- **边角互化**：正弦定理把边化角（a = 2R sin A）或角化边（sin A = a/2R），是解三角形综合题的基本工具；余弦定理常用于"已知边的关系求角"。
- **实际应用**：测量距离、高度、角度问题（仰角、俯角、方位角、方向角），建立三角形模型求解；三角形解的个数问题用"大边对大角"判断。
- 综合题中常与基本不等式结合：已知角与对边求面积最值，或已知边和角的关系求周长取值范围，注意三角形内角和与边的不等关系约束。

### 2.3 数列通项与求和专题

- **通项公式的求法体系**：公式法（等差等比）、累加累乘、构造法（aₙ₊₁ = paₙ + q、aₙ₊₁ = paₙ + f(n) 型）、Sₙ 与 aₙ 关系法（aₙ = Sₙ − Sₙ₋₁，n ≥ 2）。
- **an 与 Sn 的递推转换**：已知 Sₙ 与 aₙ 的关系式，常用"Sₙ₋₁ 代 Sₙ"或"aₙ₊₁ = Sₙ₊₁ − Sₙ"消元化为只含 aₙ 的递推式。
- **求和方法体系**：公式法、分组求和、裂项相消（重点：1/[n(n+k)]、1/[(2n−1)(2n+1)]、√型有理化）、错位相减（等差×等比）、倒序相加（对称型）。
- **裂项技巧的变式**：分母含根号、含连乘、含组合数时灵活拆分；放缩法求和（证明数列不等式）常用"先放缩后裂项"。
- 错位相减的规范书写：设 Sₙ，乘公比得 qSₙ，错位相减，整理出 Sₙ = A + (Bn + C)qⁿ 形式，最后代 n = 1 检验。

### 2.4 数列综合与证明

- **等差数列与等比数列的判定**：用定义（aₙ₊₁ − aₙ 为常数、aₙ₊₁/aₙ 为常数）或中项性质证明；注意证明"不是等差/等比"只需举反例。
- **数列与不等式综合**：证明 a₁ + a₂ + … + aₙ < M 型不等式，常用裂项放缩、等比放缩（先缩后比）、累乘放缩等方法。
- **数列与函数综合**：数列作为离散函数，单调性可用作差或作商判断；数列的周期性（如 aₙ₊₂ = aₙ）用于求特定项。
- **数列的实际应用**：等差模型（单利、均匀变化）、等比模型（复利、增长率）、递推模型（aₙ₊₁ = paₙ + q 型应用题）。
- **压轴题常见结构**：已知 Sₙ 与 aₙ 递推，第一问求通项，第二问求前 n 项和，第三问证明不等式或研究最值，层层递进，注意前面结论为后面服务。

### 例题

在△ABC 中，内角 A、B、C 所对的边分别为 a、b、c，且 b² + c² − a² = bc。

（1）求角 A；（2）若 a = √3，求 △ABC 面积的最大值。

解：（1）由余弦定理 cos A = (b² + c² − a²)/(2bc) = bc/(2bc) = 1/2，又 A ∈ (0, π)，故 A = π/3。

（2）由余弦定理 a² = b² + c² − 2bc cos A，即 3 = b² + c² − bc。

由基本不等式 b² + c² ≥ 2bc，得 3 = b² + c² − bc ≥ 2bc − bc = bc，即 bc ≤ 3，当且仅当 b = c = √3 时等号成立。

所以 S = 1/2 bc sin A = 1/2 bc × √3/2 = √3 bc/4 ≤ 3√3/4，即 △ABC 面积的最大值为 3√3/4。

解析：本题是"解三角形 + 基本不等式求最值"的经典组合。第一问直接用余弦定理；第二问用余弦定理建立 b、c 的约束，再用基本不等式求 bc 的最大值。注意基本不等式等号成立条件（b = c，此时为等边三角形）是否满足题设。

## 本章小结与常见错误

1. 已知两边及其中一边的对角求角时不讨论解的个数：如 sin B 有两个可能值（B 与 π − B），需结合"大边对大角"或三角形内角和取舍。
2. 图象变换顺序混乱：先伸缩后平移时平移量未除以 ω，如 y = sin x 到 y = sin(2x + π/3) 应先向左平移 π/3 再横坐标缩 1/2，或先缩 1/2 再平移 π/6，混淆两者必错。
3. 错位相减相减后项数数错：两式相减后共有 n + 1 项，首尾各一项是单项，中间 n − 1 项是等比数列，整理时系数容易算错。
4. 解三角形用余弦定理时符号错误：cos A = (b² + c² − a²)/(2bc) 中分子是 b² + c² − a²，写成 a² − b² − c² 会导致角判断相反（A 与 π − A）。

## 第3章 几何专题

### 3.1 立体几何综合

- **知识主线**：空间中的平行（线线、线面、面面）与垂直（线线、线面、面面）判定与性质，构成立体几何证明的两大脉络。
- **平行关系的转化链**：线线平行 ⇄ 线面平行 ⇄ 面面平行，通过判定定理（由低维推高维）与性质定理（由高维降低维）互相转化。
- **垂直关系的转化链**：线线垂直（异面所成角 90°）→ 线面垂直（判定定理：与面内两条相交直线垂直）→ 面面垂直（判定定理：一个平面过另一个平面的垂线），性质定理反向使用。
- **证明的一般策略**：证明线面平行"找面内的平行线"（构造平行四边形、三角形中位线）；证明线面垂直"找面内两条相交直线"；辅助线常是连中点、作垂线。
- **几何体中的最值与展开问题**：最短路径（表面展开）、截面问题、球与多面体的组合（外接球、内切球），注意先定球心（外接球球心在过截面圆心的垂线上）。
- 三视图与直观图：三视图"长对正、高平齐、宽相等"；斜二测画法中平行性不变、长度减半。

### 3.2 空间向量方法专题

- **向量法解决平行与垂直**：线面平行（方向向量与法向量垂直 + 线不在面内）、面面平行（法向量共线）、线面垂直（方向向量与法向量共线）、面面垂直（法向量数量积为 0）。
- **空间角的向量公式**：异面直线角 cos θ = |a·b|/(|a||b|)；线面角 sin θ = |a·n|/(|a||n|)；二面角 cos θ = ±(n₁·n₂)/(|n₁||n₂|)（符号看图）。
- **距离的向量公式**：点面距 d = |PA·n|/|n|（A 为面内一点）；线面距、面面距转化为点面距；异面直线距离用公垂线方向向量求。
- **建系与取点的技巧**：优先利用垂直关系建系，让尽量多的点落在坐标轴或坐标平面上；中点、重心、三等分点坐标用向量或定比分点求。
- **答题规范**：解答题中"建系 → 求坐标 → 求向量 → 套公式 → 下结论"每一步都要写出关键步骤，法向量求解过程（设 n = (x, y, z)，列两个方程，取 z = 1）要清晰展示。

### 3.3 直线与圆、圆锥曲线综合

- **圆锥曲线的定义与方程**：椭圆（和定值 2a）、双曲线（差绝对值 2a）、抛物线（到焦点与准线等距），由定义求轨迹；标准方程用待定系数法。
- **直线与圆锥曲线的位置关系**：联立消元 → 判别式判断交点个数；弦长公式 |AB| = √(1 + k²)|x₁ − x₂|；注意直线与渐近线平行、与抛物线对称轴平行时的一次方程情形。
- **设而不求与韦达定理**：设交点 A(x₁, y₁)、B(x₂, y₂)，用韦达定理整体代换处理弦长、中点、垂直、面积等，是解析几何解答题的核心方法。
- **定点定值问题**：动直线过定点（含参数直线方程整理为"过定点的直线系"）、定值问题（先猜特殊位置再证明），常用"参数思想 + 消参"。
- **范围与最值问题**：转化为函数最值（一元二次函数、基本不等式）或几何意义（点到直线距离等），注意判别式对参数的约束。
- 圆锥曲线解答题通常第一问求方程（送分），第二问直线与曲线综合（定点定值、面积最值、存在性探究），计算能力与化简技巧（整体代入、消元）是得分关键。

### 3.4 解析几何中的常见题型

- **中点弦与点差法**：已知弦中点求直线方程或斜率，用点差法（代入相减），配合判别式检验存在性。
- **焦点弦与焦点三角形**：椭圆、双曲线中焦点三角形用定义 + 余弦定理求面积（椭圆 S = b² tan(θ/2)，双曲线 S = b² cot(θ/2)）；抛物线焦点弦长 x₁ + x₂ + p。
- **轨迹方程的求法**：直接法（几何条件直接翻译）、定义法（符合圆锥曲线定义直接用定义）、相关点法（代入法：动点由已知曲线上点确定）、参数法（引入参数消参）。
- **面积问题**：三角形面积 S = 1/2 |AB| · d（弦长乘点到直线距离），或 S = 1/2 |x₁y₂ − x₂y₁|（用向量叉积的模），选择简便形式。
- **探究性问题**："是否存在……使成立"先假设存在，用条件推出参数或点的坐标，若与条件矛盾则不存在，最后要写"存在"或"不存在"的结论。
- 解析几何运算量大，复习中要训练"会而不繁"：优先选择简洁设线方式（如设 x = my + n 避开斜率不存在讨论）、整体代换、先化简后代入。

### 例题

已知椭圆 C：x²/4 + y² = 1，过点 P(0, 1) 的直线 l 与椭圆交于 A、B 两点，求 △AOB（O 为坐标原点）面积的最大值。

解：显然直线 l 的斜率存在，设 l：y = kx + 1，A(x₁, y₁)、B(x₂, y₂)。

联立消 y 得 x²/4 + (kx + 1)² = 1，即 (1 + 4k²)x² + 8kx = 0。

x₁ + x₂ = −8k/(1 + 4k²)，x₁x₂ = 0（直线过点 (0, 1) 恰为椭圆短轴顶点，故 x = 0 是其中一个交点，即 x₁x₂ = 0 成立，另一根 x₂ = −8k/(1 + 4k²)）。

|x₁ − x₂| = |−8k/(1 + 4k²)|。

S = 1/2 · |OP| · |x₁ − x₂| = 1/2 × 1 × 8|k|/(1 + 4k²) = 4|k|/(1 + 4k²)。

由基本不等式 1 + 4k² ≥ 4|k|，得 S = 4|k|/(1 + 4k²) ≤ 4|k|/(4|k|) = 1，当且仅当 4k² = 1，即 k = ±1/2 时取等号。

故 △AOB 面积的最大值为 1。

解析：以 OP 为底、|x₁ − x₂| 为高求面积（因 O、P 在 y 轴上，横坐标差即为水平方向的高），避免了求弦长的复杂计算。本题直线过顶点使方程出现 x = 0 的根，简化了计算；若不过顶点，则需完整用韦达定理处理。最后用基本不等式求最值，注意取等条件检验。

## 本章小结与常见错误

1. 立体几何证明跳步：线面平行、垂直的判定中漏写"两条相交直线""平面内""线在面外"等关键条件，导致推理不完整扣分。
2. 空间角公式用错函数：线面角用 sin θ = |a·n|/(|a||n|)，二面角余弦正负符号不结合图形判断，直接写正导致结论错误。
3. 解析几何设直线不讨论斜率不存在：设 y = kx + b 默认斜率存在，对垂直于 x 轴的直线漏解；应优先设 x = my + n 形式避免讨论，或单独验证。
4. 韦达定理结果忘记代回判别式检验：由条件求出参数后未验证直线与曲线有两个交点（Δ > 0），产生增解。
