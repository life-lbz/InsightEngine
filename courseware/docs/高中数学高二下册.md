## 第1章 数列

### 1.1 数列的概念与表示

- **数列定义**：按照确定的顺序排列的一列数叫做数列，数列中的每个数叫这个数列的项。数列可以看成以正整数集 N* 为定义域的函数，即数列是一种特殊的函数（离散型）。
- **通项公式**：数列 {aₙ} 的第 n 项 aₙ 与序号 n 之间的关系式叫通项公式，如 aₙ = 2n − 1。通项公式不是唯一的表示方式，也并非所有数列都有通项公式。
- **递推公式**：用数列中相邻项之间的关系表示数列的方法，如 a₁ = 1，aₙ₊₁ = aₙ + 2。已知递推公式和初始值，可以逐项求出数列的任意一项，也可以设法归纳出通项公式。
- 数列的分类：按项数分为有穷数列与无穷数列；按项的大小变化分为递增数列、递减数列、常数列、摆动数列。判断数列单调性可用 aₙ₊₁ − aₙ 的符号或 aₙ₊₁/aₙ 与 1 的关系（各项为正时）。
- 由前 n 项和 Sₙ 求通项：aₙ = Sₙ − Sₙ₋₁（n ≥ 2），a₁ = S₁；求得的通项若 n = 1 时不满足 n ≥ 2 的表达式，需分段表示。

### 1.2 等差数列

- **定义**：从第 2 项起，每一项与前一项的差等于同一个常数 d 的数列叫等差数列，d 叫公差。递推形式：aₙ₊₁ − aₙ = d。
- **通项公式**：aₙ = a₁ + (n − 1)d，可变形为 aₙ = aₘ + (n − m)d。通项公式是关于 n 的一次函数（d ≠ 0 时）。
- **前 n 项和公式**：Sₙ = n(a₁ + aₙ)/2 = na₁ + n(n − 1)d/2。Sₙ 是关于 n 的二次函数（d ≠ 0 时，常数项为 0），可借助二次函数研究最值。
- **中项性质**：a、A、b 成等差数列 ⟺ A = (a + b)/2（A 叫等差中项）。若 m + n = p + q，则 aₘ + aₙ = aₚ + a_q。
- **常用结论**：等差数列中连续等长的项（如 a₁, a₃, a₅…或每 k 项一组）仍构成等差数列；Sₙ、S₂ₙ − Sₙ、S₃ₙ − S₂ₙ 成等差数列，公差为 n²d。
- 前 n 项和的最值：d > 0 时 Sₙ 有最小值，d < 0 时 Sₙ 有最大值，可通过"找变号项"（aₙ ≥ 0 且 aₙ₊₁ ≤ 0）或二次函数对称轴确定。

### 1.3 等比数列

- **定义**：从第 2 项起，每一项与前一项的比等于同一个常数 q（q ≠ 0）的数列叫等比数列，q 叫公比。递推形式：aₙ₊₁/aₙ = q。等比数列中任何一项都不为 0，公比不为 0。
- **通项公式**：aₙ = a₁q^(n−1)，可变形为 aₙ = aₘq^(n−m)。
- **前 n 项和公式**：q = 1 时 Sₙ = na₁；q ≠ 1 时 Sₙ = a₁(1 − qⁿ)/(1 − q) = (a₁ − aₙq)/(1 − q)。求和时必须先判断 q 是否等于 1。
- **中项性质**：a、G、b 成等比数列 ⟺ G² = ab（G 叫等比中项，G = ±√(ab)，注意符号）。若 m + n = p + q，则 aₘaₙ = aₚa_q。
- **常用结论**：等比数列中连续等长的项仍成等比数列；Sₙ、S₂ₙ − Sₙ、S₃ₙ − S₂ₙ 成等比数列，公比为 qⁿ；各项均为正数时对数后变为等差数列。
- 等比数列与等差数列的转化：{log_a aₙ}（aₙ > 0）为等差数列；{a^(bₙ)}（bₙ 为等差数列）为等比数列，两类数列常相互转化研究。

### 1.4 数列通项与求和

- **求通项的常用方法**：公式法（等差、等比直接用）；累加法（aₙ₊₁ − aₙ = f(n) 型）；累乘法（aₙ₊₁/aₙ = f(n) 型）；构造法（aₙ₊₁ = paₙ + q 型，构造 aₙ₊₁ + t = p(aₙ + t) 转化为等比数列）；Sn 与 an 关系法。
- **错位相减法**：适用于"等差数列 × 等比数列"型数列（如 aₙ = n·2ⁿ），先写出 Sₙ，再两边同乘公比 q，两式相减整理求和。这是高考数列解答题的高频考法。
- **裂项相消法**：把通项拆成两项之差，如 1/[n(n+1)] = 1/n − 1/(n+1)，1/[(2n−1)(2n+1)] = 1/2 · [1/(2n−1) − 1/(2n+1)]，1/(√n + √(n+1)) = √(n+1) − √n，相加后中间项抵消。
- **分组求和法**：通项由几个简单数列的和构成时，分组分别求和；并项求和用于正负交替的数列；倒序相加法用于首末对称的数列（如推导等差数列求和公式的方法）。
- 数列综合题中，证明"aₙ₊₁ = paₙ + q"型数列构造等比数列，证明数列不等式常用放缩法（如先裂项再放缩）。

### 例题

已知数列 {aₙ} 满足 a₁ = 1，aₙ₊₁ = 2aₙ + 1（n ∈ N*）。

（1）证明数列 {aₙ + 1} 是等比数列；（2）求数列 {aₙ} 的通项公式与前 n 项和 Sₙ。

解：（1）由 aₙ₊₁ = 2aₙ + 1，两边同加 1 得 aₙ₊₁ + 1 = 2aₙ + 2 = 2(aₙ + 1)。

又 a₁ + 1 = 2 ≠ 0，故数列 {aₙ + 1} 是以 2 为首项、2 为公比的等比数列。

（2）由（1）得 aₙ + 1 = 2 × 2^(n−1) = 2ⁿ，故 aₙ = 2ⁿ − 1。

所以 Sₙ = (2 + 2² + … + 2ⁿ) − n = 2(2ⁿ − 1)/(2 − 1) − n = 2ⁿ⁺¹ − 2 − n。

解析：构造法是"aₙ₊₁ = paₙ + q（p ≠ 1）"型递推式的标准解法：设 aₙ₊₁ + t = p(aₙ + t)，比较系数得 t = q/(p − 1)。本题 t = 1，两边同加 1 后形成等比数列。求和时把通项拆成等比部分与常数部分分组求和。

## 本章小结与常见错误

1. 等比数列求和忘记讨论 q = 1：直接用 Sₙ = a₁(1 − qⁿ)/(1 − q)，分母为零导致错误，必须先讨论公比是否为 1。
2. 用 Sₙ 求 aₙ 时丢 n = 1 的情形：只写 aₙ = Sₙ − Sₙ₋₁（n ≥ 2）而不单独验证 a₁，或验证后不分段表示。
3. 错位相减时错位、漏项：乘公比后的式子没有错开一位对齐，或相减时最后一项符号处理错误、项数统计错误。
4. 等差数列前 n 项和最值判断失误：把"aₙ ≥ 0"与"Sₙ 最大"混为一谈，d < 0 时应找"由正变负"的项，而不是看 aₙ 的绝对值。

## 第2章 导数及其应用

### 2.1 导数的概念与运算

- **平均变化率与瞬时变化率**：函数 y = f(x) 从 x₀ 到 x₀ + Δx 的平均变化率为 Δy/Δx = [f(x₀ + Δx) − f(x₀)]/Δx；当 Δx → 0 时的极限叫 f(x) 在 x₀ 处的导数，记作 f'(x₀)，即 f'(x₀) = lim(Δx→0) [f(x₀ + Δx) − f(x₀)]/Δx。
- **导数的几何意义**：f'(x₀) 是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率，切线方程为 y − f(x₀) = f'(x₀)(x − x₀)。"过某点"与"在某点"的切线含义不同：过点 (a, b) 的切线，切点可能不是 (a, b)，需设切点求参数。
- **基本初等函数的导数公式**：(x^α)' = αx^(α−1)，(sin x)' = cos x，(cos x)' = −sin x，(eˣ)' = eˣ，(aˣ)' = aˣ ln a，(ln x)' = 1/x，(log_a x)' = 1/(x ln a)，(C)' = 0。
- **求导法则**：四则运算 (u ± v)' = u' ± v'，(uv)' = u'v + uv'，(u/v)' = (u'v − uv')/v²；复合函数求导法则（链式法则）：y = f(g(x))，则 y' = f'(g(x)) · g'(x)，如 (ln(2x + 1))' = 2/(2x + 1)。
- 求导是后续单调性、极值、最值分析的基础，求导结果的正确性直接决定整道题，必须熟练掌握公式与法则。

### 2.2 导数与函数的单调性

- **判断单调性**：在区间 D 上，若 f'(x) > 0，则 f(x) 在 D 上单调递增；若 f'(x) < 0，则 f(x) 在 D 上单调递减。注意：f'(x) ≥ 0 且 f'(x) 不恒等于 0 时函数单调递增。
- **求单调区间步骤**：确定定义域 → 求导 f'(x) → 解不等式 f'(x) > 0（增区间）、f'(x) < 0（减区间）。所得区间必须限制在定义域内，多个单调区间用"和"或逗号连接，不能用"∪"。
- **已知单调性求参数**：函数在某区间上单调递增 ⟺ f'(x) ≥ 0 在该区间恒成立（且等号不恒成立），常转化为不等式恒成立问题求参数范围。
- 含参数的单调性讨论：对参数分类讨论，常见分类依据有二次项系数符号、判别式、两根大小比较，讨论要"不重不漏"。
- 具体函数如 f(x) = eˣ − ax 的单调性，转化为 eˣ > a 与 eˣ < a 的解集，体现导数与指数、对数函数结合的综合性。

### 2.3 函数的极值与最值

- **极值的概念**：函数在 x₀ 附近取得最大值（或最小值）的局部性质，极大值、极小值统称极值，x₀ 叫极值点。极大值与极小值没有必然的大小关系，极小值可能大于极大值。
- **极值的判定**：若 f'(x) 在 x₀ 两侧由正变负，则 x₀ 为极大值点；由负变正，则 x₀ 为极小值点；符号不变则 x₀ 不是极值点。f'(x₀) = 0 是 x₀ 为极值点的必要不充分条件（如 f(x) = x³ 在 0 处）。
- **求极值步骤**：求定义域与导数 → 解 f'(x) = 0 得驻点 → 列表判断驻点两侧导数的符号 → 写出极值。
- **闭区间上的最值**：先求开区间内的极值，再与端点函数值比较，最大者为最大值，最小者为最小值。含参最值问题需对参数分类讨论。
- **实际应用**：优化问题（利润最大、成本最低、容积最大等）通过建立目标函数、求导求最值解决，注意自变量的实际取值范围与端点取舍。

### 2.4 导数的综合应用

- **不等式证明**：证明 f(x) > g(x)，常构造函数 h(x) = f(x) − g(x)，证明 h(x)_min > 0；或利用不等式放缩（如 ln x ≤ x − 1，eˣ ≥ x + 1）。
- **恒成立与存在性问题**：f(x) ≥ a 恒成立 ⟺ f(x)_min ≥ a；存在 x 使 f(x) ≥ a ⟺ f(x)_max ≥ a。常用分离参数法：分离出参数 a 后求另一函数的最值。
- **函数零点问题**：函数零点个数问题转化为方程 f(x) = 0 的根或两函数图象交点个数问题；利用导数研究函数单调性与极值，结合零点存在定理判断零点个数。
- **含参讨论的常见题型**：已知极值点个数求参数、已知最值求参数、已知零点个数求参数等，核心是"图象交点个数 ↔ 方程根的个数 ↔ 函数零点个数"三者的转化。
- 导数压轴题的常见结构：第一问求单调区间或极值（送分），第二问不等式证明或恒成立求参数，第三问零点或综合探究。

### 例题

已知函数 f(x) = x − 1 − ln x。

（1）求 f(x) 的单调区间与极小值；（2）证明：当 x > 0 时，x − 1 ≥ ln x。

解：（1）定义域为 (0, +∞)，f'(x) = 1 − 1/x = (x − 1)/x。

令 f'(x) = 0 得 x = 1。当 0 < x < 1 时 f'(x) < 0，当 x > 1 时 f'(x) > 0。

故 f(x) 的单调递减区间为 (0, 1)，单调递增区间为 (1, +∞)，极小值为 f(1) = 0（也是最小值）。

（2）由（1）知 f(x) ≥ f(1) = 0，即 x − 1 − ln x ≥ 0，故当 x > 0 时，x − 1 ≥ ln x，等号当且仅当 x = 1 时成立。

解析：第（1）问是导数基本流程；第（2）问"证明不等式"通过构造函数 f(x) = x − 1 − ln x，把原不等式转化为证明函数最小值非负。结论 ln x ≤ x − 1（x > 0）是重要的不等式放缩工具，可在此基础上推广得到 ln x ≤ x − 1 与 eˣ ≥ x + 1 等常用放缩链。

## 本章小结与常见错误

1. 复合函数求导漏乘内层导数：如 (e^(2x))' 误写成 e^(2x)，正确为 2e^(2x)；或 (ln(3x + 1))' 漏掉内层导数 3。
2. 极值点判定错误：仅由 f'(x₀) = 0 就断言 x₀ 是极值点，忽略两侧符号变化；如 f(x) = x³ 在 0 处导数为 0 但不是极值点。
3. 单调区间合并用"∪"：函数在不同区间上分别单调时不能用并集符号连接，如 f(x) = 1/x 的单调递减区间应写成 (−∞, 0) 和 (0, +∞)。
4. 求切线混淆"在点处"与"过点"：求过曲线外一点的切线时，直接把该点当切点代入切线方程，导致漏解；必须设切点 (x₀, f(x₀)) 建立方程求解。

## 第3章 计数原理与概率统计

### 3.1 两个计数原理

- **分类加法计数原理**：完成一件事有 n 类不同方案，第 k 类方案中有 mₖ 种不同方法，则完成这件事共有 N = m₁ + m₂ + … + mₙ 种方法。"分类"要求各类方案相互独立、不重不漏。
- **分步乘法计数原理**：完成一件事需要分成 n 个步骤，第 k 步有 mₖ 种不同方法，则完成这件事共有 N = m₁ × m₂ × … × mₙ 种方法。"分步"要求各步骤相互依存，缺一不可。
- 两个原理的根本区别：分类用"加法"（一步到位），分步用"乘法"（逐步完成）。实际问题中常"先分类后分步"。
- 典型应用：数字组成问题（含特殊数字位置限制）、涂色问题、分配问题、路径问题等，注意 0 不能在首位、元素不能重复使用等限制条件。

### 3.2 排列与组合

- **排列**：从 n 个不同元素中取出 m（m ≤ n）个元素，按照一定的顺序排成一列，叫排列。排列数 A(n, m) = n(n − 1)…(n − m + 1) = n!/(n − m)!。全排列 A(n, n) = n!。
- **组合**：从 n 个不同元素中取出 m（m ≤ n）个元素组成一组，与顺序无关，叫组合。组合数 C(n, m) = A(n, m)/m! = n!/[m!(n − m)!]。
- **组合数性质**：C(n, m) = C(n, n − m)，C(n, m) + C(n, m + 1) = C(n + 1, m + 1)（组合数递推公式，用于化简）。
- **排列组合应用题的常见方法**：特殊元素优先安排、相邻问题捆绑法、不相邻问题插空法、定序问题倍缩法、分组分配问题（先分组后分配，均匀分组要除以组数的阶乘）、间接法（正难则反）。
- 排列与组合的区别核心是"是否有顺序"：有顺序用排列，无顺序用组合。如"选 3 人担任 3 个不同职务"是排列，"选 3 人参加活动"是组合。

### 3.3 二项式定理

- **二项式定理**：(a + b)ⁿ = Σ C(n, k) a^(n−k) b^k，k = 0 到 n，其中 C(n, k) 叫二项式系数。展开式共 n + 1 项，a 的指数从 n 降到 0，b 的指数从 0 升到 n，各项指数之和为 n。
- **通项公式**：T(k+1) = C(n, k) a^(n−k) b^k（第 k + 1 项）。求特定项（如常数项、含 x^m 的项、有理项）时，由通项公式列出关于 k 的方程求解。
- **二项式系数的性质**：对称性 C(n, k) = C(n, n − k)；二项式系数先增后减，中间项最大（n 为偶数时中间一项最大，n 为奇数时中间两项相等且最大）；C(n, 0) + C(n, 1) + … + C(n, n) = 2ⁿ。
- **赋值法**：令 a = b = 1 得各项系数和；令 a = 1，b = −1 得奇数项与偶数项系数之差等，用于求展开式的系数和问题。
- 区分"二项式系数"与"项的系数"：C(n, k) 是二项式系数，(a + b)ⁿ 展开式中某项的系数还包含 a、b 前面的系数，如 (1 + 2x)ⁿ 的 x^k 项系数是 C(n, k)·2^k。

### 3.4 随机变量及其分布

- **随机变量**：随机试验结果的变量表示，如掷骰子的点数 X。离散型随机变量取值可以一一列出。
- **分布列**：X 取各个可能值 xᵢ 的概率 pᵢ，满足 pᵢ ≥ 0 且 Σ pᵢ = 1。求分布列的步骤：确定取值 → 求概率 → 列分布列并检验概率和为 1。
- **两点分布与二项分布**：两点分布 X ~ B(1, p)；n 次独立重复试验中事件发生 k 次的概率 P(X = k) = C(n, k) p^k (1 − p)^(n−k)，X ~ B(n, p) 叫二项分布。
- **超几何分布**：从含 M 个次品的 N 件产品中不放回取 n 件，次品数 X 的分布 P(X = k) = C(M, k)C(N − M, n − k)/C(N, n)，用于不放回抽样。
- **期望与方差**：E(X) = Σ xᵢpᵢ，D(X) = Σ (xᵢ − E(X))²pᵢ。E(aX + b) = aE(X) + b，D(aX + b) = a²D(X)。二项分布 E(X) = np，D(X) = np(1 − p)。
- **统计案例**：成对数据的相关关系（散点图、相关系数 r）、一元线性回归模型（最小二乘法求回归方程）、独立性检验（2×2 列联表与卡方检验），是新课标强调的实际应用内容。

### 例题

某射击运动员每次射击命中目标的概率为 3/4，各次射击相互独立。记 X 为射击 4 次命中目标的次数。

（1）求 P(X = 3)；（2）求 X 的分布列、期望与方差。

解：（1）X ~ B(4, 3/4)，P(X = 3) = C(4, 3) × (3/4)³ × (1/4) = 4 × 27/64 × 1/4 = 27/64。

（2）分布列：P(X = k) = C(4, k)(3/4)^k (1/4)^(4−k)，k = 0, 1, 2, 3, 4。

E(X) = np = 4 × 3/4 = 3，D(X) = np(1 − p) = 4 × 3/4 × 1/4 = 3/4。

解析：独立重复试验中事件发生次数服从二项分布，直接用二项分布公式计算概率，期望、方差可直接套用公式 E(X) = np、D(X) = np(1 − p)，避免逐一列出分布列再按定义计算，提高效率且不易出错。

## 本章小结与常见错误

1. 排列与组合混淆：凡是与"顺序"有关的（职务安排、排队、组数等）用排列，与顺序无关的（选人、选物）用组合；题目中"从中选 3 名同学参加三科竞赛"与"选 3 名同学参加活动"计算方法不同。
2. 均匀分组忘记除序：把 6 人分成三组，每组 2 人，若按 C(6,2)C(4,2)C(2,2) 计算会多乘 3!，均匀分组必须除以组数的阶乘。
3. 二项式系数与项的系数混用：求 (1 + 2x)⁵ 的 x² 项系数时直接写 C(5,2)，漏掉 2² 的因子，正确为 C(5,2)·2² = 40。
4. 分布列概率和不为 1 不检验：列完分布列后未验证 Σ pᵢ = 1，概率计算错误未被及时发现；或求期望、方差时把 np 公式套用到非二项分布问题。
