# 高中化学高一上册课程讲义
课程编号：senior_chemistry_g10s1　适用学段：高中　年级：高一　学期：上学期

本册讲义对应人教版高中化学必修第一册，是全册高中化学的起点。本册以"物质分类—离子反应—氧化还原反应"为主线建立化学学科的基本观念，并以钠及其化合物为载体示范"结构决定性质、性质决定用途"的元素化学学习范式。学好本册内容，将为后续元素化学（氯、硫、氮等）与化学反应原理打下坚实基础。

## 第一章 物质及其变化

> 本章核心：学会用分类的观点认识物质，掌握电解质与非电解质、离子反应及离子方程式的基本规律。

### 1.1 物质的分类与分散系

物质分类有两种基本方法：**树状分类法**（按层次逐级展开，如 纯净物 → 化合物 → 酸/碱/盐/氧化物）与**交叉分类法**（同一物质按不同标准可归入不同类别，如 Na₂SO₄ 既是钠盐又是硫酸盐）。

**分散系**是由分散质和分散剂组成的混合物体系，按分散质粒子直径大小分为三类：溶液（<1 nm）、胶体（1~100 nm）、浊液（>100 nm）。胶体具有**丁达尔效应**（用一束光照射胶体时，在垂直于光线的方向可观察到一条光亮的"通路"，这是区分胶体与溶液的常用方法）、**布朗运动**和电泳现象。向 Fe(OH)₃ 胶体中加入电解质溶液或加热，胶体粒子聚集成大颗粒而沉降，称为聚沉，如豆浆中加盐卤制成豆腐。

制备 Fe(OH)₃ 胶体的反应：向沸水中滴加饱和 FeCl₃ 溶液并继续煮沸至液体呈红褐色：

FeCl₃ + 3H₂O =Fe(OH)₃（胶体）+ 3HCl

### 1.2 电解质与非电解质

在水溶液里或熔融状态下能够导电的化合物叫做**电解质**，如酸、碱、盐、活泼金属氧化物（Na₂O、CaO 等）；在上述条件下均不能导电的化合物叫做**非电解质**，如蔗糖、酒精、CO₂、SO₂ 等。判断时要注意：单质和混合物既不是电解质也不是非电解质；CO₂、SO₂、NH₃ 的水溶液虽能导电，但导电原因是它们与水反应生成的 H₂CO₃、H₂SO₃、NH₃·H₂O 电离所致，故它们本身是非电解质。

电解质在水溶液中（或熔融状态下）离解成自由移动离子的过程叫**电离**，可用电离方程式表示：

- HCl = H⁺ + Cl⁻
- NaOH = Na⁺ + OH⁻
- Na₂SO₄ = 2Na⁺ + SO₄²⁻

电解质按电离程度分为强电解质（完全电离，如强酸、强碱、绝大多数盐）与弱电解质（部分电离，如弱酸 CH₃COOH、H₂CO₃，弱碱 NH₃·H₂O、水）。

### 1.3 离子反应与离子方程式

在溶液中（或熔融状态下）有离子参加或生成的反应称为**离子反应**。离子反应发生的条件（复分解型）：生成沉淀、生成气体、生成难电离物质（弱酸、弱碱或水），三者满足其一即可发生。

用实际参加反应的离子符号表示化学反应的式子叫**离子方程式**。书写步骤：写（写出化学方程式）→ 拆（把易溶于水且易电离的物质拆成离子，单质、气体、难溶物、难电离物、氧化物一律保留化学式）→ 删（删去两边不参加反应的离子）→ 查（检查原子守恒与电荷守恒）。

典型离子方程式：

- 盐酸与 NaOH 反应：H⁺ + OH⁻ = H₂O
- 盐酸与 Na₂CO₃ 反应：CO₃²⁻ + 2H⁺ = H₂O + CO₂↑
- 硫酸铜溶液与氢氧化钡溶液反应：Cu²⁺ + SO₄²⁻ + Ba²⁺ + 2OH⁻ = BaSO₄↓ + Cu(OH)₂↓（两个沉淀都需写出）

### 例题

**题目**：写出下列反应的离子方程式，并判断能否发生离子反应：(1) 澄清石灰水中通入少量 CO₂；(2) NaHCO₃ 溶液与稀盐酸反应。

**解析**：(1) 澄清石灰水主要成分 Ca(OH)₂，通入少量 CO₂ 生成 CaCO₃ 沉淀，化学方程式为 Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O，改写成离子方程式：Ca²⁺ + 2OH⁻ + CO₂ = CaCO₃↓ + H₂O（注意 CO₂ 是气体，保留化学式）。(2) NaHCO₃ 为易溶强电解质拆为 Na⁺ 与 HCO₃⁻，HCO₃⁻ 是弱酸酸式酸根，不拆为 H⁺ 和 CO₃²⁻，与盐酸反应的离子方程式为 HCO₃⁻ + H⁺ = H₂O + CO₂↑。两反应分别有沉淀和气体生成，均能发生。

## 本章小结与常见错误

1. 常见错误：把 CO₂、SO₂、NH₃ 误判为电解质。它们的水溶液导电是因为生成了新物质，本身是非电解质；判断电解质应看其自身能否电离。
2. 常见错误：离子方程式"拆"得不当。如将 CaCO₃、难溶碱 Cu(OH)₂ 拆成离子，或将弱电解质 H₂CO₃、NH₃·H₂O 完全拆开；应牢记"强酸强碱可溶性盐才拆"。
3. 常见错误：忽略电荷守恒。如写 Cu + Ag⁺ = Cu²⁺ + Ag，左右电荷不守恒，正确为 Cu + 2Ag⁺ = Cu²⁺ + 2Ag。
4. 常见错误：NaHCO₃ 电离方程式写成 NaHCO₃ = Na⁺ + H⁺ + CO₃²⁻。碳酸氢根是弱酸酸式酸根，电离方程式应为 NaHCO₃ = Na⁺ + HCO₃⁻。

## 第二章 氧化还原反应

> 本章核心：从化合价升降与电子转移两个层面认识氧化还原反应，掌握氧化剂、还原剂的概念与方程式配平方法。

### 2.1 氧化还原反应的概念与本质

凡有元素化合价升降的化学反应都是**氧化还原反应**。**本质**是电子的转移（得失或偏移），化合价升降是电子转移的外在表现。判断一个反应是否为氧化还原反应，只需看反应前后是否有元素化合价变化。

在氧化还原反应中：化合价升高的物质是**还原剂**（被氧化，发生氧化反应，产物为氧化产物）；化合价降低的物质是**氧化剂**（被还原，发生还原反应，产物为还原产物）。口诀："升失氧、降得还"（化合价升高、失电子、被氧化；化合价降低、得电子、被还原）。

四类基本反应与氧化还原反应的关系：置换反应全部是氧化还原反应；复分解反应全部不是氧化还原反应；化合反应与分解反应不一定是氧化还原反应（有单质参加或生成时才是）。

### 2.2 氧化剂、还原剂与电子转移的表示

**双线桥法**表示电子转移：在反应物和生成物之间分别用两条线标出同种元素化合价的变化，注明"得（失）2e⁻"并标明"被还原（被氧化）"。**单线桥法**表示电子转移方向：箭头从还原剂中失电子的元素指向氧化剂中得电子的元素，只在箭头上标出电子总数（不标"得/失"）。

例：Zn + 2HCl = ZnCl₂ + H₂↑，Zn 失去 2e⁻ 被氧化（作还原剂），H 得 2e⁻ 被还原（HCl 作氧化剂）。氧化性：氧化剂 > 氧化产物；还原性：还原剂 > 还原产物，据此可比较物质氧化性、还原性强弱。

常见氧化剂：O₂、Cl₂、浓 H₂SO₄、HNO₃、KMnO₄、FeCl₃ 等；常见还原剂：活泼金属、C、H₂、CO、SO₂、Fe²⁺、I⁻ 等。处于中间价态的元素（如 S、Fe²⁺）既可作氧化剂又可作还原剂。

### 2.3 氧化还原反应方程式的配平

依据：氧化还原反应中**化合价升降总数相等**（电子得失守恒）。配平步骤（化合价升降法）：①标出变价元素化合价；②求出升降价的最小公倍数，确定氧化剂、还原剂的化学计量数；③用观察法配平其他物质；④检查各元素原子守恒与电荷守恒。

例如配平铜与稀硝酸反应：Cu + HNO₃（稀）→ Cu(NO₃)₂ + NO↑ + H₂O。Cu 升 2 价，N 由 +5 降为 +2 降 3 价，最小公倍数为 6，故 Cu 计 3、NO 计 2，得 3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（其中 6 mol HNO₃ 作酸、2 mol 作氧化剂）。

### 例题

**题目**：配平方程式：KMnO₄ + HCl（浓）→ KCl + MnCl₂ + Cl₂↑ + H₂O，并指出氧化剂与还原剂。

**解析**：Mn 由 +7 降为 +2，降低 5 价；Cl 由 -1 升为 0，升高 1 价，但 2 个 Cl⁻ 生成 1 个 Cl₂，升降最小公倍数为 5，故 KMnO₄ 配 2、Cl₂ 配 5：2KMnO₄ + 16HCl（浓）= 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O。氧化剂是 KMnO₄，还原剂是 HCl（注意 HCl 部分作还原剂、部分作酸，起酸性作用的 HCl 为 6 mol，作还原剂的是 10 mol）。

## 本章小结与常见错误

1. 常见错误：认为"有氧参加的反应才是氧化还原反应"。判断标准是化合价是否变化，如 H₂ + Cl₂ 点燃 2HCl 无氧参与，仍是氧化还原反应。
2. 常见错误：氧化剂与还原剂混淆。要抓"升失氧、降得还"，化合价升高的是还原剂而非氧化剂。
3. 常见错误：配平只配原子不查电子守恒。如配平后左右电荷不相等；必须确保化合价升降总数相等。
4. 常见错误：把 HCl 全部当作还原剂。在 KMnO₄ 与浓盐酸反应中，HCl 只有部分被氧化，另一部分起酸性作用。

## 第三章 钠及其化合物

> 本章核心：以钠为典型金属，学习活泼金属单质、氧化物、盐的性质，掌握过氧化钠的强氧化性及碳酸钠与碳酸氢钠的转化。

### 3.1 钠的性质

钠是银白色、质软的金属，密度比水小（0.97 g/cm³），熔点低（97.8 ℃），导电导热性好。钠是活泼金属，具有很强的还原性。

- 与 O₂ 反应：常温下 4Na + O₂ = 2Na₂O（白色）；点燃时 2Na + O₂ 点燃 Na₂O₂（淡黄色）。
- 与水反应：2Na + 2H₂O = 2NaOH + H₂↑，现象可概括为"浮、熔、游、响、红"（浮在水面、熔成小球、四处游动、发出嘶嘶响声、滴入酚酞变红，说明生成碱性物质）。
- 与盐溶液反应时先与水反应：如钠投入 CuSO₄ 溶液中，2Na + 2H₂O = 2NaOH + H₂↑，CuSO₄ + 2NaOH = Cu(OH)₂↓ + Na₂SO₄，放出氢气并生成蓝色沉淀。
- 与 Cl₂、S 等非金属反应：2Na + Cl₂ 点燃 2NaCl；2Na + S = Na₂S（研磨或加热）。

实验室中钠保存在**煤油**中以隔绝空气和水。取用时用镊子夹取，吸干表面煤油，剩余钠放回原瓶，不可乱丢。

### 3.2 钠的氧化物：氧化钠与过氧化钠

| 氧化物 | 氧化钠 Na₂O | 过氧化钠 Na₂O₂ |
| --- | --- | --- |
| 颜色 | 白色 | 淡黄色 |
| 氧元素化合价 | -2 | -1 |
| 与水反应 | Na₂O + H₂O = 2NaOH | 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ |
| 与 CO₂ 反应 | Na₂O + CO₂ = Na₂CO₃ | 2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂ |

过氧化钠中 Na⁺ 与 O₂²⁻ 个数比为 2∶1，O₂²⁻ 中氧为 -1 价，既表现氧化性又有还原性。上述两个反应中过氧化钠既是氧化剂又是还原剂，每 2 mol Na₂O₂ 参与反应转移 2 mol 电子。过氧化钠可用作呼吸面具和潜水艇中的供氧剂、漂白剂等。

### 3.3 碳酸钠与碳酸氢钠、焰色反应

碳酸钠（Na₂CO₃，俗称纯碱、苏打）与碳酸氢钠（NaHCO₃，俗称小苏打）均为白色固体，都易溶于水（Na₂CO₃ 溶解度更大）。

- 热稳定性：Na₂CO₃ 稳定受热不分解；2NaHCO₃ 加热 Na₂CO₃ + H₂O + CO₂↑。
- 与盐酸反应：Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑（反应分两步，先生成 NaHCO₃，放出气体慢）；NaHCO₃ + HCl = NaCl + H₂O + CO₂↑（放出气体快）。
- 相互转化：Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃；NaHCO₃ + NaOH = Na₂CO₃ + H₂O（或加热）。
- 鉴别方法：加热法（NaHCO₃ 分解产生气体使澄清石灰水变浑浊）或滴加盐酸观察放出气体快慢。

**焰色反应**是元素的物理性质（不是化学变化），用于检验钠、钾等元素：钠的焰色为黄色，钾的焰色为紫色（观察钾的焰色需透过蓝色钴玻璃，以滤去钠的黄光）。操作步骤：洗（盐酸洗净铂丝）→ 烧（灼烧至无色）→ 蘸 → 烧 → 观察。

### 例题

**题目**：向 100 mL 0.5 mol/L 的 NaOH 溶液中通入一定量 CO₂，充分反应后所得溶液中加入足量盐酸，共收集到标准状况下气体 0.448 L。求通入 CO₂ 的质量。

**解析**：n(NaOH) = 0.5 × 0.1 = 0.05 mol。加盐酸放出气体说明产物中有 NaHCO₃（或 Na₂CO₃ 与 NaHCO₃ 混合物）。n(CO₂) = 0.448/22.4 = 0.02 mol。由碳守恒知 n(CO₂ 通入) = n(CO₂ 放出) = 0.02 mol，m(CO₂) = 0.02 × 44 = 0.88 g。本题关键：加足量盐酸后放出的 CO₂ 全部来自原溶液中含碳物质，利用碳元素守恒快速求解。

## 本章小结与常见错误

1. 常见错误：认为 Na₂O₂ 中钠为 +1 价、氧为 -2 价。过氧化钠中氧为 -1 价，含 O₂²⁻，故 Na₂O₂ 不是碱性氧化物。
2. 常见错误：把 Na₂O₂ 与 H₂O、CO₂ 的反应误判为置换反应或复分解反应。它们是氧化还原反应，Na₂O₂ 既作氧化剂又作还原剂。
3. 常见错误：认为 Na₂CO₃ 与盐酸反应立即大量放气。盐酸少量时先生成 NaHCO₃，CO₃²⁻ + H⁺ = HCO₃⁻，只有盐酸足量时才放出 CO₂。
4. 常见错误：用焰色反应判断物质成分时忽略钠黄光的干扰。检验钾元素必须透过蓝色钴玻璃观察。
