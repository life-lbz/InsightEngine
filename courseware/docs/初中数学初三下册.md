## 第1章 反比例函数

### 1.1 反比例函数的概念

- **反比例函数**：一般地，形如 y = k/x（k 为常数，k ≠ 0）的函数叫做反比例函数，其中 x 是自变量，y 是 x 的函数，自变量 x 的取值范围是 x ≠ 0 的一切实数。
- 反比例函数的等价形式：y = k/x（k ≠ 0）可以写成 xy = k（k ≠ 0）或 y = k·x⁻¹，三种形式要能灵活转化。判断是否为反比例函数，关键是能否化成 y = k/x（k ≠ 0）的形式。
- 反比例函数中 k 的取值：k ≠ 0 是定义的必要条件，当 k = 0 时 y = 0（x ≠ 0），不是反比例函数。
- 反比例函数与正比例函数对应：正比例函数 y = kx 中两变量同时增大或减小；反比例函数 y = k/x 中一个增大时另一个减小，体现"成反比例"的关系。

### 1.2 反比例函数的图象与性质

- **图象**：反比例函数的图象是**双曲线**，由两支曲线组成，分别位于两个象限内。图象与坐标轴**没有交点**（因为 x ≠ 0 且 y ≠ 0），但无限接近坐标轴（渐近性）。
- **性质**：当 k > 0 时，双曲线的两支分别位于第一、三象限，在每个象限内，y 随 x 的增大而减小；当 k < 0 时，两支分别位于第二、四象限，在每个象限内，y 随 x 的增大而增大。
- 重要提醒："在每个象限内"这个条件不能省略，双曲线在不同的象限内增减性不同，比较两个点的大小时必须先判断它们是否在同一象限内。
- |k| 越大，双曲线离坐标轴越远；反比例函数图象是中心对称图形（关于原点对称）和轴对称图形（关于直线 y = x 和 y = -x 对称）。

### 1.3 k 的几何意义

- **k 的几何意义**：过双曲线 y = k/x 上任一点 P 分别作 x 轴、y 轴的垂线，与坐标轴围成的矩形面积为 |k|；连接 P 与原点，三角形面积为 |k|/2。
- 利用几何意义可以"数形结合"比较 k 的大小、求函数解析式中的 k 值，是中考常考内容。
- 应用：已知图象上一点求 k，可用点的坐标代入；已知矩形（或三角形）面积求 k，需根据图象所在象限确定 k 的符号。
- 反比例函数与一次函数的综合：两个函数图象的交点坐标就是由两个解析式组成的方程组的解；比较函数值大小时，按交点横坐标把 x 轴分成几个区间分别讨论。

### 例题

如图，反比例函数 y = k/x 的图象经过点 A(2，3)。(1) 求 k 的值；(2) 点 B(1，6) 和 C(-3，-2) 是否在这个函数的图象上？

解：(1) 把 A(2，3) 代入 y = k/x，得 k = 2 × 3 = 6，所以反比例函数为 y = 6/x。

(2) 对点 B(1，6)：xy = 1 × 6 = 6 = k，所以点 B 在图象上；

对点 C(-3，-2)：xy = (-3) × (-2) = 6 = k，所以点 C 也在图象上。

解析：判断点是否在反比例函数图象上，只需看"点的横纵坐标之积是否等于 k"。点 A 在图象上得 k = xy = 6；反比例函数图象上任意一点的横纵坐标之积恒等于常数 k，这是它的本质特征。

## 本章小结与常见错误

1. 增减性表述不严谨：反比例函数"y 随 x 的增大而减小（增大）"必须加上"在每个象限内"的前提，跨象限比较大小不能直接套用增减性。
2. 忽略 x ≠ 0：反比例函数自变量 x 不能为 0，图象与坐标轴无交点，画图时不能画到坐标轴上。
3. 判断函数类型出错：如 y = 2/(x+1) 分母含"x+1"，不是反比例函数 y = k/x 的标准形式；y = k/x 中分子必须是常数。
4. k 的符号与象限对应错误：k > 0 图象在一、三象限，k < 0 在二、四象限，常与一次函数的"k > 0 递增"混淆。

## 第2章 相似

### 2.1 相似图形与相似比

- **相似图形**：形状相同的图形叫做相似图形。相似多边形的对应角相等，对应边成比例。对应边的比叫做**相似比**。
- 全等是相似的特殊情形（相似比为 1）。相似多边形周长的比等于相似比，面积的比等于相似比的平方。
- **成比例线段**：在四条线段 a、b、c、d 中，如果 a/b = c/d，那么这四条线段叫做成比例线段，简称比例线段。
- 比例的性质：比例的基本性质 a/b = c/d ⇔ ad = bc；合比性质 (a + b)/b = (c + d)/d；等比性质等。平行线分线段成比例：两条直线被一组平行线所截，所得的对应线段成比例。

### 2.2 相似三角形的判定与性质

- **判定方法**：两角分别相等的两个三角形相似（AA，最常用）；两边成比例且夹角相等的两个三角形相似（SAS 型）；三边成比例的两个三角形相似（SSS 型）。平行于三角形一边的直线截其他两边（或两边的延长线），所截得的三角形与原三角形相似。
- 与全等三角形判定对比记忆：全等要求对应元素相等，相似要求对应元素成比例或角相等，记忆时可类比"SSS、SAS、ASA、AAS、HL"。
- **性质**：相似三角形对应角相等，对应边成比例；对应高的比、对应中线的比、对应角平分线的比都等于相似比；周长的比等于相似比；面积的比等于相似比的平方。
- 面积比是相似比的平方，这是最易出错的性质，做题时务必注意"平方"关系。

### 2.3 位似图形与相似的应用

- **位似图形**：如果两个图形不仅是相似图形，而且每组对应点所在的直线都经过同一点，那么这样的两个图形叫做位似图形，这个点叫做位似中心，这时的相似比又叫**位似比**。
- 位似图形的性质：位似图形上任意一对对应点到位似中心的距离之比等于位似比；对应线段平行（或在同一条直线上）且成比例。
- 在平面直角坐标系中，以原点为位似中心，把图形放大（或缩小）为原来的 k 倍时，对应点的坐标为 (kx，ky) 或 (-kx，-ky)（注意两种可能，k 与 -k 分别在异侧）。
- 相似的应用：测高（利用太阳光影子或标杆比例）、测宽（利用相似三角形构建比例式）、位似画图等，体现了数学建模思想。

### 例题

如图，在△ABC 中，DE ∥ BC，AD = 3，DB = 2，△ADE 的面积为 6。求四边形 DBCE 的面积。

解：因为 DE ∥ BC，所以 △ADE ∽ △ABC（平行于三角形一边的直线截其他两边，所得三角形与原三角形相似）。

相似比 k = AD/AB = 3/(3 + 2) = 3/5。

所以 S△ADE / S△ABC = (3/5)² = 9/25，即 6 / S△ABC = 9/25，

解得 S△ABC = 6 × 25/9 = 50/3。

所以 S四边形DBCE = S△ABC - S△ADE = 50/3 - 6 = 32/3。

答：四边形 DBCE 的面积为 32/3。

解析：由平行得三角形相似，注意相似比取 AD/AB 而不是 AD/DB；面积比等于相似比的平方。先求整个三角形的面积，再相减得四边形面积。

## 本章小结与常见错误

1. 面积比写成相似比：相似三角形的面积比等于相似比的"平方"，周长比、对应高之比才等于相似比本身，两者极易混淆。
2. 相似比的方向弄反：△ADE 与 △ABC 的相似比是 AD/AB 还是 AB/AD，取决于谁比谁；列比例式时对应边必须对应写。
3. 判定条件不足就下结论：判定相似至少需要两个条件（AA 或两边成比例且夹角相等或三边成比例），仅凭一组角相等或一组边成比例不能判定。
4. 位似变换坐标漏写负号：以原点为位似中心放大 k 倍时，坐标应为 (kx，ky) 或 (-kx，-ky) 两种情况，常只写一种而漏掉另一种。

## 第3章 锐角三角函数

### 3.1 锐角三角函数的定义

- 在 Rt△ABC 中，∠C = 90°，设 ∠A 为锐角，∠A 的对边为 a、邻边为 b、斜边为 c，则：
  - **正弦** sinA = 对边/斜边 = a/c；
  - **余弦** cosA = 邻边/斜边 = b/c；
  - **正切** tanA = 对边/邻边 = a/b。
- 三角函数值只与角的大小有关，与直角三角形的大小（边长）无关；由相似三角形的性质可以说明这一结论。
- 三者关系：sin²A + cos²A = 1；tanA = sinA/cosA；当 ∠A + ∠B = 90° 时，sinA = cosB（互余关系）。
- 定义中要注意：sinA、cosA、tanA 都是直角三角形中"两边之比"，解题时要先找准哪个角、哪两边。

### 3.2 特殊角的三角函数值

- 30°、45°、60° 角的三角函数值必须熟记：
  - sin30° = 1/2，cos30° = √3/2，tan30° = √3/3；
  - sin45° = √2/2，cos45° = √2/2，tan45° = 1；
  - sin60° = √3/2，cos60° = 1/2，tan60° = √3。
- 记忆技巧：正弦、余弦值可按分子规律记忆——sin 值分子依次为 √1、√2、√3（分母为 2），cos 值分子依次为 √3、√2、√1；tan 值依次为 √3/3、1、√3。
- 由函数值求角度：已知 sinA = 1/2，则 ∠A = 30°；这类"反求角"是解直角三角形的基础。

### 3.3 解直角三角形及其应用

- **解直角三角形**：由直角三角形中除直角外的已知元素，求出其余未知元素的过程。基本工具：勾股定理（三边关系）、锐角互余（两锐角关系）、三角函数定义（边角关系）。
- 解直角三角形的基本类型：已知两边（用勾股定理求第三边，用三角函数求角）；已知一边一角（选适当的三角函数关系求其他边）。
- **应用问题**：仰角、俯角（视线与水平线的夹角，在水平线上方为仰角，下方为俯角）；坡度（坡面的铅直高度与水平宽度的比，i = h/l，坡角 α 有 tanα = i）；方向角（北偏东等）。
- 解实际问题的步骤：把实际问题转化为数学问题，画出图形，构造直角三角形，选择合适的三角函数关系求解，最后作答并检验合理性。

### 例题

热气球的探测器显示，从热气球看一栋高楼顶部的仰角为 30°，看这栋高楼底部的俯角为 60°，热气球与高楼的水平距离为 120 m。求这栋高楼的高度（结果保留根号）。

解：如图（文字描述），设热气球在 C 点，高楼为 AB，过 C 作 CD ⊥ AB 于点 D。

在 Rt△ACD 中，∠ACD = 30°，CD = 120，tan30° = AD/CD，AD = 120 × √3/3 = 40√3（m）。

在 Rt△BCD 中，∠BCD = 60°，tan60° = BD/CD，BD = 120 × √3 = 120√3（m）。

所以 AB = AD + BD = 40√3 + 120√3 = 160√3（m）。

答：这栋高楼的高度为 160√3 m。

解析：仰角、俯角问题通常要"作高构造两个直角三角形"，分别用正切关系求出楼顶上方与楼底下方的高度，再相加。关键是把仰角、俯角正确标在图形中，找准直角三角形的边角关系。

## 本章小结与常见错误

1. 正弦、余弦定义混淆：sinA = 对边/斜边，cosA = 邻边/斜边，tanA = 对边/邻边，三者对应关系要记准，不能把对边与邻边弄反。
2. 特殊角函数值记错：如 sin30° 写成 √2/2、tan45° 写成 √3 等；建议按口诀或表格强化记忆，同时注意分母有理化。
3. 仰角、俯角、坡度理解错误：仰角是视线在水平线上方与水平线的夹角，俯角在下方；坡度 i = h/l = tanα，不是坡角本身。
4. 解直角三角形时缺条件强解：解三角形必须已知"两边"或"一边一角"（除直角外），已知条件不足时不能凭空假设，需先通过已知条件求出缺失元素。
