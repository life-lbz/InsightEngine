# 初中物理初三上册课程讲义
课程编号：junior_physics_g9s1　适用学段：初中　年级：初三　学期：上学期

本讲义依据人教版初中物理九年级全一册教学内容编写，围绕内能与热机、电流和电路、电压电阻与欧姆定律三大章节展开，完成从热学向电学的过渡，建立电学的基本概念与分析方法。

## 第一章 内能与热机

本章学习内能的概念、改变内能的两种方式、比热容及其计算、热机的工作原理与热机效率，理解能量转化在热学中的体现。

### 1.1 内能

- **内能的概念**：构成物体的所有分子，其热运动的动能与分子势能的总和，叫做物体的内能。内能的单位是焦耳（J）。一切物体在任何温度下都具有内能。
- **内能与温度的关系**：同一物体的温度越高，分子热运动越剧烈，内能越大。但温度升高内能一定增大，内能增大温度不一定升高（如晶体熔化过程中吸热内能增大而温度不变）。
- **改变内能的两种方式**：做功和热传递，这两种方式对改变物体内能是等效的。
  - 做功改变内能：外界对物体做功，物体内能增大（如压缩空气、搓手取暖）；物体对外做功，内能减小（如气体膨胀推动瓶塞跳出，瓶内水蒸气液化出现"白气"）。
  - 热传递改变内能：热传递是内能从高温物体转移到低温物体的过程，转移内能的多少叫热量，用 Q 表示，单位也是焦耳。
- **热传递的条件**：存在温度差，热传递的方向总是从高温物体传向低温物体，直到温度相同为止。

### 1.2 比热容

- **比热容的概念**：一定质量的某种物质，在温度升高（降低）时吸收（放出）的热量与它的质量和升高（降低）温度乘积之比，叫做这种物质的比热容，用 c 表示，单位是 J/(kg·℃)。
- **比热容公式**：c = Q/(mΔt)，变形可得吸放热公式 Q = cmΔt。其中 Δt 为温度变化量，升温时 Δt = t末 - t初，降温时 Δt = t初 - t末。
- **水的比热容**：c水 = 4.2×10³ J/(kg·℃)，表示质量为 1 kg 的水温度升高（或降低）1 ℃ 时吸收（或放出）的热量为 4.2×10³ J。
- **比热容的应用**：水的比热容大，吸热升温慢、放热降温慢，常用来做冷却剂（汽车发动机用水冷却）、取暖介质（暖气片用水）、调节气候（沿海地区昼夜温差小）等。比热容是物质的特性，与质量、温度变化无关。

### 1.3 热机与热机效率

- **热机的概念**：把内能转化为机械能的机器叫热机，常见的有蒸汽机、内燃机、汽轮机、喷气发动机等。内燃机分为汽油机和柴油机。
- **内燃机的四冲程**：汽油机的一个工作循环由吸气、压缩、做功、排气四个冲程组成，其中只有做功冲程对外做功，将内能转化为机械能；压缩冲程将机械能转化为内能。一个工作循环曲轴转两圈，活塞往复两次，做功一次。
- **热值**：某种燃料完全燃烧放出的热量与其质量之比，叫做这种燃料的热值，用 q 表示，单位是 J/kg（气体燃料常用 J/m³）。公式为 Q放 = mq。
- **热机效率**：热机用来做有用功的那部分能量与燃料完全燃烧放出的能量之比，即 η = W有用/Q放。热机效率越高，燃料利用越充分。提高热机效率的途径：使燃料充分燃烧、减少热量损失、保持良好的润滑等。

### 例题

**例题1（计算题）**：把质量为 2 kg、温度为 20 ℃ 的水加热到 70 ℃，水的比热容 c水 = 4.2×10³ J/(kg·℃)。求水吸收的热量。

**分析**：已知水的质量 m = 2 kg，初温 20 ℃，末温 70 ℃，温度变化量 Δt = 70 ℃ - 20 ℃ = 50 ℃，代入吸热公式 Q吸 = cmΔt 计算。

**解答**：Δt = 70 ℃ - 20 ℃ = 50 ℃。Q吸 = c水 m Δt = 4.2×10³ J/(kg·℃) × 2 kg × 50 ℃ = 4.2×10⁵ J。

**答案**：水吸收的热量为 4.2×10⁵ J。

## 本章小结与常见错误

1. **Δt 取值错误**："温度升高到 70 ℃"（末温为 70 ℃）与"温度升高了 70 ℃"（变化量为 70 ℃）含义不同，计算时混淆会导致错误。
2. **热量与温度概念混淆**：热传递转移的是内能，不能说"传递温度"；物体温度升高不一定吸收了热量（也可能外界对其做功）。
3. **做功冲程与压缩冲程能量转化记反**：压缩冲程是机械能转化为内能，做功冲程是内能转化为机械能。
4. **比热容与热值单位混淆**：比热容单位是 J/(kg·℃)，热值单位是 J/kg，两者含义不同，计算时要区分 Q = cmΔt 与 Q放 = mq。

## 第二章 电流和电路

本章学习电荷与电流的基本知识、电路的组成与连接方式，重点掌握串并联电路的识别、电流表的使用以及串并联电路中的电流规律。

### 2.1 电荷与电流

- **摩擦起电**：用摩擦的方法使物体带电的现象叫摩擦起电。摩擦起电的实质是电子的转移，得到电子的物体带负电，失去电子的物体带正电，并不是创造了电荷。
- **两种电荷及作用规律**：自然界只有正、负两种电荷，同种电荷互相排斥，异种电荷互相吸引。带电体能够吸引轻小物体。
- **电流**：电荷的定向移动形成电流。正电荷定向移动的方向规定为电流的方向。金属导体中实际移动的是自由电子，方向与电流方向相反。
- **电流的单位**：安培（A），常用单位还有毫安（mA）、微安（μA），换算关系：1 A = 10³ mA = 10⁶ μA。

### 2.2 电路的组成与连接

- **电路的组成**：电源、用电器、开关、导线是电路的四部分。电源提供电能（如电池、发电机），用电器消耗电能（如灯泡、电铃），开关控制电路通断。
- **通路、断路、短路**：处处连通的电路叫通路；某处断开的电路叫断路（开路）；电源短路是指电流不经用电器直接流回电源，会烧坏电源甚至引起火灾，是不允许的。
- **串联电路**：把用电器逐个顺次连接起来的电路。串联电路只有一条电流路径，各用电器互相影响，开关控制整个电路，与位置无关。
- **并联电路**：把用电器并列连接起来的电路。并联电路有多条电流路径，各用电器互不影响，干路开关控制整个电路，支路开关只控制本支路。

### 2.3 电流表的使用与串并联电流规律

- **电流表的使用规则**：电流表要串联在被测电路中；电流要从正接线柱流入、从负接线柱流出；被测电流不能超过电流表的量程（先用大量程试触）；绝对不允许不经过用电器把电流表直接接在电源两极上。
- **电流表的读数**：看清量程与分度值，大量程 0~3 A 分度值为 0.1 A，小量程 0~0.6 A 分度值为 0.02 A。
- **串联电路的电流规律**：串联电路中电流处处相等，即 I = I₁ = I₂ = I₃。
- **并联电路的电流规律**：并联电路中干路电流等于各支路电流之和，即 I = I₁ + I₂ + I₃。

### 例题

**例题2（计算题）**：如图所示的并联电路中，通过灯泡 L₁ 的电流为 0.3 A，通过灯泡 L₂ 的电流为 0.5 A，电流表接在干路上。求干路电流是多少安？

**分析**：并联电路中干路电流等于各支路电流之和，把两条支路电流相加即可。

**解答**：I = I₁ + I₂ = 0.3 A + 0.5 A = 0.8 A。

**答案**：干路电流为 0.8 A。

## 本章小结与常见错误

1. **电流方向与电子移动方向混淆**：规定电流方向为正电荷定向移动方向，金属导体中实际是自由电子定向移动，电子移动方向与电流方向相反。
2. **电流表连接错误**：电流表必须串联，若并联在用电器两端会造成短路；正负接线柱接反会使指针反向偏转，损坏电流表。
3. **电路识别错误**：串联、并联判断失误，尤其注意"导线直接连接电源两极"的短路情况，此时灯泡不亮且会烧坏电源。
4. **并联电路电流规律理解错误**：并联电路干路电流等于各支路电流之和，不是各处电流相等（各处电流相等是串联电路的特点）。

## 第三章 电压电阻与欧姆定律

本章学习电压、电阻的概念及测量工具，重点掌握欧姆定律 I = U/R 及其在串并联电路中的应用，学会分析动态电路与伏安法测电阻。

### 3.1 电压与电压表

- **电压的概念**：电压是使电路中自由电荷发生定向移动形成电流的原因，用 U 表示，单位是伏特（V），常用单位还有千伏（kV）、毫伏（mV），1 kV = 10³ V = 10⁶ mV。一节干电池的电压为 1.5 V，家庭电路电压为 220 V。
- **电压表的使用规则**：电压表要并联在被测电路两端；电流从正接线柱流入、负接线柱流出；被测电压不能超过电压表量程。电压表可以直接接在电源两极上测电源电压。
- **串联电路的电压规律**：串联电路两端的总电压等于各部分电路两端电压之和，即 U = U₁ + U₂。
- **并联电路的电压规律**：并联电路中各支路两端的电压都相等，即 U = U₁ = U₂。

### 3.2 电阻

- **电阻的概念**：导体对电流阻碍作用的大小叫电阻，用 R 表示，单位是欧姆（Ω），常用单位还有千欧（kΩ）、兆欧（MΩ），1 MΩ = 10³ kΩ = 10⁶ Ω。
- **电阻的决定因素**：导体的电阻与导体的材料、长度、横截面积有关，还与温度有关。同种材料，导体越长电阻越大，横截面积越大电阻越小；金属导体的电阻随温度升高而增大。
- **电阻是导体本身的一种性质**：导体的电阻由其自身的材料、长度、横截面积决定，与导体两端的电压和通过的电流无关。
- **滑动变阻器**：通过改变接入电路中电阻丝的长度来改变电阻的元件。使用规则：串联接入电路；接线柱要"一上一下"接入；闭合开关前应将滑片移到阻值最大处。铭牌"20 Ω 2 A"表示最大阻值为 20 Ω、允许通过的最大电流为 2 A。

### 3.3 欧姆定律

- **欧姆定律内容**：导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比。
- **欧姆定律公式**：I = U/R。变形公式 U = IR（求电压）和 R = U/I（求电阻，但电阻不由电压和电流决定）。
- **应用注意事项**：公式中的 I、U、R 是对同一段导体、同一时刻而言的，计算时要注意一一对应；使用时各物理量的单位应统一（V、Ω、A）。
- **伏安法测电阻**：用电压表测导体两端电压 U，用电流表测通过导体的电流 I，由 R = U/I 计算电阻。为了减小误差，要多次测量求平均值；连接电路时开关要断开，滑动变阻器起到保护电路和多次测量改变电压的作用。

### 3.4 欧姆定律在串并联电路中的应用

- **串联电路总电阻**：串联电路的总电阻等于各串联电阻之和，即 R = R₁ + R₂。串联电阻越多，总电阻越大，总电阻大于其中任何一个电阻。
- **并联电路总电阻**：并联电路总电阻的倒数等于各支路电阻倒数之和，即 1/R = 1/R₁ + 1/R₂。并联电阻越多，总电阻越小，总电阻小于其中任何一个支路电阻。
- **串联分压规律**：串联电路中电压按电阻大小分配，U₁/U₂ = R₁/R₂，电阻越大分得的电压越多。
- **并联分流规律**：并联电路中电流按电阻大小分配，I₁/I₂ = R₂/R₁，电阻越大通过的电流越小。
- **动态电路分析思路**：判断电路连接方式 → 明确电表测量对象 → 判断滑动变阻器阻值变化 → 根据串并联规律判断电流、电压变化。

### 例题

**例题3（计算题）**：电阻 R₁ = 10 Ω 与电阻 R₂ = 20 Ω 串联后接在电压为 6 V 的电源两端。求：（1）电路中的电流；（2）R₁ 两端的电压。

**分析**：串联电路总电阻 R = R₁ + R₂，再由欧姆定律 I = U/R 求电流，最后用 U₁ = IR₁ 求 R₁ 两端电压。

**解答**：（1）R = R₁ + R₂ = 10 Ω + 20 Ω = 30 Ω，I = U/R = 6 V ÷ 30 Ω = 0.2 A。（2）U₁ = IR₁ = 0.2 A × 10 Ω = 2 V。

**答案**：电路中电流为 0.2 A，R₁ 两端的电压为 2 V。

## 本章小结与常见错误

1. **电阻与电压电流关系表述错误**：不能说"电阻与电压成正比、与电流成反比"，R = U/I 只是计算式，电阻由导体自身因素决定。
2. **电压表串联在电路中**：电压表必须并联，若错接成串联，电路相当于断路，灯泡不亮，电压表读数接近电源电压。
3. **滑动变阻器接线错误**：把滑动变阻器接成"同上同下"，接入的是定值电阻（电阻不变）或金属杆（电阻为零），必须"一上一下"。
4. **并联电路总电阻计算错误**：并联电路总电阻要用倒数公式，不能用 R = R₁ + R₂；总电阻小于任何一个分电阻，据此可以检验计算结果。
