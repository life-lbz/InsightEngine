# 高中化学高三下册课程讲义
课程编号：senior_chemistry_g12s2　适用学段：高中　年级：高三　学期：下学期

本讲义为高考化学二轮复习讲义，聚焦"实验专题"与"综合模拟与应试"两大板块。二轮复习的目标是把一轮的知识网络转化为应试能力：实验题要会操作、会分析、会评价、会设计；综合卷要做到审题精准、表达规范、时间合理。本讲义结合高考真题结构，总结高频考法与失分点，帮助同学们在冲刺阶段实现"会做的题不丢分、有思路的题得全分"。

## 第一章 实验专题

> 本章核心：系统梳理化学实验基本操作与安全、气体制备与性质实验、定量实验（中和滴定等）与实验方案设计评价，建立"原理—装置—操作—评价"四维实验思维。

### 1.1 化学实验基本操作与安全

基本操作要点：

- 药品取用：固体用镊子或药匙，块状固体"一横二放三慢竖"；液体试剂瓶塞倒放、标签向手心；定量取用用托盘天平（精确到 0.1 g）与量筒（不用于配制溶液、不加热）；浓酸浓碱需在通风处操作并防飞溅。
- 加热：酒精灯用外焰加热，先预热再集中加热；给试管内液体加热时试管口不对人、液体不超过容积 1/3；蒸发皿、坩埚可高温加热，烧杯、锥形瓶垫石棉网，量筒、容量瓶不可加热。
- 过滤与洗涤：过滤"一贴二低三靠"；沉淀洗涤用蒸馏水（或指定溶剂），洗涤干净的判断标准是取最后一次洗涤液检验无目标离子。
- 气密性检查：微热法（手捂或酒精灯微热，导管口有气泡，冷却后形成水柱）。
- 安全知识：酒精灯失火用湿布盖灭；浓硫酸沾到皮肤先大量水冲洗再涂 NaHCO₃ 溶液；实验尾气有毒气体须吸收（Cl₂、SO₂ 用 NaOH 溶液）；可燃性气体点燃前须验纯。

常见实验事故处理：碱液溅到皮肤用大量水冲洗后涂硼酸；苯酚沾到皮肤用酒精洗涤；液溴沾到皮肤用酒精或甘油擦洗。

### 1.2 气体的制备与性质实验

气体发生装置选择依据"反应物状态与反应条件"：

- 固+固加热：O₂（2KMnO₄ 加热 K₂MnO₄ + MnO₂ + O₂↑ 或 2KClO₃ 加热 2KCl + 3O₂↑）、NH₃（2NH₄Cl + Ca(OH)₂ 加热 CaCl₂ + 2NH₃↑ + 2H₂O）、CH₄ 等。
- 固+液不加热：H₂（Zn + 稀硫酸）、CO₂（CaCO₃ + 稀盐酸，不用稀硫酸因生成微溶 CaSO₄ 阻碍反应）、H₂S 等；启普发生器适用块状固体与液体常温反应。
- 固（液）+液加热：Cl₂（MnO₂ + 浓盐酸加热）、SO₂（Na₂SO₃ + 浓硫酸）、HCl、C₂H₄（乙醇浓硫酸 170 ℃）、NO₂ 等。

收集方法：密度比空气大且不与空气反应用向上排空气法（Cl₂、CO₂、SO₂）；密度比空气小用向下排空气法（NH₃、H₂、CH₄）；难溶或微溶于水用排水法（H₂、O₂、NO——注意 NO 只能用排水法，因与 O₂ 反应）。

净化与干燥：根据气体性质选干燥剂——酸性气体用浓硫酸（不能干燥 NH₃、H₂S）；碱性气体用碱石灰（不能干燥 Cl₂、CO₂、SO₂ 等酸性气体）；Cl₂ 中 HCl 用饱和食盐水除杂（Cl₂ 在饱和食盐水中溶解度小）。

性质实验设计要点：验证漂白性用品红溶液；验证还原性用酸性 KMnO₄ 或溴水；验证酸性用石蕊或与 NaHCO₃ 反应；尾气处理（点燃、溶液吸收、收集）。

### 1.3 定量实验与数据处理

高考常考定量实验：酸碱中和滴定、配制一定物质的量浓度溶液、气体体积法测定、沉淀重量法。

**配制一定物质的量浓度溶液**（如 100 mL 1.00 mol/L NaCl）：计算 → 称量/量取 → 溶解（冷却至室温）→ 转移（玻璃棒引流）→ 洗涤（烧杯与玻璃棒 2~3 次，洗涤液并入容量瓶）→ 定容（距刻度线 1~2 cm 时改用胶头滴管）→ 摇匀。误差分析按"c = n/V"逐项判断：未冷却就转移定容→V 偏小→c 偏高；定容时俯视→V 偏小→c 偏高；仰视→c 偏低；洗涤不充分→n 偏小→c 偏低。

**酸碱中和滴定**：酸式滴定管（盛酸、氧化性溶液）与碱式滴定管（盛碱），先检漏、润洗（用待装液润洗 2~3 次，不能用蒸馏水）；滴定过程"左手控活塞、右手摇锥形瓶、眼睛注视锥形瓶内颜色变化"；终点判断：滴入最后半滴溶液，颜色突变且 30 秒内不恢复。数据处理：取多次平行实验的平均值（舍去偏差大的数据），误差分析同样回归 c(待测) = c(标)×V(标)/V(待测)。

**气体法测定**：如测定合金中锌的质量分数，通过排水量气法测 H₂ 体积，注意读数时"上下移动量筒使液面相平"（内外压强相等）、视线与液面最低处相平、冷却至室温再读数。

### 1.4 实验方案设计与评价

实验方案设计的基本要求：科学性（原理正确）、可行性（条件可实现）、简约性（步骤少、仪器简单）、安全性（无污染、防爆防毒）、经济性（原料易得、产率高）。

设计思路：明确实验目的 → 选择合适的反应原理 → 设计装置与步骤 → 预期现象与结论 → 评价改进。评价角度常考：①能否达到目的；②操作是否简便安全；③是否引入杂质或污染环境；④产率与纯度；⑤方案对比选优（如检验 Fe²⁺ 选 KMnO₄ 滴加后褪色还是先加 KSCN 后加氯水，需考虑干扰）。

开放探究题规范：猜想 → 方案 → 现象 → 结论"四步作答"，现象描述要具体（颜色变化、沉淀、气泡），结论要与猜想一一对应。

### 例题

**题目**：某同学用"排饱和食盐水法"收集氯气后用 NaOH 溶液吸收尾气。请回答：(1) 为什么不能用排水法收集 Cl₂？(2) 若用 0.2 mol Cl₂ 通入过量 NaOH 溶液中，生成的 NaClO 的物质的量是多少？

**解析**：(1) Cl₂ 能溶于水（1 体积水约溶 2 体积 Cl₂），且与水反应生成 HCl 和 HClO，故不能用排水法；而 Cl₂ 在饱和食盐水中的溶解度小，可用排饱和食盐水法收集。(2) 反应 Cl₂ + 2NaOH = NaCl + NaClO + H₂O 中 Cl₂ 与 NaClO 系数比 1∶1，0.2 mol Cl₂ 生成 0.2 mol NaClO；该反应中氯气既是氧化剂又是还原剂，转移电子 0.2 mol（1 mol Cl₂ 转移 1 mol e⁻）。

## 本章小结与常见错误

1. 常见错误：容量瓶定容前忘记摇匀或未冷却即定容。未冷却溶液体积膨胀，定容后冷却体积收缩导致 c 偏高；转移后必须先洗涤烧杯和玻璃棒并把洗涤液转入容量瓶。
2. 常见错误：滴定管未润洗直接使用。未用待装液润洗会稀释标准液，导致标准液消耗体积偏大、待测液浓度测定值偏高；锥形瓶则不能润洗。
3. 常见错误：气密性检查与验纯操作混淆。点燃 H₂、CH₄ 等可燃气体前必须验纯；制备装置必须检查气密性后再装药品（或装好后检查）。
4. 常见错误：实验评价只答"能/不能"不说理由。评价题须给出"原理是否正确、操作是否可行、有无污染"等具体依据，做到有理有据。

## 第二章 综合模拟与应试

> 本章核心：把握高考化学试卷结构与命题规律，掌握选择题与主观题的应试策略，规范作答、合理分配时间，实现稳定发挥。

### 2.1 高考化学题型结构与命题特点

全国卷及各省新高考化学卷一般分为选择题（单项选择题，约 14~16 题，每题 3 分）与主观题（工艺流程题、原理综合题、实验综合题、有机推断题，以及选考/必考的结构化学）。试卷结构特点：

- 选择题考查面广：化学与生活（STSE）、阿伏加德罗常数（NA 陷阱题）、离子方程式正误判断、离子共存、元素推断与周期律、电化学、速率平衡图像、有机物结构与性质、实验基本操作等。
- 主观题情境真实：以"工业流程、新型电池、催化剂机理、药物合成"等真实情境为载体，考查信息提取与迁移能力。
- 近年趋势：增加开放性设问（如方案设计、原因解释），强调证据推理与模型认知、科学探究与社会责任等核心素养。

### 2.2 各题型解题策略

**选择题（稳、准、快）**：

- NA 题：先锁定陷阱点——标准状况下非气体（SO₃、HF、苯等）、可逆反应不完全（N₂ + 3H₂ ⇌ 2NH₃、SO₂ 与 O₂、NO₂ 与 N₂O₄）、盐类水解（Fe³⁺、NH₄⁺ 等）、胶体粒子数（Fe(OH)₃ 胶粒是若干粒子聚合体）、电子转移数（歧化反应、氧化还原配平）。
- 离子方程式判断：查四个守恒（原子、电荷、电子、质量）+ 拆写是否正确 + 反应是否发生（量不同产物不同：CO₂ 少量/过量、NaOH 少量/过量）。
- 电化学：判断电极、介质、离子迁移方向；写电极反应先定"失得电子"再配介质与电荷。
- 有机物：抓官能团性质与反应类型，注意同分异构体数目、核磁共振氢谱峰数与峰面积比。

**主观题（审题、建模、规范）**：

- 工艺流程题：按"原料—预处理—核心反应—分离提纯—产品"读流程，设问常考方程式书写、条件控制原因、循环利用与绿色化学。
- 原理综合题：图像题先找拐点与平台，K 与转化率用三段式计算，电极反应书写注意介质。
- 实验题：明确实验目的，按"装置—操作—现象—结论"组织答案，原因解释题用"温度/浓度/压强→速率与平衡→结果"的逻辑链。
- 有机题：由分子式算不饱和度，特征反应定官能团，信息反应照搬条件，逆推设计合成路线。

### 2.3 答题规范与常见失分点

规范要求：

- 化学用语：化学式、离子符号、结构简式书写正确；方程式必须配平并写条件与"↑""↓"（注明"反应条件"与"点燃/加热/催化剂"等）；离子方程式注意电荷守恒。
- 计算题：写"解、设"，列出关系式，注明单位，结果保留有效数字（题目要求），"标准状况下气体体积"换算 22.4 L/mol 时先确认标准状况。
- 简答题：分点作答、先结论后理由、用化学术语（"使……完全沉淀""抑制……水解""平衡向……方向移动"），不写口语化表述。
- 常见失分点：审题漏看"少量/过量""标准状况""标况下非气体"；方程式条件漏写；有效数字处理不当；描述现象只说"变红"不说明试剂与颜色变化细节；推断题推出结构后不回代验证。

### 2.4 时间管理与综合模拟方法

时间分配建议（以 75 分钟/100 分或 90 分钟为例）：选择题 35%~40% 时间（约每题 1 分钟），主观题先做熟悉的题（一般按题号顺序，也可先做有机/流程等得分率高的题），留出 5~10 分钟检查。

综合模拟四步法：

1. 限时训练：每周至少 2 套完整试卷，严格限时、模拟考场心态。
2. 错题归因：把错题按"知识性错误、审题性错误、表述性错误、计算性错误"分类统计，针对性补漏。
3. 回归教材：对高频考点（离子反应、氧化还原、平衡、实验操作、有机官能团）逐一对照教材原文，确保术语准确。
4. 查漏补缺：考前两周不再刷新题，以错题本与教材目录自查为主，保持手感的模拟题控制在一周 1 套。

### 例题

**题目**：设 NA 为阿伏加德罗常数的值，判断下列说法是否正确并说明理由。(1) 标准状况下，11.2 L 苯含 0.5NA 个苯分子；(2) 1 mol NO₂ 与足量水反应转移 2NA 个电子；(3) 1 L 0.1 mol/L FeCl₃ 溶液中 Fe³⁺ 数目为 0.1NA。

**解析**：(1) 错误。标准状况下苯是液体（熔点 5.5 ℃，标准状况 0 ℃ 时苯为固体），不能用 22.4 L/mol 换算。(2) 错误。3NO₂ + H₂O = 2HNO₃ + NO，3 mol NO₂ 中 2 mol 被氧化（+4→+5）、1 mol 被还原（+4→+2），转移 2 mol e⁻，故 1 mol NO₂ 反应转移 2/3 mol e⁻，即 2NA/3 个电子。(3) 错误。Fe³⁺ 水解生成 Fe(OH)₃，Fe³⁺ 数目小于 0.1NA。本题集中考查 NA 题的三大高频陷阱：标准状况非气体、歧化反应电子转移数、盐类水解。

## 本章小结与常见错误

1. 常见错误：做 NA 题时对"标准状况下"视而不见。标准状况下呈非气态的物质（H₂O、苯、SO₃、HF、CCl₄、NO₂ 的聚合）不能直接用 22.4 L/mol，必须先判断物质状态。
2. 常见错误：主观题不写反应条件或"↑↓"符号。方程式书写"配平、条件、气体/沉淀符号"三者缺一不可，这是最集中的非智力失分点。
3. 常见错误：审题粗心漏掉"过量/少量""标准状况""能否"等限定词。建议圈画题干关键限定词，再动笔作答。
4. 常见错误：冲刺阶段盲目刷新题忽视错题归纳。考前应以错题归因与教材回归为主，保持适量模拟维持手感，切忌"刷题焦虑"。
