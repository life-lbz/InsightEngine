本讲义依据人教版《义务教育教科书·数学》七年级下册编写，内容涵盖相交线与平行线、实数、二元一次方程组三个章节，建立起几何与代数并行的双主线学习框架，为后续学习平面几何证明和方程（组）解决实际问题打下基础。

## 第1章 相交线与平行线

### 1.1 对顶角与邻补角

- **邻补角**：两条直线相交所成的四个角中，有一条公共边且另一边互为反向延长线的两个角，叫做互为邻补角。邻补角互补，和为 180°。
- **对顶角**：一个角的两边分别是另一个角的两边的反向延长线，这两个角叫做对顶角。对顶角相等。
- 两条直线相交形成的角中存在 2 对对顶角、4 对邻补角。理解"对顶角相等"是几何推理中最基本的依据之一。
- 几何推理的书写要规范，如"因为 ∠1 与 ∠2 是对顶角，所以 ∠1 = ∠2（对顶角相等）"。

### 1.2 垂线

- 当两条直线相交所成的四个角中有一个角是直角（90°）时，这两条直线**互相垂直**，其中一条直线叫做另一条直线的垂线，它们的交点叫做**垂足**。垂直用符号"⊥"表示。
- 垂线的两个基本事实：(1) 在同一平面内，过一点有且只有一条直线与已知直线垂直；(2) 连接直线外一点与直线上各点的所有线段中，**垂线段最短**。
- 点到直线的距离：直线外一点到这条直线的垂线段的长度，叫做**点到直线的距离**。注意是"垂线段的长度"，而不是"垂线段"本身。
- 垂线的画法：利用三角尺，一条直角边与已知直线重合，另一条直角边过已知点画线即可；过直线上一点和直线外一点的画法略有不同。

### 1.3 平行线的判定

- **平行线**：在同一平面内，不相交的两条直线叫做平行线。记作 a ∥ b。过直线外一点，有且只有一条直线与这条直线平行（平行公理）。
- 平行公理的推论：如果两条直线都与第三条直线平行，那么这两条直线也互相平行，即若 a ∥ c，b ∥ c，则 a ∥ b。
- 两条直线被第三条直线所截，形成"三线八角"：同位角、内错角、同旁内角。**判定方法**：同位角相等，两直线平行；内错角相等，两直线平行；同旁内角互补，两直线平行。
- 平行线的判定是由"角的关系"推出"线的位置关系"，是几何推理的重要内容。

### 1.4 平行线的性质

- **平行线的性质**：两直线平行，同位角相等；两直线平行，内错角相等；两直线平行，同旁内角互补。
- 平行线的判定与性质互为逆用：判定是"由角推线"（先看角后得平行），性质是"由线推角"（先有平行后得角的关系），二者条件与结论正好互换，不能混淆。
- 解决平行线问题时，常添加辅助线——过折点作已知直线的平行线，从而把折角转化为同位角、内错角或同旁内角。
- 平移：把一个图形整体沿某一直线方向移动，会得到一个新图形，新图形与原图形的形状、大小完全相同。平移前后对应点的连线平行且相等。

### 例题

如图（文字描述）：直线 AB ∥ CD，直线 EF 分别交 AB、CD 于点 E、F，∠AEF = 58°，EG 平分 ∠AEF 交 CD 于点 G。求 ∠EGC 的度数。

解：因为 AB ∥ CD，所以 ∠AEF = ∠EFC = 58°（两直线平行，内错角相等）。

又因为 EG 平分 ∠AEF，所以 ∠AEG = 1/2 ∠AEF = 29°。

因为 AB ∥ CD，所以 ∠AEG = ∠EGC = 29°（两直线平行，内错角相等）。

答：∠EGC = 29°。

解析：本题综合运用平行线的性质与角平分线定义。解题关键是识别角的位置关系：∠AEG 与 ∠EGC 是被直线 EG 所截形成的内错角，由 AB ∥ CD 可直接得到二者相等。

## 本章小结与常见错误

1. 混淆平行线的判定与性质：判定由角相等（互补）推出两直线平行，性质由两直线平行推出角相等（互补），条件结论不能互换。
2. 点到直线的距离理解错误：把"垂线段"当成距离，实际距离是垂线段的"长度"，是一个数值。
3. 对顶角、邻补角识别错误：只有两边互为反向延长线才是对顶角；有公共顶点且一条公共边的互补两角才是邻补角。
4. 计算中漏掉"90°"条件：垂直不一定直接给出直角符号，需由已知"互相垂直"推得一个角为 90°再参与计算。

## 第2章 实数

### 2.1 平方根与算术平方根

- 如果一个数 x 的平方等于 a，即 x² = a，那么这个数 x 叫做 a 的**平方根**（也叫二次方根）。正数有两个平方根，它们互为相反数；0 的平方根是 0；负数没有平方根。
- 求一个数 a 的平方根的运算，叫做**开平方**，开平方与平方互为逆运算。正数 a 的正的平方根记作 √a，叫做 a 的**算术平方根**；0 的算术平方根是 0。
- 规定：√a ≥ 0（非负性），被开方数 a ≥ 0（有意义条件）。两个非负性在求值、化简中经常用到。
- 常见平方根结论：√(a²) = |a|，即当 a ≥ 0 时 √(a²) = a，当 a < 0 时 √(a²) = -a。

### 2.2 立方根

- 如果一个数 x 的立方等于 a，即 x³ = a，那么这个数 x 叫做 a 的**立方根**（也叫三次方根），记作 ∛a。求一个数的立方根的运算叫做开立方，开立方与立方互为逆运算。
- 每个数（正数、负数、0）都有唯一的立方根：正数的立方根是正数，负数的立方根是负数，0 的立方根是 0。
- 立方根与平方根的重要区别：负数没有平方根，但有立方根；平方根有两个（互为相反数），立方根只有一个。
- 性质：∛(-a) = -∛a，即被开方数变号时立方根也变号；(∛a)³ = a，∛(a³) = a。

### 2.3 实数的分类与运算

- **无理数**：无限不循环小数叫做无理数，如 π、√2、1.010010001…（两个 1 之间依次多一个 0）等。
- **实数**：有理数和无理数统称实数。实数按定义可分为有理数与无理数；按正负可分为正实数、0、负实数。
- 实数与数轴上的点**一一对应**，即每个实数都可以用数轴上唯一的一个点表示，反过来数轴上的每个点都表示一个唯一的实数。无理数也可以用数轴上的点表示。
- 实数的运算：有理数的运算律和运算性质在实数范围内同样适用。无理数的四则运算中，加减需化为同类根式合并，乘除可利用乘法交换律、结合律化简。

### 例题

求下列各式的值：(1) √49；(2) -∛27；(3) √(3-1)²（即 √( (3-1)² ) 化简为 √4）；并比较 √3 与 1.7 的大小。

解：(1) √49 = 7；

(2) -∛27 = -3；

(3) √(3-1)² = √4 = 2。

比较大小：1.7² = 2.89 < 3，所以 √3 > 1.7。

解析：算术平方根、立方根开方后为有理数可直接求值；比较无理数大小时常用"平方比较法"，把两个正数同时平方后比较平方数的大小，从而判断原数的大小。

## 本章小结与常见错误

1. 平方根与算术平方根混淆：√4 = 2（算术平方根只取非负的一个），而 4 的平方根是 ±2，两者记法、含义都不同。
2. 负数平方根判断错误：负数没有平方根，如 √(-4) 无意义，但负数有立方根，如 ∛(-8) = -2。
3. 误判无理数：把 22/7、3.1415926（有限小数）、0.333…（循环小数）当作无理数，实际上无理数是无限不循环小数。
4. 化简 √(a²) 忘记绝对值：如 √( (-3)² ) = 3 而非 -3，应先取绝对值再开方。

## 第3章 二元一次方程组

### 3.1 二元一次方程（组）的概念

- **二元一次方程**：含有两个未知数，并且所含未知数的项的次数都是 1 的整式方程，叫做二元一次方程。一般形式为 ax + by = c（a、b 不为 0）。
- 一个二元一次方程有**无数个解**，每个解是一对数值 x = a，y = b，通常写成 {x = a, y = b} 的形式，即用大括号把一对值合在一起表示。
- **二元一次方程组**：把具有相同未知数的两个二元一次方程合在一起，就组成了一个二元一次方程组。
- **方程组的解**：使方程组中每个方程都成立的未知数的值，叫做方程组的解。二元一次方程组的解一般只有一个（一对值）。

### 3.2 代入消元法

- **代入消元法**：把方程组中一个方程的一个未知数用含另一个未知数的式子表示出来，再代入另一个方程，实现"消元"，得到一元一次方程，从而求出方程组的解。
- 步骤：变形（选系数简单的方程，用一个未知数表示另一个）→ 代入（把含一个未知数的式子代入另一个方程消元）→ 解一元一次方程求出一个未知数 → 回代求出另一个未知数 → 检验并写成 {x = …, y = …} 的形式。
- 代入法适合某个方程中某个未知数的系数为 1 或 -1 的情形，此时变形最简单。

### 3.3 加减消元法与方程组应用

- **加减消元法**：当两个方程中同一个未知数的系数相等或互为相反数时，把两个方程两边分别相减或相加，消去这个未知数，得到一元一次方程。
- 若系数既不相等也不互为相反数，可先把某个未知数的系数化成绝对值相等（乘以适当的数），再加减消元。例如把第一个方程两边同乘 2 使 x 的系数统一。
- 列二元一次方程组解应用题：审题找两个等量关系，设两个未知数，分别列两个方程组成方程组，解方程组并检验作答。
- 常见应用：行程问题（相遇、追及）、工程问题、商品销售问题、配套问题、年龄问题等。方程组比一元方程能更自然地表达两个等量关系。

### 例题

解方程组：{ 3x + 2y = 12, 2x - y = 1 }。

解法一（代入消元法）：由 2x - y = 1 得 y = 2x - 1，代入 3x + 2y = 12，得 3x + 2(2x - 1) = 12，即 7x - 2 = 12，解得 x = 2。回代得 y = 2 × 2 - 1 = 3。

解法二（加减消元法）：由 2x - y = 1 得 4x - 2y = 2（两边同乘 2），与 3x + 2y = 12 相加，得 7x = 14，x = 2；代回得 y = 3。

所以原方程组的解为 {x = 2, y = 3}。

解析：两种消元法殊途同归。代入法关键在"用一个未知数表示另一个"；加减法关键在使同一未知数系数绝对值相等，然后相加（异号）或相减（同号）消元。解完后应代回检验。

## 本章小结与常见错误

1. 判断二元一次方程漏条件：方程 ax + by = c 中要求 a、b 均不为 0，且各项次数必须为 1，如 xy = 2 中 xy 次数为 2，不是二元一次方程。
2. 代入消元时代入错误方程或忘记变号：应代入"另一个"没有变形的方程，且用含 x 的式子表示 y 时等式右边各项符号不能弄错。
3. 加减消元时系数处理不当：两方程相加（减）时，应把含未知数的项和常数项分别对齐相加（减），漏掉"两边同乘"或乘错倍数都会导致错误。
4. 解写成坐标形式或漏写大括号：方程组的解必须写成 {x = a, y = b} 的形式，不能只写 "x = a" 或写成点的坐标 "(a, b)"。
