# 高中物理高三上册课程讲义
课程编号：senior_physics_g12s1　适用学段：高中　年级：高三　学期：上学期

> 本册为一轮复习讲义，覆盖力学、电磁学两大板块的知识网络化梳理与实验专题，重在建立知识体系与综合解题能力。

## 第一章 力学综合复习

### 1.1 运动学与牛顿定律综合

- **知识网络**：匀变速直线运动公式（$v=v_0+at$，$x=v_0t+\frac{1}{2}at^2$，$v^2-v_0^2=2ax$）、平抛运动、圆周运动与牛顿定律（$F=ma$）构成运动学主线。
- 复习要点：
  - 图象法：v-t 图、x-t 图、a-t 图的斜率、面积、截距含义。
  - 临界问题：两物体恰好分离、恰好滑动（$f$ 达最大静摩擦力）时速度相等、加速度相等。
  - 传送带与板块模型：先判断物体与传送带（或木板）间的相对运动，再确定摩擦力方向，分段处理。
- 典型思路：受力分析 → 运动过程分段 → 每段列牛顿第二定律与运动学方程 → 衔接点（速度、位置）连续。

### 1.2 能量与动量综合

- **三大观点**：
  - 动力学观点（牛顿定律 + 运动学）：求加速度、时间、瞬时受力。
  - 能量观点（动能定理、机械能守恒、功能关系）：求位移、速度、做功、能量转化。
  - 动量观点（动量定理、动量守恒）：求时间、冲击力、碰撞前后速度。
- 功能关系总结：合外力做功 = 动能变化（动能定理）；重力做功 = 重力势能减小；克服安培力做功 = 电能增加；摩擦生热 $Q=fs_{\text{相对}}$。
- 动量守恒的三种典型情景：碰撞、爆炸与反冲、人船模型（$m_1x_1=m_2x_2$）。
- 综合题"多过程 + 多对象"处理策略：分段列式、找衔接点、选择合适观点（能量问题优先用动能定理与守恒定律，含时间与冲量用动量定理）。

### 1.3 力学综合问题建模

- 常见物理模型汇总：
  - 轻绳模型：绳中张力处处相等，绷紧瞬间动量守恒、能量有损失（绳拉直瞬间）。
  - 轻弹簧模型：弹簧弹性势能 $E_p=\frac{1}{2}kx^2$，压缩与伸长最大时两物体共速。
  - 轻杆模型：杆的弹力方向可沿杆也可不沿杆（铰链连接时沿杆）。
  - 滑块—木板模型：相对滑动判断、摩擦力方向、共速后一起运动还是继续相对滑动。
- 解题规范：明确研究对象 → 画受力图（标出所有力）→ 分阶段列方程 → 代数计算（注意单位与正方向）→ 检验结果合理性。

### 例题

**例1（计算题）**：光滑水平面上，质量 $M=4\ \mathrm{kg}$ 的木板静止，质量 $m=1\ \mathrm{kg}$ 的小物块以 $v_0=5\ \mathrm{m/s}$ 的初速度滑上木板左端，物块与木板间动摩擦因数 $\mu=0.4$，木板足够长（$g=10\ \mathrm{m/s^2}$）。求：(1) 物块与木板最终共同速度；(2) 系统产生的热量；(3) 物块相对木板滑行的距离。

**解析**：(1) 物块与木板组成的系统水平方向动量守恒：$mv_0=(m+M)v$，$v=\frac{1\times 5}{5}=1\ \mathrm{m/s}$。

(2) 由能量守恒，产生的热量等于系统损失的动能：$Q=\frac{1}{2}mv_0^2-\frac{1}{2}(m+M)v^2=\frac{1}{2}\times 1\times 25-\frac{1}{2}\times 5\times 1=12.5-2.5=10\ \mathrm{J}$。

(3) 摩擦生热 $Q=\mu mg\cdot s_{\text{相对}}$，$s_{\text{相对}}=\frac{Q}{\mu mg}=\frac{10}{0.4\times 1\times 10}=2.5\ \mathrm{m}$。

**易错点：滑块—木板模型中热量用相对位移计算，不能误用物块对地的位移；动量守恒的动量应相对同一惯性参考系（地面）。**

## 本章小结与常见错误

1. 三大观点选择不当：含时间与冲击力的问题盲目用动能定理，忘记动量定理在处理"力对时间的积累"上的优势。
2. 动量守恒选错系统或参考系，未注意碰撞、爆炸瞬间内力远大于外力方可近似守恒。
3. 摩擦生热公式中 $s_{\text{相对}}$ 与功的位移 $s_{\text{对地}}$ 混淆，导致热量计算错误。
4. 多过程问题漏掉衔接点条件（如绳拉直瞬间的能量损失、碰撞后共速），造成全程能量表达式错误。

## 第二章 电磁学综合复习

### 2.1 电场与磁场综合

- **知识主线**：场强（矢量，力角度）→ 电势（标量，能角度）→ 电场力做功 → 带电粒子运动。
- 电场中带电粒子的三种运动：加速（直线）、偏转（类平抛）、圆周（点电荷电场、等效重力场）。
- 磁场中带电粒子：$v\perp B$ 时做匀速圆周运动，$r=\frac{mv}{qB}$，$T=\frac{2\pi m}{qB}$。
- 复合场（电场 + 磁场 + 重力场）典型问题：
  - 速度选择器：$qvB=qE$，$v=\frac{E}{B}$ 的粒子直线通过。
  - 质谱仪：电场加速 + 磁场偏转，测比荷。
  - 回旋加速器：$T_{\text{电场}}=T_{\text{回旋}}$，最大动能 $E_{k\max}=\frac{q^2B^2R^2}{2m}$（由 D 形盒半径决定）。
  - 叠加场中做匀速圆周运动：重力与电场力平衡，洛伦兹力提供向心力。
- 解题要点：先判断受力（重力、电场力、洛伦兹力），再判断运动性质，分阶段列方程，注意洛伦兹力不做功。

### 2.2 电磁感应综合

- 电磁感应与电路：切割导体棒是电源，$E=BLv$，用闭合电路欧姆定律求电流，注意内阻。
- 电磁感应与力学：安培力 $F=BIL$ 随速度变化，棒可能经历"变加速 → 匀速（收尾）"过程。
- 电磁感应与能量：克服安培力做功 = 电能 = 其他形式能（焦耳热），$Q_{\text{热}}=I^2Rt$（总焦耳热按电阻分配）。
- 电荷量公式：$q=\bar{I}\Delta t=\frac{N\Delta\Phi}{R_{\text{总}}}$，只与磁通量变化量有关，与时间无关。
- 双棒模型：等长棒同向运动，系统动量守恒（无外力时）；动量不守恒时用动量定理。

### 2.3 力电综合问题

- 高考压轴常客：带电体在电场、磁场、重力场中的多过程运动，如"先电场加速 → 磁场圆周 → 电场偏转"的衔接问题。
- 解题四步：
  1. 明确对象与过程，画运动轨迹草图。
  2. 分阶段分析受力与运动（直线/圆周/类平抛）。
  3. 每阶段选择合适规律（牛顿定律、动能定理、圆周运动条件、洛伦兹力）。
  4. 衔接点建方程（速度大小与方向在交界处连续）。
- 数形结合：善用轨迹图与几何关系（圆周半径、弦长、圆心角），磁场边界问题注意"相切"条件。

### 例题

**例2（计算题）**：如图所示，在直角坐标系的第一象限内存在垂直纸面向里的匀强磁场，磁感应强度 $B=0.5\ \mathrm{T}$，$y>0$ 区域（$x>0$）。一带正电粒子以速度 $v=2\times 10^6\ \mathrm{m/s}$ 从原点 O 沿 $x$ 轴正方向射入磁场，粒子比荷 $\frac{q}{m}=5\times 10^7\ \mathrm{C/kg}$。求：(1) 粒子在磁场中做圆周运动的半径；(2) 粒子再次经过 $x$ 轴的位置坐标。

**解析**：(1) 由 $r=\frac{mv}{qB}=\frac{v}{(\frac{q}{m})B}=\frac{2\times 10^6}{5\times 10^7\times 0.5}=0.08\ \mathrm{m}$。

(2) 粒子沿 $x$ 轴正方向入射，在磁场中做逆时针（由左手定则）匀速圆周运动，圆心在 $y$ 轴正方向 $r$ 处，转半圈后再次回到 $x$ 轴，出射点与入射点间距离为直径 $2r=0.16\ \mathrm{m}$，故再次经过 $x$ 轴的位置坐标为 $(0.16,\ 0)$。

**易错点：粒子出磁场后做匀速直线运动，磁场边界处的轨迹画图与几何关系（弦、半径、圆心角）是得分关键。**

## 本章小结与常见错误

1. 复合场中遗漏洛伦兹力方向判断（负电荷方向相反），或忘记洛伦兹力不做功导致能量守恒式多写一项。
2. 电磁感应中电荷量 $q=\frac{N\Delta\Phi}{R}$ 与焦耳热 $Q$ 混淆，$q$ 与时间无关、$Q$ 与时间有关。
3. 带电粒子在叠加场中做圆周运动时，未先检查重力与电场力是否平衡就列向心力方程。
4. 磁场边界"恰好离开/恰好击中"类问题忽视临界几何条件（相切、相离），直接套公式。

## 第三章 实验专题复习

### 3.1 力学实验

- **必修实验**：
  - 探究匀变速直线运动的速度与位移关系：纸带数据处理，逐差法求加速度 $a=\frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T^2}$。
  - 探究加速度与力、质量的关系：控制变量法；平衡摩擦力（垫高木板使小车匀速下滑）；砂桶质量远小于小车质量。
  - 探究功与速度变化的关系：橡皮筋做功，找 $W-v^2$ 关系。
  - 验证机械能守恒定律：$mgh=\frac{1}{2}mv^2$，重物质量可约去；先接通电源后释放纸带；选点迹清晰且第 1、2 点间距约 2 mm 的纸带。
  - 验证动量守恒定律：斜槽末端水平、小球碰前静止、用水平射程代替水平速度。
- 测量类实验：刻度尺（估读到 mm 下一位）、弹簧测力计、打点计时器（电磁式 50 Hz，每 0.02 s 打一点）、游标卡尺与螺旋测微器读数规则。

### 3.2 电学实验

- **核心实验**：
  - 伏安法测电阻：外接法（$R_V\gg R_x$ 时）与内接法（$R_x\gg R_A$ 时）的选择。
  - 描绘小灯泡的伏安特性曲线：分压式接法（从零开始连续可调），外接法。
  - 测定电源电动势和内阻：伏安法、伏阻法、安阻法；$U-I$ 图象纵截距为 $E$、斜率为 $-r$。
  - 多用电表的使用：机械调零 → 选挡 → 欧姆调零 → 测量 → 换挡重新调零；读数乘以倍率。
  - 电表改装：电流表改装电压表（串联 $R=\frac{U}{I_g}-R_g$）、改装电流表（并联 $R=\frac{I_gR_g}{I-I_g}$）。
- 滑动变阻器接法选择：要求电压（电流）从零开始变化或变化范围大用分压式；限流式能耗小、操作简单。

### 3.3 实验数据处理与误差分析

- 数据处理方法：列表法、图象法（描点作图、拟合直线）、公式法。作图的坐标起点不一定是零，标度要合适使图线占据大部分图幅。
- 误差来源分析：系统误差（仪器、原理缺陷）与偶然误差（读数、操作）。减小偶然误差：多次测量取平均值、多组数据作图。
- 有效数字与读数规范：螺旋测微器（千分尺）读到 0.001 mm，估读到 0.001 mm；游标卡尺不估读。
- 电学实验常见误差：伏安法内接法使测量值偏大（测的电流是准确的，电压偏大），外接法使测量值偏小。

### 例题

**例3（判断与数据处理题）**：某同学用"验证机械能守恒定律"实验装置，打出的一条纸带如图，测得第 1、2 两点间距离为 $x_{12}=3.8\ \mathrm{mm}$，请判断该纸带是否满足实验要求，并说明理由。若已知相邻计数点时间间隔 $T=0.02\ \mathrm{s}$，第 2 点速度如何计算？

**解析**：由自由落体运动，第 1、2 两点间（对应 $t=T=0.02\ \mathrm{s}$）理论位移应为 $x=\frac{1}{2}gT^2=\frac{1}{2}\times 9.8\times 0.02^2\approx 2\ \mathrm{mm}$。若 $x_{12}=3.8\ \mathrm{mm}$ 明显大于 2 mm，说明重物释放时纸带已提前运动（或打点前纸带有初速度），该纸带不满足"初速度为零"的要求，应舍去。

第 2 点速度用平均速度法：$v_2=\frac{x_{13}}{2T}$（$x_{13}$ 为第 1 点到第 3 点的距离）。

**易错点：验证机械能守恒必须保证重物初速为零，判断依据就是第 1、2 点间距接近 2 mm；瞬时速度用平均速度法而非 $v=gt$ 计算（$v=gt$ 会引入重力加速度这一待验证量）。**

## 本章小结与常见错误

1. 电学实验中内外接法选择错误：判断标准是比较待测电阻与电压表、电流表电阻的相对大小，而非只看题目给的条件。
2. 螺旋测微器读数漏估一位，游标卡尺读数错误估读（游标卡尺不估读）。
3. 验证机械能守恒时用 $v=gt$ 计算速度，循环论证导致实验结论失去验证意义。
4. 平衡摩擦力时误用砂桶重力代替小车合外力（应满足 $m_{\text{砂桶}}\ll M_{\text{小车}}$），导致系统误差。

- 一轮复习重在"网络化"：把零散知识连成线、织成网，每章画知识结构图并标注公式适用条件。
- 综合题分阶段练：先做单过程基础题，再过渡到两过程、三过程的综合题，每道题做完后复盘"为什么这么分段、每个衔接点列什么方程"。
- 实验复习对照考纲逐一过关：会原理、会操作、会读数、会数据处理、会误差分析，缺一不可。
