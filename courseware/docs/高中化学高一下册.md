# 高中化学高一下册课程讲义
课程编号：senior_chemistry_g10s2　适用学段：高中　年级：高一　学期：下学期

本册讲义对应人教版高中化学必修第一册（元素化学部分）与必修第二册（物质结构与元素周期律、化工生产）。本册以氯、硫、氮三种典型非金属元素为载体，深入"结构决定性质、性质决定用途"的学科思想，最后上升到原子结构与元素周期律的理论高度，初步建立"位—构—性"统一的化学观念。

## 第一章 氯及其化合物

> 本章核心：氯气是典型的活泼非金属单质，掌握其性质、氯水成分、实验室制备与氯离子检验。

### 1.1 氯气的性质

氯气（Cl₂）是黄绿色、有刺激性气味的有毒气体，密度比空气大，能溶于水（1 体积水约溶解 2 体积 Cl₂），易液化。氯气化学性质活泼，具有强氧化性。

- 与金属反应：2Na + Cl₂ 点燃 2NaCl（白烟）；Cu + Cl₂ 点燃 CuCl₂（棕黄色烟，溶于水得蓝色溶液）；2Fe + 3Cl₂ 点燃 2FeCl₃（棕褐色烟，注意生成三价铁）。
- 与非金属反应：H₂ + Cl₂ 点燃（或光照）2HCl。氢气在氯气中安静燃烧，发出苍白色火焰，瓶口有白雾（HCl 遇水蒸气形成盐酸小液滴）。
- 与水反应：Cl₂ + H₂O ⇌ HCl + HClO（可逆反应，产物为盐酸与次氯酸）。
- 与碱反应：Cl₂ + 2NaOH = NaCl + NaClO + H₂O（用于吸收多余氯气，尾气处理）；2Cl₂ + 2Ca(OH)₂ = CaCl₂ + Ca(ClO)₂ + 2H₂O，漂白粉的主要成分是 CaCl₂ 和 Ca(ClO)₂，有效成分是 Ca(ClO)₂。

### 1.2 氯水与次氯酸的漂白性

新制氯水因含 Cl₂ 而呈黄绿色，氯水是多种微粒共存的混合物：分子有 Cl₂、H₂O、HClO；离子有 H⁺、Cl⁻、ClO⁻（及少量 OH⁻）。氯水的性质是多微粒性质的叠加：酸性（H⁺）、漂白性（HClO）、强氧化性（Cl₂、HClO）、与 AgNO₃ 生成白色沉淀（Cl⁻）。

次氯酸（HClO）是弱酸，具有**强氧化性**，能使有色物质褪色（漂白原理是氧化漂白，不可逆），光照易分解：2HClO 光照 2HCl + O₂↑，故新制氯水应避光保存，久置氯水因 HClO 分解几乎变为稀盐酸。

漂白粉漂白原理：Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO，漂白粉在空气中因吸收 CO₂ 和 H₂O 生成 HClO 而逐渐失效。

### 1.3 氯气的实验室制备与氯离子检验

实验室用浓盐酸与二氧化锰共热制氯气：MnO₂ + 4HCl（浓）加热 MnCl₂ + Cl₂↑ + 2H₂O。也可用 KMnO₄ 与浓盐酸在常温下反应：2KMnO₄ + 16HCl（浓）= 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O。

制备装置：固液加热型发生装置 → 饱和食盐水（除 HCl，因 Cl₂ 在饱和食盐水中溶解度很小）→ 浓硫酸（干燥）→ 向上排空气法收集 → 尾气用 NaOH 溶液吸收（防污染）。注意：Cl₂ 不能用排水法收集，因为其能溶于水。

**Cl⁻ 检验**：向待测液中先加稀硝酸酸化（排除 CO₃²⁻、OH⁻ 等干扰），再滴加 AgNO₃ 溶液，若产生白色沉淀（AgCl），则证明含 Cl⁻，反应的离子方程式：Ag⁺ + Cl⁻ = AgCl↓。加酸酸化的目的是防止 CO₃²⁻ 与 Ag⁺ 生成 Ag₂CO₃ 沉淀造成误判。

### 例题

**题目**：向盛有氯水的试管中加入 NaHCO₃ 粉末，观察到有气泡产生，说明氯水中含有哪种微粒？写出反应的离子方程式。

**解析**：气泡为 CO₂，说明氯水中含有 H⁺（酸的通性）。HCO₃⁻ 与 H⁺ 反应：HCO₃⁻ + H⁺ = H₂O + CO₂↑。该实验证明新制氯水具有酸性。若继续向该氯水中滴加紫色石蕊溶液，先变红（H⁺）后褪色（HClO 漂白），这正体现了氯水成分的多样性。

## 本章小结与常见错误

1. 常见错误：认为氯气与铁反应生成 FeCl₂。氯气氧化性强，与 Fe 反应直接生成 FeCl₃。
2. 常见错误：混淆"干燥的氯气"与"氯水"的漂白性。干燥 Cl₂ 无漂白性，起漂白作用的是氯水中的 HClO。
3. 常见错误：认为 Cl₂ 可用排水法收集或直接用 NaOH 溶液洗气干燥。收集应用向上排空气法或排饱和食盐水法。
4. 常见错误：检验 Cl⁻ 时不加稀硝酸酸化。应先用稀硝酸酸化，排除 CO₃²⁻ 等干扰后再加 AgNO₃。

## 第二章 硫和氮及其化合物

> 本章核心：系统学习硫、氮两种重要非金属元素及其化合物的性质、转化与用途，了解酸雨、氮氧化物污染等环境问题。

### 2.1 硫与二氧化硫、硫酸

硫（S）是黄色固体，俗称硫黄，难溶于水，微溶于酒精，易溶于 CS₂。硫的化学性质：与金属反应生成低价硫化物，如 Fe + S 加热 FeS、2Cu + S 加热 Cu₂S（证明硫的氧化性弱于氯气）；与 O₂ 反应 S + O₂ 点燃 SO₂（蓝紫色火焰）。

**SO₂** 是无色、有刺激性气味的有毒气体，密度比空气大，易溶于水（1 体积水约溶 40 体积 SO₂），是酸性氧化物：

- 与水反应：SO₂ + H₂O ⇌ H₂SO₃（亚硫酸，可形成酸雨）。
- 与碱反应：SO₂ + 2NaOH = Na₂SO₃ + H₂O（尾气处理）。
- 漂白性：SO₂ 能与某些有色物质化合生成不稳定的无色物质，使品红溶液褪色，加热后颜色恢复（区别于 HClO 的氧化漂白，HClO 漂白不可逆）。
- 还原性（+4 价硫可被氧化）：2SO₂ + O₂ 催化剂加热 2SO₃；SO₂ + Cl₂ + 2H₂O = H₂SO₄ + 2HCl（等物质的量时 SO₂ 与 Cl₂ 混合，漂白能力反而消失）。
- 弱氧化性：SO₂ + 2H₂S = 3S↓ + 2H₂O。

**浓硫酸**的特性：①吸水性（作干燥剂，干燥 Cl₂、SO₂ 等，不能干燥 NH₃、HI 等）；②脱水性（使蔗糖炭化变黑，体现 C、H、O 按 2∶1 脱出）；③强氧化性：Cu + 2H₂SO₄（浓）加热 CuSO₄ + SO₂↑ + 2H₂O；C + 2H₂SO₄（浓）加热 CO₂↑ + 2SO₂↑ + 2H₂O。常温下浓硫酸使铁、铝钝化，故可用铁罐车运输浓硫酸。

### 2.2 氮的氧化物、氨与铵盐、硝酸

氮气 N₂ 化学性质稳定（N≡N 键能大），放电条件下：N₂ + O₂ 放电 2NO（无色），2NO + O₂ = 2NO₂（红棕色，有刺激性气味），NO₂ 与水反应 3NO₂ + H₂O = 2HNO₃ + NO，此反应是工业制硝酸的重要反应，NO、NO₂ 是大气污染物（光化学烟雾成分）。

**氨（NH₃）**：无色、有刺激性气味的气体，极易溶于水（1 体积水约溶 700 体积 NH₃），可用喷泉实验证明。氨水显碱性：NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻。氨的化学性质：

- 与酸反应：NH₃ + HCl = NH₄Cl（白烟，可用于检验 NH₃）；NH₃ + HNO₃ = NH₄NO₃。
- 还原性（催化氧化）：4NH₃ + 5O₂ 催化剂加热 4NO + 6H₂O（工业制硝酸第一步）。
- 实验室制备：2NH₄Cl + Ca(OH)₂ 加热 CaCl₂ + 2NH₃↑ + 2H₂O，用向下排空气法收集，用湿润的红色石蕊试纸验满（变蓝）。

**铵盐**都是易溶于水的白色晶体，受热易分解（NH₄Cl 加热 NH₃↑ + HCl↑），与碱共热放出 NH₃：NH₄⁺ + OH⁻ 加热 NH₃↑ + H₂O，这是检验 NH₄⁺ 的常用方法（湿润红色石蕊试纸变蓝）。

**硝酸**：无色、有刺激性气味的液体，易挥发，具有强氧化性。浓硝酸与金属反应：Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O；3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。常温下浓硝酸使铁、铝钝化。硝酸见光或受热分解：4HNO₃ 光照或加热 4NO₂↑ + O₂↑ + 2H₂O，故浓硝酸应保存在棕色瓶中并避光。

### 2.3 环境保护与含硫、含氮物质的转化

**酸雨**：pH 小于 5.6 的降水，主要由 SO₂ 和氮氧化物溶于水形成。防治措施：开发使用清洁能源、烟气脱硫脱硝（如石灰石—石膏法：CaCO₃ 高温分解成 CaO，CaO + SO₂ = CaSO₃，再氧化成 CaSO₄）。

**工业制硫酸**（接触法）三阶段：①沸腾炉煅烧硫铁矿 4FeS₂ + 11O₂ 高温 2Fe₂O₃ + 8SO₂；②接触室催化氧化 2SO₂ + O₂ 催化剂加热 2SO₃；③吸收塔中用 98.3% 浓硫酸吸收 SO₃（不用水吸收，防止形成酸雾）：SO₃ + H₂O = H₂SO₄。

**工业制硝酸**（氨氧化法）：4NH₃ + 5O₂ 催化剂加热 4NO + 6H₂O → 2NO + O₂ = 2NO₂ → 3NO₂ + H₂O = 2HNO₃ + NO（NO 循环利用）。

氮的"价类二维"转化思想：同一种元素处于不同价态的化合物之间可以相互转化，如 NH₃（-3）→ NO（+2）→ NO₂（+4）→ HNO₃（+5），复习时要善于用化合价与物质类别两个维度构建知识网络。

### 例题

**题目**：将 32 g Cu 完全溶于一定量浓硝酸中，收集到标准状况下气体 11.2 L（为 NO₂ 与 NO 的混合气体）。求混合气体中 NO₂ 与 NO 的物质的量之比。

**解析**：n(Cu) = 32/64 = 0.5 mol，反应中 Cu 失去电子总数 n(e⁻) = 0.5 × 2 = 1 mol。设 NO₂ 为 x mol、NO 为 y mol，由电子守恒：x + 3y = 1；由气体总量：x + y = 11.2/22.4 = 0.5。联立解得 x = 0.25、y = 0.25，即 n(NO₂)∶n(NO) = 1∶1。本题考查硝酸与金属反应中"电子守恒 + 原子守恒"的综合运用。

## 本章小结与常见错误

1. 常见错误：认为 SO₂ 与 HClO 的漂白原理相同。SO₂ 是化合型漂白（加热恢复），HClO 是氧化型漂白（不可逆），且 SO₂ 使品红褪色加热后颜色复现。
2. 常见错误：收集 NH₃ 时误用向上排空气法。NH₃ 密度比空气小，应用向下排空气法，且不能用浓硫酸干燥。
3. 常见错误：认为铜与硝酸反应只有一种情况。浓硝酸产物为 NO₂，稀硝酸产物为 NO，要注意"浓稀不同，产物不同"。
4. 常见错误：误以为酸雨就是 pH < 7 的雨水。正常雨水因溶有 CO₂ 呈弱酸性，酸雨的判定标准是 pH < 5.6。

## 第三章 物质结构与元素周期律

> 本章核心：从原子结构出发认识元素周期表，掌握元素周期律（位—构—性关系），理解离子键与共价键的本质区别。

### 3.1 原子结构

原子由质子（+）、中子（0）、核外电子（-）构成。质量数 A = 质子数 Z + 中子数 N。原子呈电中性：质子数 = 核外电子数。**核素**：具有一定数目质子和一定数目中子的原子。**同位素**：质子数相同而中子数不同的同种元素的不同核素，如 ¹H、²H（氘 D）、³H（氚 T）；¹²C 与 ¹⁴C。同位素化学性质几乎完全相同。

核外电子分层排布遵循：电子层由内向外依次为 K、L、M、N 层；每层最多容纳 2n² 个电子；最外层不超过 8 个（K 层为最外层时不超过 2 个）；次外层不超过 18 个。可用原子结构示意图表示，如 Na（11）：2、8、1。

### 3.2 元素周期表与元素周期律

元素周期表有 7 个周期（短周期 1~3，长周期 4~7）、16 个族（7 个主族 ⅠA~ⅦA、7 个副族、Ⅷ族、0 族）。元素周期表是元素周期律的表现形式，周期序数 = 电子层数，主族序数 = 最外层电子数。

**元素周期律**：元素的性质随原子序数递增而呈周期性变化的规律，本质是原子核外电子排布（特别是最外层电子数）的周期性变化。

同周期（从左到右）：核电荷数增大，原子半径减小，失电子能力减弱、得电子能力增强，金属性减弱、非金属性增强，最高价氧化物对应水化物碱性减弱、酸性增强，气态氢化物稳定性增强。

同主族（从上到下）：电子层数增多，原子半径增大，失电子能力增强、得电子能力减弱，金属性增强、非金属性减弱。

**位—构—性关系**：由元素在周期表中的位置可推原子结构，进而推断其性质。比较金属性强弱可依据单质与水（酸）反应的难易、最高价氧化物水化物碱性强弱；比较非金属性强弱可依据与 H₂ 化合的难易、气态氢化物稳定性、最高价含氧酸酸性强弱、元素单质之间的置换反应等。元素金属性、非金属性强弱与单质化学活泼性是不同概念，不可混同。

### 3.3 化学键

化学键是相邻原子间强烈的相互作用。**离子键**：阴、阳离子间通过静电作用形成的化学键，存在于离子化合物（活泼金属与活泼非金属形成的化合物、铵盐等）中，如 NaCl、MgO、NaOH、NH₄Cl。离子化合物中可能存在共价键（如 NaOH 中的 O—H 键、Na₂O₂ 中的 O—O 键）。

**共价键**：原子间通过共用电子对形成的化学键，存在于共价化合物（如 HCl、CO₂、H₂O、CH₄）与非金属单质（H₂、Cl₂）中。共价键分为极性键（不同种原子间，如 H—Cl）与非极性键（同种原子间，如 Cl—Cl）。

判断化合物类型：含金属阳离子或 NH₄⁺ 的一般是离子化合物；只含非金属元素的化合物多为共价化合物（注意铵盐 NH₄Cl、NH₄NO₃ 是离子化合物）。电子式书写：NaCl 为 Na⁺[∶Cl∶]⁻；H₂O 为 H∶O∶H（O 上还有两对孤对电子）；HCl 为 H∶Cl∶。

### 例题

**题目**：A、B、C、D 为短周期元素，A 的原子最外层电子数是内层电子数的一半，B 是地壳中含量最多的元素，C 是短周期中金属性最强的元素，D 与 B 同主族且原子序数大于 B。判断四种元素并比较其金属性、非金属性强弱。

**解析**：B 为 O（地壳中含量最多）；C 为 Na（第三周期 ⅠA 族，短周期金属性最强）；D 与 O 同主族且原子序数大，为 S；A 最外层电子数是内层电子数的一半：若 A 为 Li（2、1，最外层 1 不是内层一半）不对；若 A 为 Si（2、8、4，最外层 4 是内层 10 的一半），故 A 为 Si。金属性 Na > Si；非金属性 O > S > Si。结论：C（Na）金属性最强，B（O）非金属性最强。

## 本章小结与常见错误

1. 常见错误：把原子半径大小与得失电子能力直接等同。失电子能力（金属性）与原子半径、核电荷数均有关，比较时须在同周期或同主族前提下进行。
2. 常见错误：认为只含非金属元素的化合物一定不含离子键。NH₄Cl、NH₄NO₃ 等铵盐含离子键，是离子化合物。
3. 常见错误：把"最外层电子数 = 主族序数"推广到副族。该关系只适用于主族元素。
4. 常见错误：用金属与酸反应剧烈程度判断金属性时忽略硝酸的氧化性干扰，应用非氧化性酸（盐酸、稀硫酸）。
