# 高中化学高二上册课程讲义
课程编号：senior_chemistry_g11s1　适用学段：高中　年级：高二　学期：上学期

本册讲义对应人教版高中化学选择性必修1《化学反应原理》，是高中化学最抽象、最定量化的板块。内容包括化学反应速率与化学平衡、水溶液中的离子平衡（电离平衡、盐类水解、沉淀溶解平衡）。掌握平衡思想（勒夏特列原理）、守恒思想（电荷守恒、物料守恒、质子守恒）与"定量计算"方法是本册学习的核心目标。

## 第一章 化学反应速率与平衡

> 本章核心：化学反应速率的影响因素、化学平衡状态的特征与判断、平衡移动方向（勒夏特列原理）的判定。

### 1.1 化学反应速率及其影响因素

化学反应速率用单位时间内反应物浓度的减少或生成物浓度的增加表示：v = Δc/Δt，单位为 mol/(L·s) 或 mol/(L·min)，取正值。同一反应用不同物质表示速率时，数值之比等于化学计量数之比，如对于 aA + bB = cC，v(A)∶v(B)∶v(C) = a∶b∶c。固体或纯液体的浓度视为常数，不能用其表示反应速率。

影响化学反应速率的因素：

- 内因：反应物本身的性质（决定因素）。
- 外因：①浓度：增大反应物浓度，速率加快（注意：对纯固体、纯液体改变用量不影响速率）；②压强：对气体反应，增大压强相当于增大浓度，速率加快（无气体参与的反应不受压强影响）；③温度：升高温度，速率加快（一般温度每升高 10 ℃，速率约增大 2~4 倍）；④催化剂：正催化剂加快反应速率，且能降低反应的活化能，同等程度改变正逆反应速率；⑤其他：接触面积、光照、超声波等。改变浓度、压强、温度只改变速率不改变平衡；催化剂不改变平衡移动方向。

有效碰撞理论：只有活化分子间发生有效碰撞才能引发反应。升温、增大浓度、加催化剂均使单位体积内活化分子数（或百分数）增大，从而加快速率。

### 1.2 化学平衡状态

可逆反应在一定条件下，正、逆反应速率相等且各组分浓度不再改变的状态叫**化学平衡状态**。其五大特征：逆（可逆反应）、等（v正 = v逆）、动（动态平衡）、定（浓度、含量不变）、变（条件改变，平衡可能移动）。

化学平衡状态的判断标志：①直接标志：v正 = v逆（同一物质）；②间接标志：各组分的物质的量、浓度、百分含量、颜色（有色物质）不再变化；③对于气体分子数变化的反应，恒温恒容时总压强、平均摩尔质量不变可作为平衡标志；气体分子数不变的反应（如 H₂ + I₂ ⇌ 2HI）总压强始终不变，不能作为标志。混合气体密度不变是否作标志，须结合恒容/恒压条件与气体分子数是否变化综合分析。

**化学平衡常数 K**：对于 aA + bB ⇌ cC + dD，K = [C]^c[D]^d / [A]^a[B]^b，K 只与温度有关（温度不变 K 不变），与浓度、压强无关。K 越大，反应进行程度越大。利用浓度商 Q 与 K 比较可判断平衡移动方向：Q < K，正向移动；Q = K，平衡状态；Q > K，逆向移动。

### 1.3 化学平衡移动与勒夏特列原理

**勒夏特列原理**：如果改变影响平衡的一个条件（浓度、温度、压强等），平衡就向能够减弱这种改变的方向移动（注意是"减弱"而非"消除"）。

- 浓度：增大反应物浓度或减小生成物浓度，平衡正向移动。
- 温度：升高温度，平衡向吸热方向移动；降低温度，平衡向放热方向移动。
- 压强：增大压强，平衡向气体分子数减小方向移动；减小压强，向气体分子数增大方向移动。气体分子数不变的反应，压强改变平衡不移动。
- 催化剂：同等程度改变正逆反应速率，平衡不移动，但能缩短达到平衡的时间。

应用实例：工业合成氨 N₂ + 3H₂ ⇌ 2NH₃（放热、气体体积减小），采用"高压、适当温度、铁触媒催化剂"，并不断液化分离氨、循环利用未反应气体，以提高转化率。

### 例题

**题目**：在恒容密闭容器中发生反应 A(g) + 2B(g) ⇌ 2C(g) ΔH < 0，下列说法正确的是（　）。

A. 容器内压强不变时，反应一定达到平衡；B. 升高温度，正逆反应速率均增大，平衡逆向移动；C. 通入 He，容器内压强增大，平衡正向移动；D. 再充入 B，B 的转化率增大、A 的转化率减小。

**解析**：该反应气体分子数减小（3→2），恒容下压强不变可作为平衡标志，A 正确。升高温度正逆速率都增大，平衡向吸热方向（逆向）移动，B 正确。恒容通入不参与反应的 He，各组分浓度不变，平衡不移动，C 错误。再充入 B，平衡正向移动，B 的转化率减小、A 的转化率增大，D 错误。答案为 A、B。

## 本章小结与常见错误

1. 常见错误：用固体或纯液体浓度表示反应速率。固体和纯液体浓度视为常数，应用气体或溶液浓度变化表示。
2. 常见错误：认为升温或加催化剂只改变正反应速率。温度、催化剂对正逆反应速率都有影响，升温同等使正逆速率加快（吸热方向加快更多），催化剂同等程度改变。
3. 常见错误：恒容条件下充入惰性气体使总压增大，误判为平衡移动。关键是各组分浓度未变，平衡不移动。
4. 常见错误：混淆转化率与平衡移动方向。增大一种反应物浓度，其自身转化率降低，另一种反应物转化率升高。

## 第二章 电离平衡

> 本章核心：弱电解质电离平衡的建立与移动、水的电离与 pH 计算、盐类水解规律及其应用（离子浓度比较、蒸干问题）。

### 2.1 弱电解质的电离平衡

弱电解质在水溶液中只发生部分电离，存在电离平衡。如醋酸：CH₃COOH ⇌ CH₃COO⁻ + H⁺。电离平衡受温度、浓度、同离子效应（加 CH₃COONa，抑制电离）、外加反应离子（加 NaOH 或金属锌消耗 H⁺，促进电离）影响，均符合勒夏特列原理。

**电离平衡常数 K_a（或 K_b）**：K_a = [CH₃COO⁻][H⁺]/[CH₃COOH]，只与温度有关，温度升高 K 增大（电离吸热）。K_a 可比较弱酸酸性强弱：K_a 越大，酸性越强，对应酸根的水解程度越小。多元弱酸分步电离，K_a1 远大于 K_a2，如 H₂CO₃ ⇌ H⁺ + HCO₃⁻（K_a1）、HCO₃⁻ ⇌ H⁺ + CO₃²⁻（K_a2）。

### 2.2 水的电离与溶液 pH

水是极弱的电解质：H₂O ⇌ H⁺ + OH⁻，水的离子积 K_w = c(H⁺)·c(OH⁻)，25 ℃ 时 K_w = 1×10⁻¹⁴。K_w 只与温度有关，升温 K_w 增大（电离吸热），100 ℃ 时约为 1×10⁻¹²。酸、碱均抑制水的电离（但由水电离出的 c(H⁺) = c(OH⁻) 仍相等），可水解的盐促进水的电离。

pH 定义：pH = -lg c(H⁺)。常温下：pH < 7 酸性，pH = 7 中性，pH > 7 碱性。pH 每变化 1，c(H⁺) 变化 10 倍。**pH 计算要点**：强酸直接由 c(H⁺) 算；强碱先算 c(OH⁻)，再通过 K_w 求 c(H⁺)；混合溶液先判断过量，酸过量算 c(H⁺)、碱过量算 c(OH⁻)；涉及强酸强碱混合时可用"若恰好中和则 pH = 7"判断。注意：任何水溶液中都同时存在 H⁺ 与 OH⁻，溶液的酸碱性由 c(H⁺) 与 c(OH⁻) 的相对大小决定。

酸碱中和滴定：用已知浓度的酸（或碱）测定未知浓度碱（或酸）的定量实验，指示剂选择：强酸强碱用酚酞或甲基橙，强酸滴弱碱用甲基橙，强碱滴弱酸用酚酞。终点判断：滴入最后一滴溶液颜色突变且半分钟内不褪色。

### 2.3 盐类水解

盐电离出的离子与水电离出的 H⁺ 或 OH⁻ 结合生成弱电解质的反应叫盐类水解，实质是促进水的电离，一般水解程度很小。规律："有弱才水解、无弱不水解、谁弱谁水解、谁强显谁性"：

- 强酸弱碱盐（NH₄Cl）：NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺，溶液显酸性。
- 强碱弱酸盐（CH₃COONa）：CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻，溶液显碱性。
- 强酸强碱盐（NaCl）：不水解，显中性。
- 弱酸弱碱盐（CH₃COONH₄）：双水解，显性由相对强弱决定（CH₃COONH₄ 显中性）。

**水解平衡的移动**：升温促进水解；加水稀释促进水解；加酸抑制阳离子水解、促进阴离子水解；加碱反之。**蒸干溶液问题**：AlCl₃ 溶液蒸干灼烧得 Al₂O₃（AlCl₃ + 3H₂O 加热 Al(OH)₃↓ + 3HCl↑，Al(OH)₃ 灼烧 2Al(OH)₃ 加热 Al₂O₃ + 3H₂O）；Na₂CO₃、Na₂SO₄ 溶液蒸干得原固体。

**离子浓度大小比较**方法（以 CH₃COONa 溶液为例）：先列守恒：①电荷守恒 c(Na⁺) + c(H⁺) = c(CH₃COO⁻) + c(OH⁻)；②物料守恒 c(Na⁺) = c(CH₃COO⁻) + c(CH₃COOH)；③质子守恒 c(OH⁻) = c(H⁺) + c(CH₃COOH)。比较结果：c(Na⁺) > c(CH₃COO⁻) > c(OH⁻) > c(H⁺)。

### 例题

**题目**：25 ℃ 时，将 0.1 mol/L 盐酸与 0.1 mol/L 氨水等体积混合，所得溶液 pH = 7。比较溶液中各离子浓度大小，并写出电荷守恒关系。

**解析**：混合后溶液呈中性，c(H⁺) = c(OH⁻)。溶液中存在 NH₄⁺、Cl⁻、H⁺、OH⁻ 四种离子，由电荷守恒 c(NH₄⁺) + c(H⁺) = c(Cl⁻) + c(OH⁻)，结合 c(H⁺) = c(OH⁻) 得 c(NH₄⁺) = c(Cl⁻)。因水解程度与电离程度相当，离子浓度关系为 c(NH₄⁺) = c(Cl⁻) > c(H⁺) = c(OH⁻)。注意：此时溶液中的 Cl⁻ 浓度为 0.05 mol/L（等体积稀释）。

## 本章小结与常见错误

1. 常见错误：认为 pH = 7 的溶液一定呈中性。pH 只表示 c(H⁺)，中性与否取决于 c(H⁺) 与 c(OH⁻) 的相对大小，100 ℃ 时中性溶液的 pH < 7。
2. 常见错误：计算由酸电离的 c(H⁺) 时忽略水电离的 H⁺。对于强酸，c(H⁺) 主要由酸提供，但 K_w 关系仍然成立；对弱酸，水的电离不可忽略时需联立 K_a 求解。
3. 常见错误：认为盐类水解反应是"完全"的。除 Al³⁺ 与 CO₃²⁻、HCO₃⁻ 等发生相互促进的完全双水解外，一般水解程度很小，书写水解方程式用"⇌"且不标"↑""↓"。
4. 常见错误：离子浓度比较时忘记列守恒关系。任意电解质溶液中必须同时满足电荷守恒、物料守恒，质子守恒可由二者相减推出。

## 第三章 化学平衡综合

> 本章核心：沉淀溶解平衡与溶度积 Ksp 的应用、化学平衡图像（速率—时间、浓度—时间、转化率—温度/压强）的分析方法、平衡计算中的"三段式"法。

### 3.1 沉淀溶解平衡

难溶电解质在水溶液中存在溶解平衡，如 AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)。**溶度积** Ksp = c(Ag⁺)·c(Cl⁻)，只与温度有关，Ksp 越小表示难溶电解质溶解能力越弱（仅对同类型如 AgCl、AgBr 可直接比较）。

**Q 与 Ksp 比较判沉淀生成与溶解**：Q > Ksp，有沉淀生成（析出）；Q = Ksp，饱和；Q < Ksp，沉淀溶解。改变条件使平衡移动（勒夏特列原理同样适用）：

- 加沉淀剂或同离子（如加 Cl⁻）抑制溶解。
- 加水稀释（对微溶物）促进溶解但不改变 Ksp。
- 加能与其中离子反应的物质（如加氨水络合 Ag⁺）促进沉淀溶解。

沉淀的转化：向 AgCl 悬浊液中加入 KI 溶液，可观察到白色沉淀转化为黄色沉淀（AgCl → AgI），原因 Ksp(AgI) < Ksp(AgCl)，沉淀向更难溶的方向转化。分步沉淀：同浓度 Cl⁻、I⁻ 共存时逐滴加入 Ag⁺，先析出更难溶的 AgI。

### 3.2 化学平衡图像分析

常见平衡图像类型及分析方法：

- **速率—时间图（v-t 图）**：看哪条曲线"突变"判断改变的条件；看突变后正逆速率相对大小判断平衡移动方向。若 v正 与 v逆 同步同幅增大（曲线贴合上移），则改变的是催化剂或等体反应加压（平衡不移动）。
- **浓度（含量）—时间图**：看各组分达到平衡所需时间（先平者对应的温度高或压强大）、平衡时含量大小。
- **转化率（含量）—温度/压强图**：看拐点之前的斜率方向判断吸热/放热、气体分子数变化；"先拐先平数值大"。
- 分析原则："定一议二"（固定一个变量讨论另两个变量）、"先拐先平"（先出现拐点的先达到平衡，对应条件较"剧烈"）。

典型判断示例：反应 mA(g) + nB(g) ⇌ pC(g)，若图中温度升高 C 的百分含量增大，则正反应吸热；若压强增大 A 的转化率增大，则 m + n > p（气体分子数减小方向）。

### 3.3 平衡常数与平衡计算

**三段式法**（物质的量浓度或物质的量均可，保持单位一致）：设起始、变化、平衡三段浓度，代入 K 表达式求解。

例如：恒温恒容下，N₂ + 3H₂ ⇌ 2NH₃，起始 c(N₂) = 1 mol/L、c(H₂) = 3 mol/L，某时刻测得 c(NH₃) = 1 mol/L，可推出变化量：c(N₂) 减少 0.5、c(H₂) 减少 1.5，平衡时 c(N₂) = 0.5、c(H₂) = 1.5、c(NH₃) = 1.0，K = 1.0²/(0.5 × 1.5³) = 16/27 ≈ 0.593。同时可求 N₂ 转化率 α = 0.5/1 × 100% = 50%。

相关计算要点：①**转化率** α = 变化量/起始量 × 100%；②**平衡常数**只与温度有关；③涉及气体用分压表示平衡常数时 Kp，各物质分压 = 总压 × 物质的量分数；④多重平衡叠加：反应③ = 反应① + 反应②，则 K₃ = K₁ × K₂（反应相减则 K 相除；系数翻倍 K 变为 K²）。

### 例题

**题目**：已知 25 ℃ 时 Ksp(AgCl) = 1.8×10⁻¹⁰，Ksp(AgBr) = 5.0×10⁻¹³。向含 0.001 mol/L Cl⁻ 和 0.001 mol/L Br⁻ 的溶液中逐滴加入 AgNO₃ 溶液，哪种沉淀先生成？当 AgCl 开始沉淀时，c(Br⁻) 为多少？

**解析**：生成 AgBr 需 c(Ag⁺) > Ksp(AgBr)/c(Br⁻) = 5.0×10⁻¹³/0.001 = 5.0×10⁻¹⁰ mol/L；生成 AgCl 需 c(Ag⁺) > 1.8×10⁻¹⁰/0.001 = 1.8×10⁻⁷ mol/L。前者更小，故 AgBr 先沉淀。当 AgCl 开始沉淀时 c(Ag⁺) = 1.8×10⁻⁷ mol/L，此时 c(Br⁻) = Ksp(AgBr)/c(Ag⁺) = 5.0×10⁻¹³/1.8×10⁻⁷ = 2.8×10⁻⁶ mol/L。此即分步沉淀的定量应用。

## 本章小结与常见错误

1. 常见错误：认为 Ksp 大的难溶物溶解度一定大。只有同类型（如 AgCl 与 AgBr 同属 AB 型）才能直接用 Ksp 比较溶解能力。
2. 常见错误：沉淀转化方向判断失误。沉淀总是向更难溶（Ksp 更小）的方向转化，如同浓度 Cl⁻、I⁻ 共存时先析出 AgI。
3. 常见错误：三段式计算中"变化量"之比写错。变化量之比等于化学计量数之比，且反应物减少、生成物增加，符号不能搞反。
4. 常见错误：看平衡图像时把"先拐先平"与"数值大小"混用。先出现拐点的对应条件更剧烈（温度更高、压强更大），但平衡后的数值大小要结合吸放热与气体分子数变化另行判断。
