## 第一章 动量

### 1.1 动量与动量定理

- **动量**：$p=mv$，是矢量，方向与速度方向相同。单位 $\mathrm{kg\cdot m/s}$。
- **冲量**：$I=Ft$（恒力冲量），是矢量，方向与力方向相同，单位 $\mathrm{N\cdot s}$。
- **动量定理**：合外力的冲量等于物体动量的变化量，$I_{\text{合}}=\Delta p=p'-p$（矢量式，需规定正方向）。
- 应用要点：
  - 变力作用常用平均力 $F$ 表示冲量；$F-t$ 图象中图线与时间轴围成的面积表示冲量。
  - 动量定理常用来解决碰撞、打击、缓冲问题（如跳高垫海绵垫、汽车安全气囊都是延长作用时间减小作用力）。
  - 动量定理是矢量式，列式时先规定正方向。

### 1.2 动量守恒定律

- **动量守恒定律**：系统不受外力或所受合外力为零时，系统的总动量保持不变：$m_1v_1+m_2v_2=m_1v_1'+m_2v_2'$。
- 适用条件（三个层次）：
  - 理想条件：系统不受外力或合外力为零。
  - 近似条件：系统内力远大于外力（如碰撞、爆炸、反冲）。
  - 单向条件：某一方向上合外力为零，则该方向上动量守恒。
- 动量守恒定律是矢量式，使用前必须先规定正方向；只适用于系统，不能对单个物体应用。
- 应用步骤：确定系统与过程 → 判断外力是否为零 → 规定正方向 → 列方程求解。

### 1.3 碰撞问题

- **碰撞分类**（以对心碰撞为例）：
  - 完全弹性碰撞：动能守恒，$v_1'=\frac{(m_1-m_2)v_1+2m_2v_2}{m_1+m_2}$，$v_2'=\frac{(m_2-m_1)v_2+2m_1v_1}{m_1+m_2}$。
  - 完全非弹性碰撞：碰后共速，动能损失最大，$\Delta E_k=\frac{1}{2}m_1v_1^2+\frac{1}{2}m_2v_2^2-\frac{1}{2}(m_1+m_2)v^2$。
  - 非弹性碰撞：动量守恒、动能不守恒（有损失）。
- 碰撞三原则：动量守恒；总动能不增加；碰后速度符合实际情况（不穿行）。
- 一动一静完全弹性碰撞特例：$m_1=m_2$ 时速度交换；$m_1\ll m_2$ 时小球反弹。

### 例题

**例1（计算题）**：质量 $m_1=2\ \mathrm{kg}$ 的小球 A 以 $v_1=6\ \mathrm{m/s}$ 的速度在光滑水平面上向右运动，与静止的质量 $m_2=4\ \mathrm{kg}$ 的小球 B 发生完全弹性碰撞，求碰后 A、B 的速度。

**解析**：规定向右为正方向，动量守恒：$m_1v_1=m_1v_1'+m_2v_2'$。

完全弹性碰撞动能守恒：$\frac{1}{2}m_1v_1^2=\frac{1}{2}m_1v_1'^2+\frac{1}{2}m_2v_2'^2$。

代入数据：$12=2v_1'+4v_2'$，$36=2v_1'^2+4v_2'^2$。

解得 $v_1'=-2\ \mathrm{m/s}$（方向向左），$v_2'=4\ \mathrm{m/s}$（方向向右）。

**易错点：碰撞问题必须同时满足动量守恒与动能不增的原则，解得的速度要检验是否会出现"穿行"。**

## 本章小结与常见错误

1. 动量守恒定律直接套用公式前未判断系统合外力是否为零，例如子弹打木块过程若桌面有摩擦则动量近似守恒需说明内力远大于外力。
2. 动量定理与动量守恒是矢量式，忘记规定正方向导致符号错误。
3. 把完全非弹性碰撞误当成一般碰撞直接列动能守恒式，碰撞中动能不一定守恒。
4. 冲量计算中误用 $I=Ft$ 处理变力，变力冲量应通过动量定理或 $F-t$ 图面积求。

## 第二章 静电场

### 2.1 电场强度与电场线

- **电荷守恒定律**：电荷既不能创生也不能消灭，只能从一个物体转移到另一个物体。
- **库仑定律**：$F=k\frac{q_1q_2}{r^2}$（真空中的点电荷），$k=9.0\times 10^9\ \mathrm{N\cdot m^2/C^2}$。
- **电场强度**：$E=\frac{F}{q}$（定义式，与试探电荷无关），矢量，方向为正电荷受电场力方向。点电荷场强 $E=k\frac{Q}{r^2}$；匀强电场 $E=\frac{U}{d}$。
- **电场线**：从正电荷（或无穷远）出发终止于负电荷（或无穷远），疏密表示强弱，切线方向为场强方向；电场线不相交，不是电荷的运动轨迹（仅当电场线与轨迹重合且电荷初速度沿切线时才可能重合）。

### 2.2 电势能与电势

- **电势能**：电荷在电场中具有的能量，$E_p=q\varphi$（带符号计算），变化量与路径无关。
- **电势**：$\varphi=\frac{E_p}{q}$，标量，沿电场线方向电势逐渐降低。
- **电势差**：$U_{AB}=\varphi_A-\varphi_B=\frac{W_{AB}}{q}$，电场力做功 $W_{AB}=qU_{AB}$（与路径无关）。
- **等势面**：电势相等的点构成的曲面。等势面与电场线垂直；电场线由高电势指向低电势；等势面越密场强越大。
- 场强与电势无直接关系：场强为零处电势不一定为零（等量同种电荷连线中点），电势为零处场强不一定为零。

### 2.3 电容器与电容

- **电容器**：储存电荷和电能的元件。电容 $C=\frac{Q}{U}$（定义式），单位法拉 F。
- 平行板电容器：$C=\frac{\varepsilon_r S}{4\pi kd}$（$\varepsilon_r$ 为相对介电常数，$S$ 为正对面积，$d$ 为板间距）。
- 两类典型动态分析：
  - 电容器始终与电源相连：$U$ 不变，改变 $d$、$S$、$\varepsilon_r$ 时由 $C\propto \frac{S}{d}$、$Q=CU$、$E=\frac{U}{d}$ 分析。
  - 充电后断开电源：$Q$ 不变，由 $C=\frac{Q}{U}$ 与 $E\propto \frac{1}{\varepsilon_r S}$ 分析（改变 $d$ 时板间场强不变）。

### 2.4 带电粒子在电场中的运动

- **加速**：电场力做功使粒子动能增加，$qU=\frac{1}{2}mv^2-\frac{1}{2}mv_0^2$。
- **偏转**（垂直进入匀强电场，类平抛）：
  - 加速度 $a=\frac{qE}{m}=\frac{qU}{md}$；飞行时间 $t=\frac{l}{v_0}$（$l$ 为板长）。
  - 侧移量 $y=\frac{1}{2}at^2=\frac{qUl^2}{2mdv_0^2}$；偏转角 $\tan\theta=\frac{v_y}{v_0}=\frac{qUl}{mdv_0^2}$。
- 注意：处理带电粒子的运动时需判断重力是否可以忽略（电子、质子等微观粒子通常忽略重力，小球、液滴等宏观物体不能忽略）。

### 例题

**例2（计算题）**：如图所示，平行板电容器两板间电压 $U=200\ \mathrm{V}$，板间距离 $d=2\ \mathrm{cm}$，一个电子（$m=0.91\times 10^{-30}\ \mathrm{kg}$，$e=1.6\times 10^{-19}\ \mathrm{C}$）从静止开始经加速电压 $U_1=1000\ \mathrm{V}$ 加速后，垂直进入偏转电场，偏转板长 $l=4\ \mathrm{cm}$。求电子离开偏转电场时的侧移量 $y$。

**解析**：加速过程：$eU_1=\frac{1}{2}mv_0^2$，得 $v_0=\sqrt{\frac{2eU_1}{m}}$。

偏转电场中：加速度 $a=\frac{eU}{md}=\frac{e\times 200}{m\times 0.02}$。

飞行时间 $t=\frac{l}{v_0}$，侧移量 $y=\frac{1}{2}at^2=\frac{U l^2}{4U_1 d}=\frac{200\times(0.04)^2}{4\times 1000\times 0.02}=0.004\ \mathrm{m}=4\ \mathrm{mm}$。

**易错点：偏转电场的侧移量公式推导中 $v_0$ 由加速电场决定，若加速与偏转混用同一电压会出错。**

## 本章小结与常见错误

1. 场强与电势关系理解错误：认为场强越大电势越高，实际电场线疏密与电势高低是两个维度。
2. 电势能公式 $E_p=q\varphi$ 漏带电荷正负号，导致正负功判断错误。
3. 电容器动态分析未分清"电压不变"与"电荷量不变"两种情形，套错公式。
4. 带电粒子偏转中忽略重力判断，或把偏转电场电压当成加速电压使用。

## 第三章 恒定电流

### 3.1 电路基本概念与欧姆定律

- **电流**：$I=\frac{q}{t}$（$q$ 为通过导体横截面的电荷量），方向规定为正电荷定向移动方向。微观表达式 $I=nqSv$。
- **欧姆定律**：$I=\frac{U}{R}$，适用于纯电阻电路（金属导体、电解液）。伏安特性曲线中，$I-U$ 图线斜率的倒数表示电阻。
- 电阻是导体本身的属性，与两端电压和通过的电流无关，$R=\frac{U}{I}$ 是量度式而非决定式。

### 3.2 电阻定律与串并联电路

- **电阻定律**：$R=\rho\frac{l}{S}$（$\rho$ 为电阻率，与材料和温度有关）。金属电阻率随温度升高而增大，半导体电阻率随温度升高而减小。
- 串联电路：电流处处相等，$U=U_1+U_2+\cdots$，$R=R_1+R_2+\cdots$，电压按电阻分配。
- 并联电路：电压处处相等，$I=I_1+I_2+\cdots$，$\frac{1}{R}=\frac{1}{R_1}+\frac{1}{R_2}+\cdots$，电流按电阻反比分配。
- 电表改装：电流表改装为电压表需串联大电阻；改装为大量程电流表需并联小电阻。

### 3.3 闭合电路欧姆定律

- **闭合电路欧姆定律**：$I=\frac{E}{R+r}$，其中 $E$ 为电动势，$r$ 为内阻。
- 路端电压与电流关系：$U=E-Ir$（图象：纵截距为 $E$，斜率为 $-r$）。
- 外电路电阻变化时的动态分析：$R\uparrow \Rightarrow I\downarrow \Rightarrow U\uparrow$。
- 功率与效率：电源总功率 $P_{\text{总}}=EI$；输出功率 $P_{\text{出}}=UI$；内耗功率 $P_{\text{内}}=I^2r$；效率 $\eta=\frac{U}{E}$。
- 电源输出功率最大的条件：$R=r$（外电阻等于内阻），此时 $P_{\max}=\frac{E^2}{4r}$。

### 3.4 电功与电功率

- **电功**：$W=UIt$；**电功率**：$P=UI$（普遍成立）。
- 纯电阻电路：$W=I^2Rt=\frac{U^2}{R}t$，$P=I^2R=\frac{U^2}{R}$（焦耳热与电功相等）。
- 非纯电阻电路（电动机、电解槽）：电功 $W=UIt$，热量 $Q=I^2Rt$，机械能（或化学能）部分为 $UIt-I^2Rt$。**此时 $U\ne IR$，欧姆定律不成立。**
- 额定功率与实际功率：用电器铭牌标注额定电压、额定功率；实际功率取决于实际电压。

### 例题

**例3（计算题）**：如图所示电路中，电源电动势 $E=6\ \mathrm{V}$，内阻 $r=1\ \Omega$，定值电阻 $R_1=4\ \Omega$，滑动变阻器 $R_2$ 从 $10\ \Omega$ 调至零。求：(1) 当 $R_2=0$ 时，电源的输出功率；(2) 当外电路总电阻为何值时电源输出功率最大，最大值是多少。

**解析**：(1) 当 $R_2=0$ 时，外电阻 $R=R_1=4\ \Omega$，电流 $I=\frac{E}{R+r}=\frac{6}{5}=1.2\ \mathrm{A}$，输出功率 $P_{\text{出}}=I^2R=1.44\times 4=5.76\ \mathrm{W}$。

(2) 电源输出功率最大的一般条件是外电阻等于内阻，即 $R=r=1\ \Omega$。但外电路总电阻 $R=R_1+R_2\ge 4\ \Omega$，受滑动变阻器取值范围限制永远无法达到 $1\ \Omega$。在 $R>r$ 区间，输出功率 $P=\frac{E^2R}{(R+r)^2}$ 随 $R$ 减小而增大，故当 $R_2=0$（$R=4\ \Omega$）时输出功率最大：

$P_{\max}=\frac{E^2R}{(R+r)^2}=\frac{36\times 4}{(4+1)^2}=\frac{144}{25}=5.76\ \mathrm{W}$。

**易错点：$P_{\max}=\frac{E^2}{4r}$ 成立的前提是外电阻可变且能达到 $r$；当外电阻存在最小值约束（$R_{\min}>r$）时，最大输出功率出现在外电阻最小处，不可盲目套公式。**

## 本章小结与常见错误

1. 欧姆定律用于非纯电阻电路（电动机等），误用 $U=IR$ 导致电功与电热混淆。
2. 电源输出功率最大条件 $R=r$ 忘记了变量取值范围，直接套公式得到不可能的结论。
3. 串并联规律张冠李戴：串联分压、并联分流，电压电流分配关系混淆。
4. 伏安特性曲线中误把 $I-U$ 图斜率当电阻，正确电阻为该点纵坐标与横坐标之比（切线斜率只反映该点动态电阻）。

## 全册复习提示

- 动量与能量的双守恒观点是高中物理的"心脏"，碰撞、爆炸、反冲、滑块-木板模型是高考必考综合载体。
- 静电场部分抓住"场强—电势—电势能—电场力做功"四条主线，熟练使用电场线、等势面两种工具。
- 恒定电流以闭合电路欧姆定律为核心，动态分析、含容电路、伏安特性曲线三大题型必须过关。
