# 初中物理初三下册课程讲义
课程编号：junior_physics_g9s2　适用学段：初中　年级：初三　学期：下学期

本讲义依据人教版初中物理九年级全一册（下册部分）教学内容编写，围绕电功率、电与磁、能源与可持续发展三大章节展开，完成初中物理全部核心内容的学习，并衔接中考与高中物理。

## 第一章 电功率

本章学习电能与电功、电功率的概念与计算、焦耳定律以及家庭电路与安全用电，理解用电器消耗电能的多少和快慢，掌握电学综合计算方法。

### 1.1 电能与电功

- **电能**：电能是由其他形式的能转化而来的能量形式，单位是焦耳（J），家庭用电常用"千瓦时"（kW·h）作单位，俗称"度"，1 kW·h = 1 度 = 3.6×10⁶ J。
- **电功**：电流所做的功叫电功，用 W 表示，表示电能转化为其他形式能的多少。电功的公式为 W = UIt，即电流做功的大小等于电压、电流和通电时间的乘积。
- **电功的计算**：由 W = UIt 结合欧姆定律，纯电阻电路中还可推出 W = I²Rt 和 W = U²t/R。
- **电能表（电度表）**：测量用电器消耗电能的仪表。电能表上的参数：如"220 V 10(20) A 600 revs/(kW·h)"，表示额定电压 220 V、标定电流 10 A、每消耗 1 kW·h 电能转盘转 600 转。读数时注意最后一位是小数位。

### 1.2 电功率

- **电功率的概念**：电流做功的快慢叫电功率，用 P 表示，等于电功与时间之比，公式为 P = W/t。
- **电功率的计算**：P = UI（普通适用），纯电阻电路中还可由欧姆定律推出 P = I²R 和 P = U²/R。单位是瓦特（W），常用单位还有千瓦（kW），1 kW = 10³ W。
- **额定功率与实际功率**：用电器在额定电压下工作时的功率叫额定功率（由铭牌标出）；用电器在实际电压下工作时的功率叫实际功率。实际功率随实际电压变化：实际电压等于额定电压时，实际功率等于额定功率；实际电压小于额定电压时，实际功率小于额定功率。实际功率由实际电压决定，不能超过额定功率长时间工作。
- **灯泡亮暗的判断**：灯泡的亮暗由实际功率决定，实际功率越大灯泡越亮，与额定功率无关。

### 1.3 焦耳定律

- **电流的热效应**：电流通过导体时电能转化为内能的现象叫电流的热效应，如电炉、电饭锅、电热毯都是利用这一原理工作的。
- **焦耳定律内容**：电流通过导体产生的热量跟电流的二次方成正比，跟导体的电阻成正比，跟通电时间成正比。
- **焦耳定律公式**：Q = I²Rt。在纯电阻电路中（电能全部转化为内能），Q = W = UIt。
- **电热的利用与防止**：利用——电热器（电烙铁、电热毯、电热水器）；防止——散热孔、散热风扇等。

### 1.4 家庭电路与安全用电

- **家庭电路的组成**：进户线（火线和零线，火线与零线间电压 220 V）、电能表、总开关、保险装置（保险丝或空气开关）、插座和用电器。各用电器之间并联，开关与所控制的用电器串联且接在火线上。
- **三孔插座与三脚插头**：三孔插座的三个孔分别接火线、零线和地线，三脚插头中较长的脚（接外壳的脚）插入接地孔，防止用电器外壳带电时触电。
- **触电形式**：单线触电（人站在地面上接触火线）和双线触电（人同时接触火线和零线）。安全电压一般不高于 36 V。
- **安全用电原则**：不接触低压带电体，不靠近高压带电体；不用湿手触摸电器；更换灯泡、搬动电器前应断开电源开关；发现有人触电应先切断电源或用绝缘体挑开电线，不能直接用手拉人。

### 例题

**例题1（计算题）**：某电热水壶的铭牌上标有"220 V 1100 W"字样。求：（1）该电热水壶正常工作时的电流；（2）该电热水壶正常工作时电阻丝的电阻（结果保留整数）。

**分析**：正常工作即实际电压等于额定电压 220 V、实际功率等于额定功率 1100 W，由 P = UI 求电流，由 R = U²/P 求电阻。

**解答**：（1）由 P = UI 得 I = P/U = 1100 W ÷ 220 V = 5 A。（2）由 P = U²/R 得 R = U²/P = (220 V)² ÷ 1100 W = 48400 ÷ 1100 Ω = 44 Ω。

**答案**：正常工作电流为 5 A，电阻丝的电阻为 44 Ω。

## 本章小结与常见错误

1. **额定功率与实际功率混淆**：额定功率是铭牌上的固定值，实际功率随实际电压变化，灯泡的亮暗取决于实际功率而不是额定功率。
2. **单位换算错误**：kW·h 与 J 换算时用错进率，1 kW·h = 3.6×10⁶ J；P = UI 中若电压用 kV、电流用 mA，结果数量级容易出错，应统一用 V、A、W。
3. **焦耳定律适用范围错误**：Q = I²Rt 对任何电路都成立，而 Q = W = UIt 只适用于纯电阻电路，电动机等非纯电阻电路不能用 Q = UIt 计算电热。
4. **电能表读数错误**：电能表示数的最后一位是小数位，抄表或计算消耗电能时容易多读一位或少读一位。

## 第二章 电与磁

本章学习磁场与磁感线、电流的磁效应、电磁铁、电动机与发电机的原理，理解电与磁相互联系、相互转化的规律。

### 2.1 磁场与磁感线

- **磁现象**：物体具有吸引铁、钴、镍等物质的性质叫磁性，具有磁性的物体叫磁体。磁体上磁性最强的部分叫磁极，分南极（S）和北极（N），同名磁极相互排斥，异名磁极相互吸引。
- **磁化**：使原来没有磁性的物体获得磁性的过程叫磁化，如钢针被磁铁摩擦后具有磁性。
- **磁场**：磁体周围存在磁场，磁场是真实存在的特殊物质。磁场的基本性质是对放入其中的磁体产生磁力的作用。规定小磁针静止时北极所指的方向为该点磁场方向。
- **磁感线**：为了形象描述磁场而假想的带箭头的曲线，磁感线上某点的切线方向表示该点的磁场方向。磁体外部磁感线从 N 极出发回到 S 极，内部从 S 极回到 N 极，磁感线是闭合曲线且不相交。
- **地磁场**：地球周围存在磁场，地磁场的南极在地理北极附近，地磁场的北极在地理南极附近。指南针（司南）就是利用地磁场工作的。

### 2.2 电生磁（电流的磁效应）

- **电流的磁效应**：1820 年，丹麦物理学家奥斯特发现通电导线周围存在磁场，即电流的磁效应。电流的磁场方向与电流方向有关。
- **通电螺线管的磁场**：通电螺线管外部的磁场与条形磁体的磁场相似，其磁极方向与电流方向有关。
- **安培定则（右手螺旋定则）**：用右手握住螺线管，四指指向电流的方向，大拇指所指的方向就是螺线管的北极（N 极）。
- **电磁铁**：内部插有铁芯的通电螺线管叫电磁铁。磁性强弱与电流大小、线圈匝数有关（电流越大、匝数越多磁性越强），优点是可以控制磁性的有无、强弱和磁极方向。应用：电磁起重机、电磁继电器、电铃、磁悬浮列车。

### 2.3 电动机与电磁感应

- **磁场对通电导线的作用**：通电导线在磁场中受到力的作用，受力方向与电流方向和磁场方向有关。电动机就是利用通电线圈在磁场中受力转动的原理制成的，工作时将电能转化为机械能。
- **电动机与换向器**：直流电动机中换向器的作用是当线圈刚转过平衡位置时自动改变线圈中的电流方向，使线圈持续转动。生活中电风扇、洗衣机、电动车都用电动机。
- **电磁感应**：1831 年，英国物理学家法拉第发现了电磁感应现象：闭合电路的一部分导体在磁场中做切割磁感线运动时，导体中会产生电流，这种电流叫感应电流。产生感应电流的条件是"闭合电路"和"部分导体切割磁感线"两个条件同时满足。
- **发电机**：发电机是利用电磁感应现象制成的，工作时将机械能转化为电能，产生的电流方向随时间周期性变化，叫交变电流。我国电网交流电的频率是 50 Hz，即每秒完成 50 次周期性变化（方向改变 100 次）。

### 例题

**例题2（判断题）**：判断下列说法是否正确，并说明理由：（1）闭合电路的一部分导体在磁场中运动时，导体中一定会产生感应电流；（2）电动机工作时把电能转化为机械能。

**分析**：根据电磁感应的产生条件和电动机的能量转化规律判断。

**解答**：（1）错误。产生感应电流必须满足"闭合电路的一部分导体做切割磁感线运动"两个条件，如果导体只是沿着磁感线方向运动而没有切割磁感线，不会产生感应电流。（2）正确。电动机利用通电线圈在磁场中受力转动，将电能转化为机械能。

**答案**：第（1）句错误，第（2）句正确，理由见解答。

## 本章小结与常见错误

1. **磁感线方向记忆错误**：磁体外部磁感线从 N 极出发回到 S 极，内部从 S 极到 N 极；地磁场中地理北极附近是地磁南极，小磁针静止时北极指向地理北方。
2. **电动机与发电机能量转化混淆**：电动机是通电线圈在磁场中受力转动，电能转化为机械能；发电机是电磁感应，机械能转化为电能。
3. **电磁感应条件缺项**：产生感应电流需要"闭合电路"和"部分导体切割磁感线"两个条件同时满足，漏掉"闭合"或误以为只要运动就有感应电流都是错误的。
4. **安培定则用错手**：判断通电螺线管磁极用右手（四指指向电流方向，拇指指向 N 极），不要用左手，也不要让四指指向磁感线方向。

## 第三章 能源与可持续发展

本章学习能源的分类、核能的利用、能量转化与守恒定律以及能源与环境问题，树立节能环保和可持续发展的意识。

### 3.1 能源及其分类

- **一次能源与二次能源**：可以直接从自然界获取的能源叫一次能源，如煤、石油、天然气、风能、水能、太阳能、核能；无法从自然界直接获取、必须通过一次能源的消耗才能得到的能源叫二次能源，如电能、煤气、汽油、焦炭。
- **可再生能源与不可再生能源**：可以从自然界源源不断得到补充的能源叫可再生能源，如风能、水能、太阳能、生物质能；在短期内不能从自然界得到补充的能源叫不可再生能源，如煤、石油、天然气（化石能源）、核能。
- **常规能源与新能源**：煤、石油、天然气等长期广泛使用的能源叫常规能源；核能、太阳能、潮汐能、地热能等新近才开始利用的能源叫新能源。

### 3.2 核能

- **核能**：原子核发生变化（裂变或聚变）时释放出的巨大能量叫核能。核能来源于原子核内部的巨大能量。
- **核裂变**：用中子轰击较大的原子核，使其分裂成两个中等大小的原子核，同时释放出能量的过程叫核裂变。链式反应可以不加控制地释放能量（原子弹），也可以在反应堆中加以控制（核电站）。核电站的核心设备是核反应堆，利用可控核裂变释放能量。
- **核聚变**：两个质量较小的原子核结合成质量较大的原子核，同时释放出能量的过程叫核聚变，也叫热核反应。核聚变放出的能量比裂变更大，氢弹利用的是核聚变，太阳内部每时每刻都在进行核聚变。可控核聚变（人造太阳）是人类正在研究的理想能源。
- **核电站的能量转化**：核能 → 内能 → 机械能 → 电能。

### 3.3 能量转化与守恒定律

- **能量守恒定律**：能量既不会凭空消灭，也不会凭空产生，它只会从一种形式转化为其他形式，或者从一个物体转移到其他物体，而在转化和转移的过程中，能量的总量保持不变。
- **能量转化的普遍性**：各种形式的能量都可以相互转化，如电能可以转化为机械能（电动机）、内能（电热器）、光能（灯泡）、化学能（充电电池）等。
- **能量转化与守恒的理解**：能量守恒定律是自然界最普遍、最重要的定律之一，它告诉我们能量不会消失，但能量的转化和转移具有方向性，可利用的能量会减少，因此要节约能源。

### 3.4 能源与可持续发展

- **能源危机与环境污染**：煤、石油等化石能源储量有限且不可再生，大量使用会排放二氧化碳（温室效应）、二氧化硫和氮氧化物（酸雨）以及粉尘，造成严重的环境污染。
- **未来的理想能源**：未来的理想能源应满足资源丰富、价格便宜、安全清洁、对环境无污染等要求。太阳能、风能、水能、地热能、核能等是重要的开发方向。
- **太阳能的利用**：直接利用太阳能的三种方式：光热转换（太阳能热水器）、光电转换（太阳能电池板）、光化转换（植物的光合作用）。太阳能具有取之不尽、清洁无污染的优点，但受天气和地域影响，能量分散、不稳定。
- **可持续发展**：提高能源利用效率，开发利用新能源，节约能源，减少污染，实现人与自然的和谐发展。

### 例题

**例题3（判断题）**：判断下列说法是否正确，并说明理由：（1）根据能量守恒定律，能量既不会消灭也不会产生，所以我们可以随便使用能源，不必节约；（2）核电站是利用可控核裂变来发电的。

**分析**：结合能量转化与守恒定律的方向性以及核电站的工作原理判断。

**解答**：（1）错误。虽然能量总量守恒，但能量的转化和转移是有方向性的，能量经转化后可利用的能量会减少，同时化石能源等不可再生资源有限，因此必须节约能源。（2）正确。核电站利用可控的链式反应（核裂变）释放能量，将核能转化为电能。

**答案**：第（1）句错误，第（2）句正确，理由见解答。

## 本章小结与常见错误

1. **核电站原理记忆错误**：核电站利用的是可控核裂变，不是核聚变；核聚变目前还难以控制，氢弹利用的是核聚变。
2. **一次能源与二次能源判断混淆**：电能、煤气、汽油是二次能源，煤、石油、天然气、风能、水能、太阳能、核能是一次能源，判断时要看是否可直接从自然界获取。
3. **把化石能源误认为可再生能源**：煤、石油、天然气是不可再生的化石能源，短期内不能再生，储量有限。
4. **能量守恒理解偏差**：误认为"能量守恒所以能量用不完、不需要节约"，实际上能量转化和转移具有方向性，可利用能量会减少，节约能源、提高利用率十分必要。
