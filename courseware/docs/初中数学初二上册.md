# 初中数学初二上册课程讲义
课程编号：junior_math_g8s1　适用学段：初中　年级：初二　学期：上学期

本讲义依据人教版《义务教育教科书·数学》八年级上册编写，内容涵盖三角形、全等三角形、因式分解与分式三个章节。本册是初中几何证明的系统起点，也是代数恒等变形能力的重要培养期。

## 第1章 三角形

### 1.1 三角形的边与三边关系

- 由不在同一直线上的三条线段首尾顺次相接所组成的图形叫做**三角形**。三角形按边分类：不等边三角形、等腰三角形（含等边三角形）；按角分类：锐角三角形、直角三角形、钝角三角形。
- **三角形三边关系**：三角形两边的和大于第三边，两边的差小于第三边。判断三条线段能否组成三角形，只需检验"两短之和大于最长边"即可。
- 三角形有 3 条**高**（从顶点向对边作垂线）、3 条**中线**（连接顶点与对边中点）和 3 条**角平分线**（平分内角的线段），它们都是线段，且都交于一点（重心、垂心、内心等）。
- 三角形的中线把三角形分成面积相等的两个三角形；三角形的稳定性源于三边长度确定后形状唯一。

### 1.2 三角形的内角和与外角

- **内角和定理**：三角形三个内角的和等于 180°。证明方法是过顶点作平行线，利用平行线的性质把三个角转化到同一个顶点或同一条直线上。
- 直角三角形的两个锐角**互余**；有两个角互余的三角形是直角三角形。
- **外角**：三角形的一边与另一边的延长线组成的角叫做三角形的外角，三角形共有 6 个外角（每个顶点处两个，且相等）。三角形的外角等于与它不相邻的两个内角的和，并且外角大于任何一个与它不相邻的内角。
- 一个三角形三个外角的和为 360°；n 边形的外角和恒为 360°。

### 1.3 多边形及其内角和

- **多边形**：在平面内，由一些线段首尾顺次相接组成的封闭图形叫做多边形。多边形相邻两边组成的角是它的内角，一边与另一边的延长线组成的角是它的外角。
- **对角线**：连接多边形不相邻两个顶点的线段叫做多边形的对角线。从 n 边形的一个顶点出发可以引出 (n - 3) 条对角线，把多边形分成 (n - 2) 个三角形，n 边形共有 n(n - 3)/2 条对角线。
- **内角和公式**：n 边形的内角和等于 (n - 2) × 180°。正 n 边形的每个内角为 (n - 2) × 180° / n。
- **外角和定理**：多边形的外角和等于 360°，与边数无关。利用外角和可求边数：正 n 边形每个外角 = 360°/n。

### 例题

一个多边形的内角和是外角和的 3 倍，求这个多边形的边数。

解：设这个多边形的边数为 n。

多边形的外角和为 360°，内角和为 (n - 2) × 180°。

由题意得 (n - 2) × 180° = 3 × 360°，即 (n - 2) × 180° = 1080°。

解得 n - 2 = 6，所以 n = 8。

答：这个多边形是八边形。

解析：本题关键是用好两个结论——n 边形内角和为 (n - 2) × 180°，任意多边形外角和为 360°（与边数无关）。根据"内角和是外角和的 3 倍"直接列方程求解。

## 本章小结与常见错误

1. 三边关系判断错误：已知两边为 3、7，第三边范围应是 4 < x < 10（两短之和大于第三边、差小于第三边），常误写成 7 - 3 ≤ x 或忽略边界不能取等号。
2. 内角和与外角和混淆：任意多边形的外角和恒为 360°，不随边数变化；内角和才随边数增加而增大。
3. 外角等于"与它不相邻"的两个内角之和：常把相邻（共顶点）内角也加进去，导致计算错误。
4. 对角线条数公式记错：从 n 边形一个顶点出发可作 (n - 3) 条对角线，n 边形总对角线数为 n(n - 3)/2，两者不能混用。

## 第2章 全等三角形

### 2.1 全等三角形的概念与性质

- **全等形**：能够完全重合的两个图形叫做全等形。**全等三角形**：能够完全重合的两个三角形叫做全等三角形。重合的顶点叫对应顶点，重合的边叫对应边，重合的角叫对应角。
- 记法：△ABC ≌ △DEF，书写时对应顶点写在对应位置上，这便于确定对应边、对应角。
- **全等三角形的性质**：全等三角形的对应边相等，对应角相等；全等三角形的对应边上的高、中线及对应角的平分线相等；全等三角形的周长、面积相等。
- 找对应元素的方法：对应角所对的边是对应边，对应边所对的角是对应角；公共边、公共角通常是对应边、对应角。

### 2.2 全等三角形的判定（SSS、SAS、ASA、AAS）

- **SSS**（边边边）：三边分别相等的两个三角形全等。这也是三角形稳定性的依据。
- **SAS**（边角边）：两边和它们的夹角分别相等的两个三角形全等。注意是"夹角"，即两边的夹角，不能是"两边和其中一边的对角"。
- **ASA**（角边角）：两角和它们的夹边分别相等的两个三角形全等。
- **AAS**（角角边）：两角和其中一个角的对边分别相等的两个三角形全等。
- 判定思路：已知两角，用 ASA 或 AAS（ASA 用夹边，AAS 用对边）；已知两边，用 SAS（找夹角）；已知一边一角，需再找一边（SAS、SSS）或一角（ASA、AAS）。

### 2.3 直角三角形的判定（HL）与全等应用

- **HL**（斜边、直角边）：斜边和一条直角边分别相等的两个直角三角形全等。HL 是直角三角形特有的判定方法，不要误用到一般三角形上。
- 证明两三角形全等的一般步骤：观察图形找已知条件（公共边、公共角、对顶角等）→ 结合已知选择恰当的判定方法 → 规范书写"在 △ABC 和 △DEF 中" → 列出条件 → 得出结论"∴ △ABC ≌ △DEF（SSS/SAS/…）"。
- 全等三角形是证明线段相等、角相等的常用工具：通过证明两个三角形全等，把要证的相等关系转化为对应边、对应角的关系。
- 常见辅助线：证明线段或角相等时可考虑构造全等三角形，如倍长中线法、截长补短法等。

### 例题

已知：如图，点 B、E、C、F 在同一条直线上，AB = DE，AC = DF，BE = CF。求证：AB ∥ DE。

证明：因为 BE = CF，所以 BE + EC = CF + EC，即 BC = EF。

在 △ABC 和 △DEF 中，

AB = DE（已知），AC = DF（已知），BC = EF（已证），

所以 △ABC ≌ △DEF（SSS）。

所以 ∠B = ∠DEF（全等三角形对应角相等），所以 AB ∥ DE（同位角相等，两直线平行）。

解析：本题先用"BE = CF"推出"BC = EF"（等量加等量，和相等），再依据 SSS 判定全等，最后由对应角相等结合平行线判定完成证明。全程要书写规范、逻辑严密。

## 本章小结与常见错误

1. 误用"SSA"或"AAA"判定：两边和其中一边的对角相等（SSA）或三个角相等（AAA）都不能判定两个三角形全等，要注意 SAS 中的角必须是夹角。
2. 对应关系写错：△ABC ≌ △DEF 中 B 的对应顶点是 E，若把 ∠B 写成对应 ∠F，则后续推理全部出错；书写时对应顶点位置必须一一对应。
3. 证明过程缺条件：直接由图形"看起来相等"下结论，缺少已知或已证的依据；公共边、对顶角相等必须明确写出。
4. HL 误用到非直角三角形：HL 只适用于两个直角三角形，一般三角形全等不能用 HL，只能用前面五种方法（SSS、SAS、ASA、AAS）。

## 第3章 因式分解与分式

### 3.1 因式分解与提公因式法

- **因式分解**：把一个多项式化成几个整式的积的形式，叫做因式分解。因式分解是整式乘法的逆变形，如 x² - 1 = (x + 1)(x - 1)。
- 因式分解必须彻底：每个因式都要分解到不能再分解为止，且结果中不再含中括号。
- **提公因式法**：如果多项式的各项有公因式，可以把这个公因式提出来，将多项式写成公因式与另一个因式的乘积的形式。公因式的确定：系数取各项系数的最大公因数，字母取各项都含有的相同字母，指数取最低次数。
- 注意符号：当首项系数为负时，通常先提出"−"号，括号内各项要变号；公因式提尽后，括号内剩余项数与原来项数相同。

### 3.2 公式法因式分解

- **平方差公式**：a² - b² = (a + b)(a - b)。应用条件：两项、符号相反、都能写成平方的形式。
- **完全平方公式**：a² ± 2ab + b² = (a ± b)²。应用条件：三项，其中两项为平方项且同号，第三项为两底数乘积的 2 倍。
- 分解步骤：一提（提公因式）→ 二套（套公式）→ 三查（检查是否分解彻底）。优先考虑提公因式，再考虑公式法，多项式整体可以看作一个整体（换元思想）。
- 完全平方公式的识别：如 4x² + 12x + 9 = (2x + 3)²，其中 2x 与 3 分别是两个底数，12x = 2 × 2x × 3。

### 3.3 分式的概念与基本性质

- **分式**：一般地，如果 A、B 表示两个整式，并且 B 中含有字母，那么式子 A/B 叫做分式。分式有意义的条件是分母 B ≠ 0；分式值为 0 的条件是分子 A = 0 且分母 B ≠ 0。
- **分式的基本性质**：分式的分子与分母同乘（或除以）同一个不等于 0 的整式，分式的值不变，即 A/B = A·C/(B·C)，A/B = A÷C/(B÷C)（C ≠ 0）。这是约分与通分的依据。
- **约分**：把分子、分母的公因式约去，化成最简分式（分子分母没有公因式，且分母不含根号，分子不含括号）。最简分式有时也叫既约分式。
- **通分**：把几个异分母的分式分别化成与原来分式相等的同分母分式。最简公分母的确定：系数取各分母系数的最小公倍数，字母因式取各分母中出现的最高次幂。

### 3.4 分式的运算与化简求值

- **分式的乘除**：分式乘分式，用分子的积作为积的分子，分母的积作为积的分母；分式除以分式，把除式的分子、分母颠倒位置后与被除式相乘。运算结果要化为最简分式或整式。
- **分式的加减**：同分母分式相加减，分母不变，把分子相加减；异分母分式相加减，先通分，变为同分母分式，再加减。结果必须化为最简。
- **分式的混合运算**：先乘方，再乘除，最后加减；有括号先算括号里的。化简求值题一般先化简，再代入所给数值计算，代入时要注意使原分式及化简过程中出现的分式都有意义。
- 分式的乘方：(A/B)ⁿ = Aⁿ/Bⁿ（n 为正整数）。运算中若分子、分母能因式分解，应先因式分解再约分，使运算简便。

### 例题

先化简，再求值：(1 - 1/(x + 2)) ÷ (x² + 2x + 1)/(x + 2)，其中 x = 3。

解：原式 = ((x + 2) - 1)/(x + 2) ÷ (x + 1)²/(x + 2)

= (x + 1)/(x + 2) × (x + 2)/(x + 1)²

= 1/(x + 1)。

当 x = 3 时，原式 = 1/(3 + 1) = 1/4。

解析：括号内先通分，除法转化为乘法（颠倒除式），约分时要注意 x + 2 与 x + 1 不能为 0（即 x ≠ -2 且 x ≠ -1），x = 3 满足条件。化简后再代入，过程简洁且不易出错。

## 本章小结与常见错误

1. 因式分解不彻底：如把 a⁴ - b⁴ 只分解成 (a² + b²)(a² - b²)，还应继续分解为 (a² + b²)(a + b)(a - b)。
2. 分式有意义的条件与值为 0 的条件混淆：分式 A/B 有意义要求 B ≠ 0；值为 0 要求 A = 0 且 B ≠ 0，两个条件缺一不可。
3. 分式加减"去分母"错误：解分式方程才去分母，分式的加减运算是通分后"分母不变、分子相加减"，不能把分子、分母同时消掉。
4. 约分漏掉符号或错误约分：约分只能约分子与分母的"公因式"，不能约公因式外的项，如 (x + 2)/(x + 1) 中的 x 不能直接约去。
