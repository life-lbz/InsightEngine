# 高中物理高三下册课程讲义
课程编号：senior_physics_g12s2　适用学段：高中　年级：高三　学期：下学期

> 本册为二轮复习讲义，聚焦压轴题突破与综合模拟应试，重在提升建模能力、多过程处理能力与考场得分能力。

## 第一章 压轴题突破

### 1.1 物理建模方法

- **建模思维**：把复杂实际问题抽象为熟悉的物理模型（质点、匀变速直线运动、平抛、圆周、滑块—木板、单棒导轨、带电粒子在复合场中的运动等）。
- 建模四步：
  1. 读题找关键词："光滑"（无摩擦）、"恰好""刚好"（临界）、"缓慢"（平衡，动能定理变形式）、"最大""最小"（极值）。
  2. 画情景图：受力图、运动过程图、轨迹图，把文字转化为图形。
  3. 确定模型：判断属于哪个基本模型，直接套用该模型的结论与方法。
  4. 检验：看结果是否符合物理意义（速度方向、能量变化、动量守恒条件）。
- 常见隐含条件翻译：轻绳（张力相等、不能承受压力）、轻杆（可承受拉压）、理想电表、不计电阻的导轨等。
- 重点模型突破：板块模型（共速后是否一起运动要重新判断摩擦力）、传送带模型（物体与带速度相等后是否还受摩擦力）、绳杆突变模型（绳拉直瞬间、杆转动）。

### 1.2 多过程问题处理策略

- 多过程问题的本质是"几个单过程 + 衔接条件"的组合。处理策略：
  - 拆：把整个过程拆成若干子过程（每段受力、运动性质相对单一）。
  - 接：寻找衔接条件——前后两段的速度、位置连续；碰撞、爆炸、绳拉直等"突变点"要单独分析动量与能量。
  - 选：每段选择合适观点，能量优先用动能定理/机械能守恒，时间与冲量用动量定理，共速用动量守恒。
- 突变点分类：
  - 碰撞：动量守恒，动能可能损失。
  - 绳绷紧：沿绳方向速度突变（动量守恒，垂直于绳的速度不变），能量有损失。
  - 脱离接触（如小球脱离圆弧轨道最高点）：压力为零，$F_N=0$ 为临界条件。
  - 恰好到最高点：绳模型 $v=\sqrt{gr}$，杆模型 $v=0$。
- 解题规范：分步列式并编号，每式注明物理依据，结果带单位，最后检验合理性。

### 1.3 图像与数形结合

- 高考压轴题常结合图像考查信息提取能力：v-t 图、x-t 图、F-a 图、U-I 图、$\Phi$-t 图、E-t 图、I-t 图。
- 图像问题五要素：点（交点、截点、极值点）、线（斜率、切线）、面积（围成面积的意义）、截距、走向（增减、对称、周期性）。
- 常见面积含义：v-t 图面积 = 位移；F-x 图面积 = 功；F-t 图面积 = 冲量；E-t 图面积 = 磁通量变化量；I-t 图面积 = 电荷量。
- 由图像反推运动：已知 v-t 图 → 求位移、加速度 → 结合牛顿定律求力；已知 $\Phi$-t 图 → 斜率即 $\frac{\Delta\Phi}{\Delta t}$ → 求感应电动势。

### 1.4 压轴题中的临界与极值问题

- 临界条件总结：
  - 恰好滑动：静摩擦力达到最大值。
  - 恰好分离：两物体间压力（弹力）为零。
  - 恰好通过最高点（绳）：$v_{\min}=\sqrt{gr}$。
  - 带电粒子恰好不飞出磁场：轨迹与边界相切。
  - 恰好到达某点速度为零：由动能定理联立。
- 极值问题工具：二次函数求极值、均值不等式（$a+b\ge 2\sqrt{ab}$）、三角函数（$\sin\theta$ 最值）、判别式法、图像法。
- 求解流程：找临界状态 → 列临界方程 → 联立求解 → 讨论结果。

### 例题

**例1（压轴题突破）**：如图所示，水平光滑轨道 AB 与半径为 $R=0.8\ \mathrm{m}$ 的竖直光滑半圆轨道 BC 相切于 B 点。质量 $m=1\ \mathrm{kg}$ 的小球以初速度 $v_0$ 从 A 点出发，恰好能通过最高点 C，不计空气阻力（$g=10\ \mathrm{m/s^2}$）。求：(1) 小球在 C 点的速度；(2) 小球在 B 点对轨道的压力；(3) 初速度 $v_0$ 的大小。

**解析**：(1) 恰好通过最高点 C（绳/轨道模型临界）：重力提供向心力 $mg=m\frac{v_C^2}{R}$，$v_C=\sqrt{gR}=\sqrt{10\times 0.8}=2\sqrt{2}\ \mathrm{m/s}\approx 2.83\ \mathrm{m/s}$。

(2) B 到 C 机械能守恒：$\frac{1}{2}mv_B^2=\frac{1}{2}mv_C^2+mg\cdot 2R$，$v_B^2=v_C^2+4gR=8+32=40$。

B 点由牛顿第二定律：$N-mg=m\frac{v_B^2}{R}$，$N=mg+m\frac{v_B^2}{R}=10+\frac{1\times 40}{0.8}=60\ \mathrm{N}$。由牛顿第三定律，小球对轨道的压力为 60 N，方向竖直向下。

(3) A 到 B 光滑轨道，$v_A=v_B=\sqrt{40}=2\sqrt{10}\ \mathrm{m/s}\approx 6.32\ \mathrm{m/s}$。

**易错点：本题为"轨道模型"，最高点临界速度是 $\sqrt{gR}$；若为杆模型临界速度则是零，两种模型必须区分。B 点压力计算要用 $v_B^2$ 的整体代换，避免来回开方引入误差。**

## 本章小结与常见错误

1. 临界条件张冠李戴：绳模型与杆模型最高点临界速度混淆（$\sqrt{gR}$ 与 0），导致能量方程错误。
2. 多过程问题忽略"突变点"的能量损失（如绳绷紧、碰撞、子弹嵌入），全程机械能守恒式写错。
3. 图像题把面积、斜率的物理意义记反，如误把 v-t 图斜率当位移、面积当加速度。
4. 压轴题"恰好""刚好"类条件不会转化为方程，找不到临界状态对应的数学表达式。

## 第二章 综合模拟与应试

### 2.1 高考物理题型结构

- 全国卷及多数新高考省份物理卷结构（参考）：
  - 单项选择题（每题 4 分，多为基础与中档题）。
  - 多项选择题（每题 6 分，选对但不全得部分分，有选错得 0 分）。
  - 实验题（两道，一力一电，共约 15 分，含读数、连线、数据处理）。
  - 计算题（两道，中档与压轴，共约 32 分）。
  - 选考/必考模块（热学、机械波或光学等，约 15 分）。
- 分值分布规律：力学约 45%、电学约 40%、其他（热、光、原子）约 15%。
- 高频考点：匀变速直线运动与图象、牛顿定律与连接体、动能定理与机械能守恒、动量守恒、带电粒子在复合场中运动、电磁感应单双棒、理想变压器与远距离输电、实验读数与设计。

### 2.2 答题规范与得分策略

- 计算题规范书写"七要素"：
  1. 研究对象与过程说明。
  2. 原始方程（不跳步、不写合并式，分步列式便于踩点得分）。
  3. 代入数据（写单位）。
  4. 结果（数字 + 单位，注意有效数字）。
  5. 矢量注明方向。
  6. 必要的文字说明（如"由动量守恒得""由动能定理得"）。
  7. 结论回扣题目设问。
- 选择题策略：排除法、特值法（取特殊值如 $45°$、极限情形）、图象法、单位检验法；多选题宁缺毋滥（不确定的选项不选）。
- 实验题策略：读数先看分度值；连线先串联再并联；数据处理作图用铅笔直尺，舍去明显偏离点。
- 压轴题策略：即使不能完整求解，也要写对前几步（受力分析方程、守恒方程），按过程踩点得分，切忌空白。

### 2.3 时间管理与考前调整

- 时间分配建议（总分 100 分，90 分钟）：
  - 选择题：30~35 分钟（每题控制在 2 分钟以内，卡壳果断跳过）。
  - 实验题：15 分钟。
  - 计算题：35 分钟（先易后难，压轴题最后一问留 10 分钟）。
  - 检查：5~10 分钟（重点检查：单位、正负号、矢量方向、有效数字、填涂卡）。
- 考前一周调整：回归课本与错题本，不再刷难题；按高考时间做 2~3 套整卷模拟，保持手感；早睡、调整生物钟。
- 考场心态：遇到新情景题"万变不离其宗"，先圈关键词建模；先易后难，保证基础分全部拿到。

### 例题

**例2（判断题）**：判断以下说法是否正确并说明理由：

(1) 物体在变力作用下一定做曲线运动。

(2) 合力对物体做正功，物体的动能一定增大，但机械能不一定增大。

(3) 电源的输出功率最大时，电源的效率也是最大的。

(4) 电磁感应中，感应电流产生的磁场总是与原磁场方向相反。

**解析**：

(1) 错误。物体做曲线运动的条件是合外力方向与速度方向不在同一直线上，变力如果始终与速度共线（如同向变力），物体做直线运动。

(2) 正确。由动能定理，合外力做正功则动能增大；但机械能是否增大取决于除重力（弹力）外其他力是否做正功，合力做正功不等于机械能增大（如物体受阻力减速下落的特例中重力做正功而机械能减小，此处"合力做正功"的例子如：物体在拉力作用下匀速上升，合外力为零不做正功，需构造合适反例，按动能定理原理解释）。

(3) 错误。输出功率最大时 $R=r$，此时效率 $\eta=\frac{R}{R+r}=50\%$；效率最大发生在外电阻趋于无穷大（断路）时，两者不可兼得。

(4) 错误。楞次定律中感应电流的磁场是"阻碍"磁通量的变化：磁通量增大时与原磁场反向，减小时与原磁场同向，"总是相反"的说法不完整。

**易错点：判断题要抓住概念的条件与适用范围，如曲线运动条件、楞次定律"阻碍变化"的完整表述，避免绝对化结论。**

## 本章小结与常见错误

1. 多选题全选导致丢分，不会使用"不确定不选"的策略。
2. 计算题直接写综合式或结果式，不写原始方程，导致踩点失分。
3. 答题顺序不当：在压轴题最后一问耗费大量时间，导致简单题来不及做。
4. 实验读数不估读、连线不规范、图象描点不用直尺连线，白白丢规范分。

## 全册复习提示

- 二轮复习的核心是"把会做的题做对、把能做对的题做快"，压轴题每天精练 1 道并复盘建模过程。
- 建立个人错题清单：按"概念错、方法错、计算错、规范错"分类，考前重点回看。
- 最后两周进入"整卷训练 + 查漏补缺"模式，控制答题节奏，模拟真实考场环境。
- 高考物理拼的不是题海，而是模型熟练度、规范书写与心态稳定，做到"易题不丢分、难题能抢分"。
