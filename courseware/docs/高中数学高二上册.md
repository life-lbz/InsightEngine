## 第1章 空间向量与立体几何

### 1.1 空间向量及其运算

- **空间向量**：在空间中，具有大小和方向的量叫做空间向量，空间向量与平面向量一样可用有向线段表示，运算也满足平行四边形法则、三角形法则。
- **空间向量的线性运算**：加法、减法、数乘运算的法则与平面向量一致，满足交换律、结合律、分配律。共线向量定理与共面向量定理是空间向量线性运算的推广。
- **共面向量**：平行于同一平面的向量叫做共面向量。三个向量 a、b、c 共面 ⟺ 存在实数 x、y 使 c = xa + yb（a、b 不共线时），判断四点共面常用这一条件。
- **空间向量基本定理**：如果三个向量 a、b、c 不共面，那么对空间中任意向量 p，存在唯一的有序实数组 (x, y, z)，使 p = xa + yb + zc。{a, b, c} 叫空间的一个基底，任意三个不共面的向量都可作基底。
- **数量积**：a · b = |a||b| cos⟨a, b⟩，具有与平面向量相同的运算律与性质：a ⊥ b ⟺ a · b = 0，|a|² = a · a。数量积是计算空间角与距离的核心工具。

### 1.2 空间向量的坐标表示

- **空间直角坐标系**：过空间中一点 O 作三条两两垂直的数轴 x、y、z 轴，建立空间直角坐标系 O-xyz。点 P(x, y, z) 与坐标一一对应，向量 OP = (x, y, z)。
- **坐标运算**：设 a = (x₁, y₁, z₁)，b = (x₂, y₂, z₂)，则 a ± b = (x₁ ± x₂, y₁ ± y₂, z₁ ± z₂)，λa = (λx₁, λy₁, λz₁)，a · b = x₁x₂ + y₁y₂ + z₁z₂。
- **向量的模与夹角**：|a| = √(x₁² + y₁² + z₁²)；cos⟨a, b⟩ = (x₁x₂ + y₁y₂ + z₁z₂) / (|a||b|)；a ⊥ b ⟺ x₁x₂ + y₁y₂ + z₁z₂ = 0。
- **距离公式**：两点 A(x₁, y₁, z₁)、B(x₂, y₂, z₂) 的距离 |AB| = √((x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)²)。
- 建系的技巧：优先选择"墙角"（三条两两垂直的棱）为坐标轴，如长方体、直三棱柱，使尽可能多的点落在坐标轴上以简化坐标。

### 1.3 空间角与距离的计算

- **异面直线所成的角**：转化为两方向向量夹角，设两直线方向向量为 a、b，则 cos θ = |a · b| / (|a||b|)，θ ∈ (0, π/2]，夹角必取锐角或直角（加绝对值）。
- **直线与平面所成的角**：设直线方向向量为 a，平面法向量为 n，则 sin θ = |a · n| / (|a||n|)，θ ∈ [0, π/2]。
- **二面角**：设两个平面的法向量为 n₁、n₂，二面角的平面角 θ 满足 cos θ = ±(n₁ · n₂) / (|n₁||n₂|)，正负号需结合图形判断二面角是锐角还是钝角。
- **点到平面的距离**：设点 P，平面 α 内取一点 A，法向量为 n，则 d = |PA · n| / |n|，即 PA 在法向量方向上的投影长度。
- 其他距离：线面距离、面面距离通常转化为点到平面的距离；异面直线间距离可用公垂线或向量方法计算。

### 1.4 立体几何中的证明方法

- **向量法证明线线垂直**：两直线方向向量数量积为 0；证明线面垂直：直线方向向量与平面内两条相交直线的方向向量都垂直。
- **向量法证明线面平行**：直线方向向量与平面法向量垂直，且直线不在平面内；也可用线面平行的判定定理与性质定理结合。
- **向量法证明面面平行与垂直**：面面平行 ⟺ 两平面法向量共线；面面垂直 ⟺ 两平面法向量数量积为 0。
- **综合法（传统方法）**：线面平行的判定（线线平行推线面平行）、线面垂直的判定（线线垂直推线面垂直）、三垂线定理等，与向量法互为补充。解答题中常"先证后用"，几何论证与向量计算结合。
- 解题流程：建系 → 求相关点坐标 → 求方向向量、法向量 → 用公式计算夹角与距离。求法向量常用"两个点积方程联立，令某一坐标为 1"。

### 例题

在正方体 ABCD-A₁B₁C₁D₁ 中，E 为棱 A₁D₁ 的中点，求异面直线 AE 与 CC₁ 所成角的余弦值。

解：以 D 为原点，DA、DC、DD₁ 分别为 x、y、z 轴正方向建立空间直角坐标系，设正方体棱长为 2。

则 A(2, 0, 0)，E(1, 0, 2)，C(0, 2, 0)，C₁(0, 2, 2)。

所以 AE = (−1, 0, 2)，CC₁ = (0, 0, 2)。

设 AE 与 CC₁ 的夹角为 θ，则 cos θ = |AE · CC₁| / (|AE||CC₁|) = |0 + 0 + 4| / (√5 × 2) = 4/(2√5) = 2√5/5。

所以异面直线 AE 与 CC₁ 所成角的余弦值为 2√5/5。

解析：用向量法求异面直线所成角，关键是"建系取点"与"夹角取锐角"（加绝对值）。CC₁ 与 z 轴平行，其方向向量可直接取 (0, 0, 2)，不必写点的坐标；注意异面直线所成角范围是 (0, π/2]，若数量积为负应取相反数。

## 本章小结与常见错误

1. 异面直线所成角忘记取锐角：直接套用 cos θ = (a · b)/(|a||b|) 得到负值，正确应取绝对值，所求角在 (0, π/2] 内。
2. 线面角用错公式：把 sin θ = |a·n|/(|a||n|) 错写成 cos θ，导致结论错误；直线与平面所成角的正弦值等于方向向量与法向量夹角余弦的绝对值。
3. 法向量求错或方向不一致：求法向量时两个方程联立解错，或在二面角计算中未结合图形判断余弦值的正负。
4. 建系不规范：三条坐标轴不两两垂直就强行建系，或建系后点的坐标写错（如把正方体顶点 A 与 A₁ 的坐标混淆）。

## 第2章 直线与圆

### 2.1 直线的倾斜角、斜率与方程

- **倾斜角**：直线与 x 轴正方向所成的角 α（0 ≤ α < π），倾斜角不是 90° 的直线的斜率为 k = tan α。
- **斜率公式**：经过两点 P₁(x₁, y₁)、P₂(x₂, y₂)（x₁ ≠ x₂）的直线斜率 k = (y₂ − y₁)/(x₂ − x₁)。倾斜角为 90° 时斜率不存在。
- **直线方程的五种形式**：点斜式 y − y₀ = k(x − x₀)；斜截式 y = kx + b；两点式 (y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁)；截距式 x/a + y/b = 1（a、b 为截距，均不为 0）；一般式 Ax + By + C = 0（A、B 不同时为 0）。
- 截距是"坐标"而非"距离"：直线在 x 轴上的截距是直线与 x 轴交点的横坐标，可以为负、为零。用截距式时注意直线过原点或平行于坐标轴的情形不能直接用。
- 求直线方程的一般步骤：先确定用什么形式，再找条件（一点一斜率、两点、截距等），最后化为一般式作答。

### 2.2 两条直线的位置关系

- **平行**：l₁: y = k₁x + b₁ 与 l₂: y = k₂x + b₂ 平行 ⟺ k₁ = k₂ 且 b₁ ≠ b₂。一般式下，l₁ ∥ l₂ ⟺ A₁B₂ − A₂B₁ = 0 且 B₁C₂ − B₂C₁ ≠ 0（或对应系数成比例且常数项不成比例）。
- **垂直**：l₁ ⊥ l₂ ⟺ k₁k₂ = −1（斜率都存在时）。一般式下，l₁ ⊥ l₂ ⟺ A₁A₂ + B₁B₂ = 0。斜率不存在的情形（垂直于 x 轴的直线）要与另一条斜率为 0 的直线垂直，需单独考虑。
- **相交**：交点坐标由方程组联立解得。三条直线交于一点或两两平行的判定，都可转化为方程组的解的讨论。
- **距离公式**：两点间距离 |P₁P₂| = √((x₂ − x₁)² + (y₂ − y₁)²)；点到直线距离 d = |Ax₀ + By₀ + C| / √(A² + B²)；两条平行直线 Ax + By + C₁ = 0 与 Ax + By + C₂ = 0 的距离 d = |C₁ − C₂| / √(A² + B²)。
- 对称问题：点关于直线对称（垂直平分），直线关于点或直线的对称，常用中点坐标与斜率乘积为 −1 求解。

### 2.3 圆的方程

- **圆的标准方程**：(x − a)² + (y − b)² = r²，其中圆心 (a, b)，半径 r > 0。圆心在原点时为 x² + y² = r²。
- **圆的一般方程**：x² + y² + Dx + Ey + F = 0（D² + E² − 4F > 0），圆心 (−D/2, −E/2)，半径 r = 1/2 · √(D² + E² − 4F)。当 D² + E² − 4F = 0 时表示一个点，小于 0 时不表示任何图形。
- 一般式化标准式用配方法：把 x、y 分别配方。求圆的方程常用"待定系数法"：设标准式或一般式，代条件求参数。
- 确定圆需要三个独立条件：圆心和半径（标准式三参数 a、b、r），或三个点的坐标（一般式三参数 D、E、F）。圆经过某点，则该点坐标满足方程。

### 2.4 直线与圆、圆与圆的位置关系

- **直线与圆的位置关系**：相离（d > r）、相切（d = r）、相交（d < r），其中 d 为圆心到直线的距离。用距离判断比联立判别式更简便；用判别式 Δ 也可判断，Δ > 0 相交、Δ = 0 相切、Δ < 0 相离。
- **弦长公式**：直线被圆截得的弦长 = 2√(r² − d²)，其中 d 为弦心距。弦的中点与圆心连线垂直于弦。
- **圆的切线**：过圆上一点的切线方程（点斜式结合半径垂直）；过圆外一点作圆的切线有两条，用圆心到切线距离等于半径求斜率（注意斜率不存在的切线）。
- **圆与圆的位置关系**：设两圆半径 R、r（R ≥ r），圆心距 d，则外离 d > R + r，外切 d = R + r，相交 |R − r| < d < R + r，内切 d = |R − r|，内含 d < |R − r|。
- **圆系与最值**：两圆相交时公共弦所在直线方程由两圆方程相减得到；圆上点到定点或定直线距离的最值问题，转化为圆心到目标的距离加减半径。

### 例题

已知圆 C：x² + y² − 2x + 4y − 4 = 0，直线 l：3x + 4y − 1 = 0，求直线 l 被圆 C 截得的弦长。

解：圆 C 化为标准方程：(x − 1)² + (y + 2)² = 9，故圆心 C(1, −2)，半径 r = 3。

圆心到直线 l 的距离 d = |3 × 1 + 4 × (−2) − 1| / √(3² + 4²) = |3 − 8 − 1| / 5 = 6/5。

弦长 = 2√(r² − d²) = 2√(9 − 36/25) = 2√(189/25) = 2 × 3√21/5 = 6√21/5。

所以直线 l 被圆 C 截得的弦长为 6√21/5。

解析：求弦长优先用"弦心距—半径—半弦长"构成的直角三角形：半弦长 = √(r² − d²)。本题先配方化标准方程得圆心与半径，再用点到直线距离公式求 d，最后代入弦长公式。注意 r² − d² 的结果要开方完全（9 − 36/25 = 225/25 − 36/25 = 189/25 = 21 × 9/25）。

## 本章小结与常见错误

1. 斜率不存在的情形漏讨论：设点斜式或斜截式解题时，默认直线斜率存在，遗漏垂直于 x 轴的直线，导致少解。
2. 距离公式符号错误：点到直线距离代入点坐标时，字母前面的符号处理错误；平行直线距离公式中 x、y 系数必须相同才能直接用。
3. 圆的一般方程条件忽略：忘记 D² + E² − 4F > 0 的判断，把退化情形当作圆处理；或配方法配方错误导致圆心、半径算错。
4. 切线条数判断错误：过圆外一点作切线有两条，错认为一条；或求切线斜率时忽略斜率不存在的切线，漏解。

## 第3章 圆锥曲线

### 3.1 椭圆

- **定义**：平面内与两个定点 F₁、F₂ 的距离之和等于常数 2a（2a > |F₁F₂|）的点的轨迹叫做椭圆，F₁、F₂ 叫焦点，|F₁F₂| = 2c 叫焦距。定义中的常数 2a 必须大于焦距，否则轨迹不是椭圆。
- **标准方程**：焦点在 x 轴上时 x²/a² + y²/b² = 1（a > b > 0），焦点在 y 轴上时 y²/a² + x²/b² = 1。其中 a² = b² + c²，a 为长半轴长，b 为短半轴长。
- **几何性质**：范围 |x| ≤ a，|y| ≤ b；对称性（关于 x 轴、y 轴、原点对称，对称中心为原点）；顶点 (±a, 0)、(0, ±b)；离心率 e = c/a ∈ (0, 1)，e 越接近 0 椭圆越圆，越接近 1 椭圆越扁。
- **焦点三角形**：椭圆上一点 P 与两焦点构成的三角形中，∠F₁PF₂ 满足 |PF₁| + |PF₂| = 2a，面积 S = b² tan(θ/2)（θ = ∠F₁PF₂），可用于求面积与角。
- 通径：过焦点垂直于长轴的弦，长度为 2b²/a，是椭圆中的重要几何量，常出现在弦长问题中。

### 3.2 双曲线

- **定义**：平面内与两个定点 F₁、F₂ 的距离之差的绝对值等于常数 2a（0 < 2a < |F₁F₂|）的点的轨迹叫做双曲线。差为 2a 表示一支，差为 −2a 表示另一支，取绝对值才表示整个双曲线。
- **标准方程**：x²/a² − y²/b² = 1（焦点在 x 轴）或 y²/a² − x²/b² = 1（焦点在 y 轴）。其中 c² = a² + b²，实轴长 2a，虚轴长 2b。
- **渐近线**：x²/a² − y²/b² = 1 的渐近线为 y = ±(b/a)x；y²/a² − x²/b² = 1 的渐近线为 y = ±(a/b)x。渐近线方程可由标准方程"右边 1 改为 0"得到，是双曲线独有的性质。
- **几何性质**：离心率 e = c/a > 1；e 越接近 1，双曲线开口越狭窄（接近两直线），e 越大开口越开阔。
- **等轴双曲线**：a = b 时方程为 x² − y² = a²，渐近线互相垂直（y = ±x），离心率 e = √2。与渐近线有关的问题常用"设双曲线为 x²/a² − y²/b² = λ（λ ≠ 0）"的技巧。

### 3.3 抛物线

- **定义**：平面内与一个定点 F 和一条定直线 l（F 不在 l 上）的距离相等的点的轨迹叫做抛物线，F 叫焦点，l 叫准线。
- **标准方程与性质**：y² = 2px（p > 0）的焦点 (p/2, 0)，准线 x = −p/2，开口向右；y² = −2px 开口向左；x² = 2py 开口向上，焦点 (0, p/2)，准线 y = −p/2；x² = −2py 开口向下。p 叫焦准距。
- 抛物线的离心率 e = 1（圆锥曲线的统一定义：到焦点与到准线距离之比为离心率，椭圆 e ∈ (0, 1)，双曲线 e > 1，抛物线 e = 1）。
- **焦点弦**：过焦点的弦叫焦点弦。设焦点弦两端点坐标为 A(x₁, y₁)、B(x₂, y₂)（y² = 2px），则 x₁x₂ = p²/4，y₁y₂ = −p²，|AB| = x₁ + x₂ + p。
- 抛物线上的点到焦点的距离等于到准线的距离，这一性质常把"到焦点的距离"转化为"到准线的距离"，简化最值问题。

### 3.4 直线与圆锥曲线的位置关系

- **位置关系的判定**：联立直线方程与圆锥曲线方程消元得一元二次方程，用判别式 Δ 判断：Δ > 0 有两个交点，Δ = 0 相切，Δ < 0 相离。直线与双曲线渐近线平行、与抛物线对称轴平行时，消元后为一次方程，只有一个交点（不是相切）。
- **弦长公式**：|AB| = √(1 + k²) · |x₁ − x₂| = √(1 + 1/k²) · |y₁ − y₂|（k 为直线斜率），其中 |x₁ − x₂| = √Δ / |a|（a 为消元后二次项系数）。
- **中点弦问题**：用"点差法"（设而不求）：设弦两端点坐标代入曲线方程相减，结合中点坐标与斜率关系，可求弦中点轨迹或直线方程。
- **设而不求思想**：设交点坐标而不具体求出，用韦达定理整体代换，是解析几何解答题的核心思想，配合"判别式 ≥ 0"检验直线存在性。
- 涉及焦点的问题优先考虑定义转化，涉及中点优先点差法，涉及弦长优先弦长公式，涉及垂直优先数量积，形成解题的"条件—方法"对应。

### 例题

已知椭圆 C：x²/4 + y²/3 = 1，斜率为 1 的直线 l 与椭圆交于 A、B 两点，且线段 AB 的中点为 M(1, m)，求 m 的值与 |AB|。

解：设 A(x₁, y₁)、B(x₂, y₂)，代入椭圆方程得 x₁²/4 + y₁²/3 = 1，x₂²/4 + y₂²/3 = 1。

两式相减得 (x₁ − x₂)(x₁ + x₂)/4 + (y₁ − y₂)(y₁ + y₂)/3 = 0。

因为 AB 中点为 M(1, m)，故 x₁ + x₂ = 2，y₁ + y₂ = 2m，且直线斜率 k = (y₁ − y₂)/(x₁ − x₂) = 1。

代入得 2/4 + 2m/(3 × 1) = 0，即 1/2 + 2m/3 = 0，解得 m = −3/4。

直线 l 的方程为 y = x − 3/4，与椭圆联立消 y 得 3x² + 4(x − 3/4)² = 12，即 7x² − 6x − 45/4 = 0，即 28x² − 24x − 45 = 0。

Δ = (−24)² − 4 × 28 × (−45) = 576 + 5040 = 5616 = 144 × 39，x₁ + x₂ = 24/28 = 6/7。

|AB| = √(1 + k²) · |x₁ − x₂| = √2 × √Δ/28 = √2 × √5616/28 = √2 × 12√39/28 = 6√78/7。

解析：本题第一问用点差法处理中点弦，第二问用联立方程 + 韦达定理 + 弦长公式。注意点差法的斜率公式要结合中点坐标整体代换；弦长公式中的 |x₁ − x₂| 用 √Δ/|a| 计算，其中 Δ、a 来自联立后的一元二次方程。计算量较大，需细心化简。

## 本章小结与常见错误

1. 圆锥曲线定义中的常数范围遗忘：椭圆要求 2a > 2c，双曲线要求 2a < 2c；若条件不满足，轨迹可能是线段、射线或不存在，直接按椭圆、双曲线处理会错。
2. 双曲线渐近线与焦点关系混淆：焦点在 x 轴与 y 轴时渐近线斜率互换，求 c² 时把 b² 当 a²（如把 c² = a² + b² 与椭圆 c² = a² − b² 混淆）。
3. 联立消元后直接用韦达定理而不检验 Δ ≥ 0：导致求出的参数不满足直线与曲线相交的几何条件，必须代回检验。
4. 焦点弦、中点弦的特殊结论套用不当：抛物线 y² = 2px 中 x₁x₂ = p²/4 等结论只对过焦点的弦成立，对不过焦点的弦套用必错。
