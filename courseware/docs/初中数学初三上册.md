## 第1章 一元二次方程

### 1.1 一元二次方程的概念

- **一元二次方程**：等号两边都是整式，只含有一个未知数（一元），并且未知数的最高次数是 2（二次）的方程，叫做一元二次方程。
- **一般形式**：ax² + bx + c = 0（a ≠ 0），其中 ax² 是二次项，a 是二次项系数；bx 是一次项，b 是一次项系数；c 是常数项。
- 判断一元二次方程的三个条件：整式方程、只含一个未知数、未知数最高次数为 2 且二次项系数不为 0。化成一般形式后，若 a = 0 且 b ≠ 0 则是一元一次方程。
- **一元二次方程的根**：使方程左右两边相等的未知数的值，叫做一元二次方程的解，也叫方程的根。一元二次方程可能有两个根。

### 1.2 直接开平方法与配方法

- **直接开平方法**：形如 x² = p（p ≥ 0）或 (x + n)² = p（p ≥ 0）的方程，直接开平方求解：x = ±√p，x + n = ±√p。当 p < 0 时方程无实数根。
- **配方法**：通过配成完全平方式（x + n)² = p 的形式来解一元二次方程的方法。步骤：移常数项到右边 → 二次项系数化为 1 → 两边加上一次项系数一半的平方 → 写成完全平方式 → 直接开平方求解。
- 配方的关键是"加上一次项系数一半的平方"，即 x² + px + (p/2)² = (x + p/2)²。
- 配方法不仅在解方程中使用，还是推导公式法、求二次函数顶点坐标的重要工具。

### 1.3 公式法与因式分解法

- **公式法**：一元二次方程 ax² + bx + c = 0（a ≠ 0）的求根公式为 x = [-b ± √(b² - 4ac)] / (2a)。使用时先把方程化为一般形式，确定 a、b、c，再代入公式计算。
- **根的判别式**：Δ = b² - 4ac。当 Δ > 0 时，方程有两个不相等的实数根；当 Δ = 0 时，方程有两个相等的实数根；当 Δ < 0 时，方程没有实数根。
- **因式分解法**：把方程化为 (x - m)(x - n) = 0 的形式，由"两个因式的积为 0，则至少有一个因式为 0"，得 x = m 或 x = n。常用提公因式、公式法、十字相乘等手段分解。
- 四种解法各有适用场合：形如 x² = p 用直接开平方；二次项系数为 1 且一次项系数为偶数常用配方法；一般方程用公式法最通用；便于分解的用因式分解法最快。

### 例题

解方程：2x² - 4x - 6 = 0（用两种方法）。

解法一（因式分解法）：两边同除以 2，得 x² - 2x - 3 = 0，因式分解得 (x - 3)(x + 1) = 0，所以 x = 3 或 x = -1。

解法二（公式法）：a = 2，b = -4，c = -6，Δ = (-4)² - 4 × 2 × (-6) = 16 + 48 = 64 > 0，

x = [4 ± √64]/(2 × 2) = (4 ± 8)/4，所以 x₁ = 3，x₂ = -1。

解析：两种方法结果一致。因式分解法要先化为积的形式；公式法要先确认一般形式并准确代入 a、b、c（注意符号）。检验：把 x = 3 和 x = -1 代入原方程都成立。

## 本章小结与常见错误

1. 一般形式系数定错：把方程化为 ax² + bx + c = 0 时，符号（正负号）必须整体带入，如 -x² + 2x + 3 = 0 中 a = -1，b = 2，c = 3。
2. 判别式使用错误：Δ = b² - 4ac 中 b 带符号计算，如 b = -4 时 b² = 16 而非 -16；另外漏乘 4ac 也常见。
3. 开平方丢解或增根：x² = 4 解得 x = ±2，不能只写 x = 2；两边同时除以含未知数的式子（如 x）可能失根。
4. 配方法配方出错：加上的是"一次项系数一半的平方"，如 x² + 6x 应加 9 得 (x + 3)²，而不是加 36 或其他数。

## 第2章 二次函数

### 2.1 二次函数的概念与图象

- **二次函数**：一般地，形如 y = ax² + bx + c（a、b、c 是常数，a ≠ 0）的函数叫做二次函数。x 是自变量，a 不能为 0，b、c 可以为 0。
- 二次函数 y = ax² 的图象是**抛物线**，顶点是原点 (0，0)，对称轴是 y 轴。a > 0 时开口向上，a < 0 时开口向下；|a| 越大，开口越小。
- 抛物线 y = ax² + c 由 y = ax² 上下平移 |c| 个单位得到；y = a(x - h)² 由 y = ax² 左右平移 |h| 个单位得到。
- 画二次函数图象的步骤：列表（以对称轴为中间取点）→ 描点 → 用平滑的曲线连接。注意抛物线的增减性随开口方向不同而不同。

### 2.2 二次函数的三种表达式与性质

- **一般式**：y = ax² + bx + c（a ≠ 0），对称轴 x = -b/(2a)，顶点坐标 (-b/(2a)，(4ac - b²)/(4a))。
- **顶点式**：y = a(x - h)² + k，顶点为 (h，k)，对称轴为 x = h，由一般式配方可得。
- **交点式**：y = a(x - x₁)(x - x₂)，其中 x₁、x₂ 是抛物线与 x 轴交点的横坐标，即对应一元二次方程的两个根。
- **性质**：当 a > 0 时，开口向上，在对称轴左侧 y 随 x 增大而减小，右侧增大，顶点处取最小值 k；当 a < 0 时相反，顶点处取最大值 k。抛物线关于对称轴左右对称。
- 待定系数法求解析式：已知顶点用顶点式，已知与 x 轴交点用交点式，已知三个一般点用一般式。

### 2.3 二次函数与一元二次方程及实际问题

- 抛物线 y = ax² + bx + c 与 x 轴的交点个数由判别式决定：Δ > 0 时有两个交点（对应方程两个不等实根），Δ = 0 时有一个交点（两个相等实根），Δ < 0 时没有交点（方程无实根）。
- 抛物线与 x 轴交点横坐标即为方程 ax² + bx + c = 0 的根；抛物线在 x 轴上方的部分对应不等式 ax² + bx + c > 0 的解集。
- 二次函数实际应用：面积最大问题（围栏）、利润最大问题（定价与销量）、运动抛物线问题（抛球、拱桥）等，核心是建立二次函数模型并求顶点（最值）。
- 求最值时注意自变量取值范围（实际意义），顶点可能在取值范围内也可能不在，不在时要结合增减性在端点处取最值。

### 例题

某商场销售一种商品，进价为每件 40 元，售价为每件 60 元，每天可卖出 100 件。经调查发现：售价每降低 1 元，每天可多卖出 20 件。问售价定为多少元时，每天的利润最大？最大利润是多少？

解：设售价降低 x 元，则售价为 (60 - x) 元，每天卖出 (100 + 20x) 件。

每件利润为 (60 - x) - 40 = 20 - x（元），总利润

y = (20 - x)(100 + 20x) = -20x² + 300x + 2000

= -20(x - 7.5)² + 3125。

因为 -20 < 0，抛物线开口向下，所以当 x = 7.5 时，y 取最大值 3125。

此时售价为 60 - 7.5 = 52.5（元）。

答：售价定为 52.5 元时，每天的利润最大，最大利润为 3125 元。

解析：利润问题关键是"总利润 = 单件利润 × 销售量"。设降价 x 元建立二次函数，配方成顶点式求最大值。注意 x 的实际取值范围（0 ≤ x ≤ 20，保证单件利润非负）。

## 本章小结与常见错误

1. 二次函数定义漏条件：y = ax² + bx + c 必须 a ≠ 0，判断时先化为一般形式再看二次项系数是否为零。
2. 对称轴与顶点坐标算错：对称轴 x = -b/(2a)，顶点纵坐标用 (4ac - b²)/(4a) 或用代入法求，符号错误是高频问题。
3. 平移方向搞反："上加下减、左加右减"要记牢，如 y = x² 向右平移 2 个单位得 y = (x - 2)²，不是 (x + 2)²。
4. 实际问题最值忽略取值范围：x 的取值超出实际问题范围（如降价为负数、销量为负数）时，不能直接用顶点横坐标，需结合单调性在范围内取最值。

## 第3章 圆

### 3.1 圆的有关性质

- **圆**：在一个平面内，线段 OA 绕它固定的一个端点 O 旋转一周，另一个端点 A 所形成的图形叫做圆。圆心 O、半径 r 确定一个圆；圆上各点到圆心的距离都等于半径。
- 与圆有关的概念：弦（连接圆上任意两点的线段）、直径（经过圆心的弦，是圆内最长的弦）、弧（圆上任意两点间的部分，大于半圆的叫优弧，小于半圆的叫劣弧）、等圆、等弧、圆心角、圆周角。
- **圆的对称性**：圆是轴对称图形，任何一条直径所在的直线都是它的对称轴；圆也是中心对称图形，对称中心是圆心。圆心角、弧、弦之间存在相等关系（等对等定理）：在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦也相等。

### 3.2 垂径定理与圆周角定理

- **垂径定理**：垂直于弦的直径平分这条弦，并且平分弦所对的两条弧。推论：平分弦（不是直径）的直径垂直于弦，并且平分弦所对的两条弧。
- 垂径定理常与勾股定理结合：由半径 r、弦心距 d、弦长的一半 a/2 构成直角三角形，有 r² = d² + (a/2)²，是解决圆中计算问题的重要模型。
- **圆周角定理**：一条弧所对的圆周角等于它所对的圆心角的一半。同弧或等弧所对的圆周角相等；半圆（或直径）所对的圆周角是直角，90° 的圆周角所对的弦是直径。
- 圆内接四边形对角互补，且任何一个外角等于它的内对角。

### 3.3 直线与圆的位置关系

- 直线与圆有三种位置关系：相离（无公共点）、相切（唯一公共点）、相交（两个公共点）。设圆心到直线的距离为 d，半径为 r，则 d > r 相离，d = r 相切，d < r 相交。
- **切线的判定**：经过半径的外端并且垂直于这条半径的直线是圆的切线（两个条件缺一不可）。切线的性质：圆的切线垂直于过切点的半径。
- **切线长定理**：从圆外一点引圆的两条切线，它们的切线长相等，这一点和圆心的连线平分两条切线的夹角。
- **圆与正多边形**：把圆分成 n 等份，依次连接各分点所得的多边形是这个圆的内接正 n 边形；正多边形的中心角 = 360°/n，边心距、半径、边长构成直角三角形。弧长 l = nπr/180，扇形面积 S = nπr²/360 = lr/2。

### 例题

已知 ⊙O 的直径为 10 cm，弦 AB 的长为 8 cm，求圆心 O 到弦 AB 的距离（弦心距）。

解：如图（文字描述），作 OC ⊥ AB 于点 C，连接 OA。

由垂径定理得 AC = 1/2 AB = 4 cm。

⊙O 的直径是 10 cm，所以半径 OA = 5 cm。

在 Rt△OAC 中，由勾股定理得 OC = √(OA² - AC²) = √(25 - 16) = √9 = 3（cm）。

## 本章小结与常见错误

1. 垂径定理的条件缺失："垂直于弦的直径"才能平分弦，若没有垂直条件，直径不一定平分弦；推论中"平分弦"的弦不能是直径。
2. 圆周角与圆心角关系用错：圆周角是圆心角的一半，前提是"同弧（或等弧）所对的角"；不同弧的角不能直接比较。
3. 切线判定漏条件：直线过半径外端且垂直于半径才是切线，只满足"过外端"或只满足"垂直"都不够；反之，切线垂直于过切点的半径。
4. 弧长与扇形面积公式混淆：l = nπr/180 与 S = nπr²/360，前者含 r 一次方、后者含 r²，常互相用错；扇形的 S = 1/2 lr 也需记牢。
