## 第1章 集合与函数概念

### 1.1 集合的含义与表示

- **集合**：把研究对象统称为元素，把一些元素组成的总体叫做集合，简称集。集合中的元素具有**确定性**、**互异性**、**无序性**三大特征。确定性指给定集合，元素属于或不属于是明确的；互异性指同一集合中的元素互不相同；无序性指元素排列顺序不影响集合本身。
- 元素与集合的关系用"∈"（属于）和"∉"（不属于）表示。常用数集：自然数集 N、正整数集 N*（或 N+）、整数集 Z、有理数集 Q、实数集 R。
- **集合的表示方法**：列举法（把元素一一列出，如 {1, 2, 3}）、描述法（用集合中元素的共同特征表示，如 {x | x² − 1 = 0}）、图示法（Venn 图）。
- **常用结论**：集合元素的互异性常作为隐含条件，例如集合 {a, a²} 中必有 a ≠ a²，即 a ≠ 0 且 a ≠ 1；解题中求得元素后必须代回检验互异性。

### 1.2 集合间的基本关系与运算

- **子集**：若集合 A 的任意一个元素都是集合 B 的元素，则称 A 是 B 的子集，记作 A ⊆ B。特别地，空集 ∅ 是任何集合的子集。若 A ⊆ B 且 B ⊆ A，则 A = B。
- **真子集**：若 A ⊆ B 且 A ≠ B，则称 A 是 B 的真子集，记作 A ⊊ B。含 n 个元素的集合有 2^n 个子集，有 2^n − 1 个真子集，有 2^n − 2 个非空真子集。
- **交集**：A ∩ B = {x | x ∈ A 且 x ∈ B}，即既属于 A 又属于 B 的元素组成的集合。
- **并集**：A ∪ B = {x | x ∈ A 或 x ∈ B}，即属于 A 或属于 B 的元素组成的集合。
- **补集**：设 U 为全集，集合 A 的补集 ∁_U A = {x | x ∈ U 且 x ∉ A}。常用结论：A ∩ (∁_U A) = ∅，A ∪ (∁_U A) = U，∁_U (∁_U A) = A。
- **容斥关系**：|A ∪ B| = |A| + |B| − |A ∩ B|，可用来求元素个数，也可借助 Venn 图直观分析。

### 1.3 函数的概念、定义域与值域

- **函数概念**：设 A、B 是非空的实数集，如果对于集合 A 中的任意一个数 x，按照某种确定的对应关系 f，在集合 B 中都有唯一确定的数 y 和它对应，那么就把对应关系 f 称为定义在集合 A 上的函数，记作 y = f(x)，x ∈ A。x 叫做自变量，x 的取值范围 A 叫做函数的**定义域**，与 x 对应的 y 值叫做函数值，函数值的集合 {f(x) | x ∈ A} 叫做函数的**值域**。
- **函数的三个要素**：定义域、对应关系、值域。判断两个函数是否相同，只看定义域与对应关系是否一致，与用什么字母表示变量无关。例如 f(x) = x 与 g(x) = (√x)² 不是同一函数（定义域不同）。
- **求定义域**：分式分母不为零、偶次根号下被开方数非负、零次幂底数不为零、对数真数大于零；实际问题还要考虑实际意义。求定义域的结果应写成集合或区间形式。
- **求值域的基本方法**：观察法、配方法、换元法、分离常数法、单调性法。如求 y = 2x − 1（x ∈ [0, 3]）的值域可用单调性直接得出。

### 1.4 函数的单调性与奇偶性

- **单调性**：设函数 f(x) 的定义域为 I，区间 D ⊆ I。若对任意 x₁、x₂ ∈ D，当 x₁ < x₂ 时都有 f(x₁) < f(x₂)，则称 f(x) 在区间 D 上单调递增；若都有 f(x₁) > f(x₂)，则称单调递减。单调性是函数在某区间上的局部性质，判断通常用**定义法**（作差变形定号）或**图象法**。
- **奇偶性**：设函数 f(x) 的定义域关于原点对称。若对定义域内任意 x 都有 f(−x) = −f(x)，则 f(x) 为**奇函数**，图象关于原点对称；若 f(−x) = f(x)，则 f(x) 为**偶函数**，图象关于 y 轴对称。
- 奇偶性判断必须先检验定义域是否关于原点对称，这是最容易忽略的步骤。既是奇函数又是偶函数的函数必为常函数 f(x) = 0（在对称定义域上）。
- **重要结论**：奇函数在关于原点对称的两个区间上单调性相同，偶函数相反；若奇函数在 x = 0 处有定义，则 f(0) = 0，可用来求参数。

### 例题

已知集合 A = {x | x² − 3x + 2 = 0}，B = {x | ax − 1 = 0}，且 A ∪ B = A，求实数 a 的取值集合。

解：由 x² − 3x + 2 = 0 得 x = 1 或 x = 2，故 A = {1, 2}。

由 A ∪ B = A 知 B ⊆ A，分情况讨论：

（1）B = ∅ 时，方程 ax − 1 = 0 无解，则 a = 0；

（2）B = {1} 时，a − 1 = 0，得 a = 1；

（3）B = {2} 时，2a − 1 = 0，得 a = 1/2。

经检验 a = 0、1、1/2 均满足 B ⊆ A，故实数 a 的取值集合为 {0, 1/2, 1}。

解析：本题核心是"并集运算等价于包含关系"：A ∪ B = A ⟺ B ⊆ A。易错点是漏掉 B = ∅ 的情形，以及求出的 a 需要代回检验是否满足 B 的元素确实是 A 中的元素。

## 本章小结与常见错误

1. 忽略集合元素的互异性：如求得 x = 1 后又求出 x = 1 的重复元素，未代回检验导致集合中出现相同元素。
2. 求函数定义域丢条件：如只考虑分母不为零而忽略偶次根号下非负，或多条件交集求错。
3. 判断奇偶性不先看定义域：定义域不关于原点对称就直接下结论，例如 f(x) = x²（x ∈ [0, 1]）不是偶函数。
4. 混淆"单调区间"与"区间上单调"：如 y = 1/x 在 (−∞, 0) 和 (0, +∞) 上分别单调递减，不能说它在整个定义域上单调递减。

## 第2章 指数函数与对数函数

### 2.1 指数与指数幂的运算

- **根式**：n 次方根的定义，√[n]a（n 为奇数时 a ∈ R，n 为偶数时 a ≥ 0）。当 n 为偶数时，√[n](a^n) = |a|；当 n 为奇数时，√[n](a^n) = a。
- **分数指数幂**：a^(m/n) = ⁿ√(a^m)（a > 0，m、n ∈ N*，n > 1），a^(−m/n) = 1 / a^(m/n)（a > 0）。分数指数幂与根式可以互化，运算时通常统一为分数指数幂形式。
- **指数运算性质**（a > 0，b > 0，m、n ∈ R）：a^m · a^n = a^(m+n)，(a^m)^n = a^(mn)，(ab)^n = a^n b^n，a^m ÷ a^n = a^(m−n)。
- 运算技巧：把底数统一为幂的形式（如 8 = 2³，4 = 2²），再进行指数运算；注意负分数指数幂表示倒数，如 4^(−1/2) = 1/2。

### 2.2 指数函数及其性质

- **定义**：形如 y = a^x（a > 0 且 a ≠ 1）的函数叫做指数函数，其中 x 是自变量，定义域为 R，值域为 (0, +∞)。
- **图象与性质**：当 a > 1 时，函数在 R 上单调递增；当 0 < a < 1 时，函数在 R 上单调递减。图象恒过定点 (0, 1)，且以 x 轴（y = 0）为渐近线。
- 指数函数图象在第一象限内"底大图高"：a > 1 时，a 越大图象越靠近 y 轴；0 < a < 1 时，a 越小图象越靠近 y 轴。据此可快速比较指数的大小关系。
- 底数不同时比较大小，常借助中间量 0 和 1：a^x 恒大于 0，a^x > 1 ⟺ x > 0（a > 1 时）；a^x < 1 ⟺ x > 0（0 < a < 1 时）。
- **指数型函数模型**：y = k·a^x 常用于刻画增长（衰减）问题，如人口增长、细胞分裂、放射性衰变等实际情境。

### 2.3 对数与对数运算

- **对数定义**：若 a^x = N（a > 0 且 a ≠ 1），则 x 叫做以 a 为底 N 的对数，记作 x = log_a N，其中 a 叫底数，N 叫真数。真数 N > 0，对数 log_a 1 = 0，log_a a = 1。
- **对数与指数的关系**：a^(log_a N) = N（对数恒等式），log_a (a^b) = b。两者互为逆运算，是解决指数、对数方程相互转化的桥梁。
- **对数运算性质**（a > 0 且 a ≠ 1，M > 0，N > 0）：log_a (MN) = log_a M + log_a N，log_a (M/N) = log_a M − log_a N，log_a (M^n) = n log_a M。
- **换底公式**：log_a b = log_c b / log_c a（a > 0 且 a ≠ 1，c > 0 且 c ≠ 1，b > 0）。由换底公式可得 log_a b = 1 / log_b a，常用自然对数 ln x（底为 e）与常用对数 lg x（底为 10）计算。
- 注意：log_a (M + N) ≠ log_a M + log_a N，对数运算不能"拆分加法"，这是最常见的高频错误点。

### 2.4 对数函数、幂函数与函数综合

- **对数函数**：y = log_a x（a > 0 且 a ≠ 1），定义域 (0, +∞)，值域 R。a > 1 时单调递增，0 < a < 1 时单调递减；图象恒过定点 (1, 0)，以 y 轴为渐近线。底数变化时，第一象限内"底大图低"。
- **幂函数**：y = x^α（α 为常数）。常见幂函数 y = x、x²、x³、x^(1/2)、x^(−1) 的图象与性质：所有幂函数都过点 (1, 1)；α > 0 时在 (0, +∞) 上单调递增，α < 0 时单调递减。
- **函数的应用**：函数的零点（使 f(x) = 0 的 x 值）可用二分法求近似解；指数函数、对数函数模型可描述增长与衰减、复利、地震震级等实际问题。
- **图象变换综合**：由 y = f(x) 通过平移、对称得到 y = f(x ± a)、y = f(x) ± b、y = −f(x)、y = f(−x) 等图象，是函数图象综合题的常用工具。

### 例题

比较大小：（1）0.7^0.8 与 0.7^0.6；（2）log_2 3 与 log_3 2；（3）1.1^0.9 与 log_0.5 0.6。

解：（1）底数 0.7 ∈ (0, 1)，指数函数 y = 0.7^x 在 R 上单调递减，又 0.8 > 0.6，故 0.7^0.8 < 0.7^0.6。

（2）log_2 3 > log_2 2 = 1，log_3 2 < log_3 3 = 1，故 log_2 3 > log_3 2。

（3）1.1^0.9 > 1.1^0 = 1，log_0.5 0.6 < log_0.5 0.5 = 1 且 log_0.5 0.6 > log_0.5 1 = 0，故 1.1^0.9 > log_0.5 0.6。

解析：比较大小的核心策略是"同底用单调性、同指比底数、不同底找中间量（0 和 1）"。第（3）题先分别与 1 比较，再借助 0 作第二层放缩，体现了"搭桥比较"的思想。

## 本章小结与常见错误

1. 根式运算符号错误：如 √[4](−2)^4 误写成 −2，正确结果为 |−2| = 2；偶次根式运算结果必须非负。
2. 对数运算乱拆分：log_a (M + N) ≠ log_a M + log_a N，log_a (M · N) 也不能写成 log_a M · log_a N。
3. 忽略对数真数大于 0 的约束：解 log_x (x − 2) > 0 这类题时忘记 x − 2 > 0 且底数 x > 0、x ≠ 1，导致增根或漏解。
4. 比较大小选错中间量：底数、指数都不同的两个幂直接相除比较，忽略了先与 0、1 比较的常规流程，导致结论错误。

## 第3章 一元二次函数方程不等式

### 3.1 二次函数与一元二次方程

- **二次函数的三种表示**：一般式 y = ax² + bx + c（a ≠ 0），顶点式 y = a(x − h)² + k（顶点为 (h, k)），交点式 y = a(x − x₁)(x − x₂)（x₁、x₂ 为图象与 x 轴交点的横坐标）。
- **二次函数性质**：对称轴 x = −b/(2a)，顶点坐标 (−b/(2a), (4ac − b²)/(4a))。a > 0 时开口向上，在对称轴左侧递减、右侧递增；a < 0 时相反。
- **判别式与根的判断**：Δ = b² − 4ac。Δ > 0 时有两个不等实根，Δ = 0 时有两个相等实根（重根），Δ < 0 时无实根。二次函数图象与 x 轴交点的个数分别对应 2 个、1 个、0 个。
- **根与系数的关系（韦达定理）**：x₁ + x₂ = −b/a，x₁ · x₂ = c/a。常与判别式配合，用于已知一根求另一根、求对称式（如 x₁² + x₂²）的值。
- 二次函数在闭区间 [m, n] 上的最值问题，需按对称轴与区间的位置关系分三种情况讨论：对称轴在区间左侧、中间、右侧。

### 3.2 一元二次不等式及其解法

- **基本思路**：一元二次不等式 ax² + bx + c > 0（或 < 0，a ≠ 0）的解法，转化为对应二次函数图象在 x 轴上方或下方的问题。先求对应方程的根，再结合开口方向确定解集。
- **解集规律**（a > 0 时）：Δ > 0 且两根为 x₁ < x₂，则 ax² + bx + c > 0 的解集为 {x | x < x₁ 或 x > x₂}，ax² + bx + c < 0 的解集为 {x | x₁ < x < x₂}；Δ = 0 时大于 0 的解集为除根以外的全体实数，小于 0 的解集为空集；Δ < 0 时大于 0 的解集为 R，小于 0 的解集为空集。
- **含参数的不等式**：按二次项系数是否为零、判别式符号、两根大小分情况讨论。二次项系数为 0 时退化为一次不等式，是不可遗漏的情形。
- 分式不等式、绝对值不等式常通过转化（移项通分、零点分段）化为整式不等式组求解，注意分母不为零与"或"与"且"的联结关系。

### 3.3 基本不等式

- **基本不等式**：若 a > 0，b > 0，则 a + b ≥ 2√(ab)，当且仅当 a = b 时等号成立。可变形为 ab ≤ ((a + b)/2)²，即两个正数的算术平均数不小于几何平均数。
- **使用条件"一正、二定、三相等"**：一正指 a、b 必须为正数；二定指和定积最大或积定和最小；三相等指等号成立条件 a = b 必须能取到，取不到等号时不能直接套用最值。
- 常用技巧：拆项（如 x + 1/x 型）、凑系数、换元、乘"1"法（如已知 x + y = 1，求 1/x + 4/y 的最小值，可乘 1 = x + y 后展开）。
- 用基本不等式求最值时，若等号取不到（如 a、b 无法相等），应改用函数的单调性求最值。

### 3.4 基本不等式与二次函数的应用

- **应用题建模**：利用二次函数或基本不等式解决最优化问题（面积最大、用料最省、利润最大等），先建立目标函数，再求最值，注意自变量的实际取值范围。
- **恒成立问题**：f(x) > m 恒成立 ⟺ f(x)_min > m；f(x) < m 恒成立 ⟺ f(x)_max < m。在区间上恒成立问题常转化为求函数最值，或利用分离参数法处理。
- **存在性问题**："存在 x 使 f(x) > m 成立" ⟺ f(x)_max > m，与恒成立问题的最值取法相反，注意区分。
- 二次方程根的分布问题：借助二次函数图象，用判别式、对称轴位置、端点函数值符号共同刻画根所在区间，体现数形结合思想。

### 例题

已知 x > 0，y > 0，且 x + 2y = 1，求 1/x + 1/y 的最小值。

解：因为 x + 2y = 1，所以 1/x + 1/y = (1/x + 1/y)(x + 2y) = 1 + 2y/x + x/y + 2 = 3 + 2y/x + x/y。

由 x > 0，y > 0，可得 2y/x + x/y ≥ 2√(2y/x · x/y) = 2√2，当且仅当 2y/x = x/y，即 x = √2 y 时等号成立。

联立 x + 2y = 1 与 x = √2 y，解得 y = 1/(2 + √2)，x = √2/(2 + √2)。

此时 (1/x + 1/y)_min = 3 + 2√2。

解析："乘 1 法"是基本不等式求最值的经典技巧：在条件 x + 2y = 1 下，目标式乘上"1"后展开，构造出积为定值的两项，再用基本不等式。要注意等号成立条件必须与条件式联立能够取到。

## 本章小结与常见错误

1. 解含参一元二次不等式不讨论二次项系数：a = 0 时是一次不等式，直接当二次处理会漏解或错解。
2. 基本不等式忽视"一正"条件：对负数直接用基本不等式，如对 x < 0 的 x + 1/x 直接断言最小值为 2，实际应先变号为 −x − 1/x ≥ 2 再处理。
3. 恒成立与存在性混淆：把"存在 x 使 f(x) > m"错误地当成恒成立，导致最值方向取反。
4. 韦达定理与判别式配合失误：用韦达定理列式后忘记同时满足 Δ ≥ 0，求出参数却不检验，造成增解。
