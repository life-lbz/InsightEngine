## 第一章 磁场

### 1.1 磁感应强度与磁感线

- **磁感应强度** $B$：描述磁场强弱和方向的物理量，$B=\frac{F}{IL}$（电流元在垂直于磁场的条件下），单位特斯拉 T。磁感应强度是矢量，方向为小磁针 N 极受力方向（即该处磁场方向）。
- **磁感线**：闭合曲线（与电场线不同，磁感线是闭合的），从 N 极出发经外部空间到 S 极，再经内部回到 N 极；疏密表示磁场强弱，切线方向表示磁场方向；磁感线不相交。
- **匀强磁场**：磁感应强度大小、方向处处相同的区域，磁感线为平行等距直线。
- 安培定则（右手螺旋定则）：判断电流的磁场方向——直线电流用"右手握导线"、环形电流与通电螺线管用"右手握线圈"。
- 磁通量 $\Phi=BS\cos\theta$（$\theta$ 为 $B$ 与面积法线的夹角），单位韦伯 Wb。磁通量是标量但有正负，磁通量变化量 $\Delta\Phi$ 是感应电流产生的必要条件。

### 1.2 安培力

- **安培力**：磁场对通电导线的作用力，$F=BIL\sin\theta$（$\theta$ 为 $B$ 与 $I$ 的夹角），方向由**左手定则**判断（伸开左手，让磁感线穿入手心，四指指向电流方向，大拇指即为安培力方向）。
- 安培力方向垂直于 $B$ 与 $I$ 决定的平面，即 $F\perp B$、$F\perp I$。
- 应用实例：电动机、电流天平、磁电式仪表。
- 两平行通电直导线：同向电流相互吸引，反向电流相互排斥。

### 1.3 洛伦兹力

- **洛伦兹力**：磁场对运动电荷的作用力，$F=qvB\sin\theta$（$\theta$ 为 $v$ 与 $B$ 的夹角），方向由左手定则判断（注意四指指向正电荷运动方向，负电荷与运动方向相反）。
- 洛伦兹力的特点：永远不做功，只改变速度方向不改变速度大小。
- 当 $v\parallel B$ 时洛伦兹力为零，电荷做匀速直线运动；当 $v\perp B$ 时电荷做匀速圆周运动。
- 与安培力的关系：安培力是洛伦兹力的宏观表现。

### 1.4 带电粒子在磁场中的运动

当 $v\perp B$ 时，带电粒子在匀强磁场中做匀速圆周运动，洛伦兹力提供向心力：

$qvB=m\frac{v^2}{r}$，得轨道半径 $r=\frac{mv}{qB}$，周期 $T=\frac{2\pi m}{qB}$。

**重要结论：周期 $T$ 与速度 $v$、半径 $r$ 无关，只由比荷 $\frac{q}{m}$ 和磁感应强度 $B$ 决定。**

解题三步法：
1. 定圆心：两速度方向垂线的交点（或一速度垂线与弦中垂线的交点）。
2. 定半径：几何关系（直角三角形、勾股定理）求 $r$。
3. 定时间：$t=\frac{\theta}{2\pi}T$（$\theta$ 为轨迹对应圆心角，弧度制）。

### 例题

**例1（计算题）**：一带电粒子（电荷量 $q=1.6\times 10^{-19}\ \mathrm{C}$，质量 $m=3.2\times 10^{-27}\ \mathrm{kg}$）以 $v=2\times 10^6\ \mathrm{m/s}$ 的速度垂直进入磁感应强度 $B=0.5\ \mathrm{T}$ 的匀强磁场。求：(1) 粒子做圆周运动的半径；(2) 运动周期；(3) 转过的圆心角为 $90°$ 所需时间。

**解析**：(1) 由 $r=\frac{mv}{qB}$，$r=\frac{3.2\times 10^{-27}\times 2\times 10^6}{1.6\times 10^{-19}\times 0.5}=0.08\ \mathrm{m}$。

(2) $T=\frac{2\pi m}{qB}=\frac{2\times 3.14\times 3.2\times 10^{-27}}{1.6\times 10^{-19}\times 0.5}=2.5\times 10^{-7}\ \mathrm{s}$。

(3) $t=\frac{90°}{360°}T=\frac{T}{4}=6.3\times 10^{-8}\ \mathrm{s}$。

**易错点：周期公式中 $\frac{m}{q}$ 是比荷的倒数，注意质量与电荷量不可颠倒；计算时间用圆心角占圆周的比例，而非弧长。**

## 本章小结与常见错误

1. 左手定则与右手定则（安培定则）混用：判断安培力、洛伦兹力用左手，判断电流磁场、感应电流方向用右手。
2. 洛伦兹力不做功的性质被忽略，误认为洛伦兹力可以改变粒子的动能。
3. 带电粒子圆周运动中"找圆心、定半径"的几何关系出错，尤其是相切、相离边界问题。
4. 负电荷的洛伦兹力方向判断忘记把四指方向反过来（指向负电荷运动反方向）。

## 第二章 电磁感应

### 2.1 电磁感应现象与楞次定律

- **电磁感应现象**：穿过闭合回路的磁通量发生变化时，回路中产生感应电流的现象。产生条件：回路闭合 + 磁通量变化（$\Delta\Phi\ne 0$）。
- **楞次定律**：感应电流具有这样的方向，即感应电流的磁场总要阻碍引起感应电流的磁通量的变化。
  - 理解："增反减同"（磁通量增加，感应电流磁场与原磁场反向；减少则同向）。
  - 推论一：阻碍相对运动——"来拒去留"（如磁铁靠近线圈时线圈产生排斥力）。
  - 推论二：使回路的面积有"增缩减扩"的趋势。
  - 推论三：安培力总是阻碍导体棒相对磁场的运动，安培力做负功（把其他能转化为电能）。
- 判断感应电流方向的一般步骤：明确原磁场方向 → 判断磁通量增减 → 由楞次定律确定感应磁场方向 → 安培定则确定感应电流方向。

### 2.2 法拉第电磁感应定律

- **法拉第电磁感应定律**：感应电动势大小与磁通量变化率成正比，$E=n\frac{\Delta\Phi}{\Delta t}$（$n$ 为线圈匝数）。
- 磁通量 $\Phi$、磁通量变化量 $\Delta\Phi$、磁通量变化率 $\frac{\Delta\Phi}{\Delta t}$ 三者区别：
  - $\Phi$ 大不代表 $\frac{\Delta\Phi}{\Delta t}$ 大；$\Phi=0$ 时 $\frac{\Delta\Phi}{\Delta t}$ 可能很大（如线圈平面转到与磁场平行瞬间）。
- 感生电场：变化的磁场在周围空间产生电场，导体处于其中产生感应电动势（涡流、电磁阻尼等应用）。

### 2.3 导体切割磁感线

- 导体棒垂直切割磁感线：$E=BLv$（$B$、$L$、$v$ 两两垂直），方向由右手定则判断（伸开右手，磁感线穿入手心，拇指指向运动方向，四指指向感应电流方向）。
- 转动切割（一端固定绕轴转动）：$E=\frac{1}{2}B\omega L^2$。
- 两种电动势的联系：$E=BLv$ 是 $E=\frac{\Delta\Phi}{\Delta t}$ 的特例（平动切割）。
- 综合问题：电磁感应中的力学与能量分析——导体棒受安培力 $F=BIL$，安培力做负功将机械能转化为电能；常见"单棒 + 导轨"模型：金属棒在恒力/外力驱动下运动，最终可能达到匀速（平衡态）。

### 例题

**例2（计算题）**：如图所示，水平放置的 U 形导轨间距 $L=0.5\ \mathrm{m}$，处于竖直向下的匀强磁场中，磁感应强度 $B=1\ \mathrm{T}$，导体棒 $ab$ 质量 $m=0.1\ \mathrm{kg}$，电阻 $R=0.5\ \Omega$（导轨电阻不计），在外力作用下以 $v=4\ \mathrm{m/s}$ 匀速向右滑动。求：(1) 感应电动势和感应电流；(2) 安培力的大小和方向；(3) 外力的功率。

**解析**：(1) $E=BLv=1\times 0.5\times 4=2\ \mathrm{V}$，$I=\frac{E}{R}=\frac{2}{0.5}=4\ \mathrm{A}$。

(2) 由右手定则，感应电流沿 $b\to a$ 方向；由左手定则，安培力方向水平向左，$F_{\text{安}}=BIL=1\times 4\times 0.5=2\ \mathrm{N}$。

(3) 导体棒匀速运动，外力与安培力平衡，$F_{\text{外}}=F_{\text{安}}=2\ \mathrm{N}$，功率 $P=F_{\text{外}}v=2\times 4=8\ \mathrm{W}$。

**易错点：匀速滑动的条件意味着合外力为零，外力功率与安培力功率（即电功率）相等，能量转化关系是解题关键。**

## 本章小结与常见错误

1. 混淆"磁通量大"与"磁通量变化率大"：感应电动势由变化率决定，与磁通量本身大小无关。
2. 楞次定律与右手定则使用混乱：回路磁通量变化用楞次定律，导体切割磁感线用右手定则（本质都是阻碍变化）。
3. 感应电流方向的"增反减同"只比较感应磁场与原磁场的方向关系，误以为感应电流方向总与原电流相反。
4. 计算感应电动势时 $E=BLv$ 忘记 $B$、$L$、$v$ 必须两两垂直，斜交时需取有效分量。

## 第三章 交变电流

### 3.1 交变电流的产生与描述

- **交变电流**：大小和方向都随时间做周期性变化的电流。正弦式交变电流由线圈在匀强磁场中绕垂直于磁场的轴匀速转动产生。
- 瞬时值：$e=E_m\sin\omega t$，$i=I_m\sin\omega t$，$u=U_m\sin\omega t$（从中性面开始计时）。
- 峰值：$E_m=NBS\omega$，$I_m=\frac{E_m}{R+r}$。
- 有效值：按热效应等效定义，正弦式交变电流 $E=\frac{E_m}{\sqrt{2}}$，$I=\frac{I_m}{\sqrt{2}}$，$U=\frac{U_m}{\sqrt{2}}$。**铭牌、电表读数、焦耳定律计算均用有效值；判断击穿电压、耐压值用峰值。**
- 平均值：$\bar{E}=N\frac{\Delta\Phi}{\Delta t}$，用于计算电荷量 $q=N\frac{\Delta\Phi}{R}$。
- 周期与频率：$T=\frac{2\pi}{\omega}$，$f=\frac{1}{T}$，我国电网 $f=50\ \mathrm{Hz}$，$T=0.02\ \mathrm{s}$。

### 3.2 变压器

- **变压器原理**：电磁感应（互感），只适用于交变电流，不改变交流的频率。
- 理想变压器规律：
  - 电压关系：$\frac{U_1}{U_2}=\frac{n_1}{n_2}$（电压与匝数成正比）。
  - 电流关系：$\frac{I_1}{I_2}=\frac{n_2}{n_1}$（电流与匝数成反比，仅一个副线圈时成立）。
  - 功率关系：$P_1=P_2$（输入功率由输出功率决定）。
- 注意：变压器不改变电压频率；多个副线圈时电流关系由 $P_{\text{入}}=P_{\text{出}}$ 求解，不能直接用匝数反比。
- 互感器：电压互感器（并联，降压）、电流互感器（串联，降流）。

### 3.3 远距离输电

- 输电原理：发电厂 → 升压变压器 → 输电线 → 降压变压器 → 用户。
- 功率损失：$P_{\text{损}}=I^2R_{\text{线}}$（电流平方与导线电阻乘积），导线电阻 $R_{\text{线}}=\rho\frac{l}{S}$。
- **减小损耗的两条途径**：减小导线电阻（增大截面积、使用电阻率小的材料）或减小输电电流。由 $P=UI$ 知，提高输电电压可减小电流，这是远距离输电采用高压的根本原因。
- 电压损失：$U_{\text{损}}=IR_{\text{线}}$，用户实际获得电压 $U_3=U_2-IR_{\text{线}}$。

### 例题

**例3（计算题）**：某发电厂输出的电功率 $P=100\ \mathrm{kW}$，输电电压 $U_1=250\ \mathrm{V}$，输电线总电阻 $R=1\ \Omega$。求：(1) 输电电流和输电线上损失的电功率；(2) 若改用 $U_2=10\ \mathrm{kV}$ 高压输电，损失功率变为多少。

**解析**：(1) $I_1=\frac{P}{U_1}=\frac{10^5}{250}=400\ \mathrm{A}$，$P_{\text{损1}}=I_1^2R=400^2\times 1=1.6\times 10^5\ \mathrm{W}=160\ \mathrm{kW}$，超过了输出功率，说明低压输电损耗极其严重。

(2) 高压输电时 $I_2=\frac{P}{U_2}=\frac{10^5}{10^4}=10\ \mathrm{A}$，$P_{\text{损2}}=I_2^2R=10^2\times 1=100\ \mathrm{W}$，损耗率仅 $0.1\%$。

**易错点：输电损失功率只能由 $P_{\text{损}}=I^2R$ 计算，不能误用 $\frac{U^2}{R}$（$U$ 应为输电线上损失的电压而非输电电压）。**

## 本章小结与常见错误

1. 有效值与峰值混用：计算焦耳热、电表读数、铭牌标称一律用有效值，电容击穿、耐压判断用峰值。
2. 变压器多个副线圈时误用匝数反比求电流，正确方法是由功率守恒 $P_{\text{入}}=P_{\text{出}}$ 求解。
3. 输电损失功率误用 $P=\frac{U^2}{R}$ 或 $P=UI$（$U$ 指输电线电压降），正确为 $P_{\text{损}}=I^2R_{\text{线}}$。
4. 变压器不能改变频率，认为升压后频率也增大的认识是错的。

## 全册复习提示

- 磁场部分核心是"圆周运动 + 几何"的带电粒子问题，多做边界与相切类练习。
- 电磁感应是力学、电学、能量的交汇点，"单棒+导轨"模型必须掌握动力学与能量两条分析路径。
- 交变电流抓住"一个来源（正弦产生）、两个值（峰值/有效值）、三个工具（变压器、输电、瞬时值表达式）"即可覆盖考点。
