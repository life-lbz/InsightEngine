# 高中数学高三下册课程讲义
课程编号：senior_math_g12s2　适用学段：高中　年级：高三　学期：下学期

本讲义为人教A版高中数学二轮复习专题讲义，围绕"压轴题方法"与"综合模拟与应试"两大主题，冲刺高考。二轮复习的重点是把一轮复习形成的知识网络转化为解题能力：突破导数、圆锥曲线压轴题，优化考场时间分配与答题规范，同时查漏补缺、回归基础，实现从"会做"到"做对、得分"的跨越。

## 第1章 压轴题方法

### 1.1 导数压轴题常见题型与解题策略

- **题型概览**：导数压轴题主要考查①求单调区间与极值最值（基础问）；②不等式恒成立、能成立求参数范围；③利用导数证明不等式；④函数零点个数与极值点偏移；⑤数列不等式的导数放缩。前两问通常可得分，最后一问体现区分度。
- **求参数范围的通法**：分离参数法（a ≥ f(x) 恒成立 ⟺ a ≥ f(x)_max，注意等号取到）与含参讨论法（直接研究含参函数的单调性、最值）。选择原则：能分离优先分离，不能分离或分离后函数复杂则讨论。
- **必要性探路**：先由特殊值（如 x = 0、x = 1、端点值）得到参数的必要范围，缩小讨论区间，再证明充分性，可大幅简化运算。如 f(x) ≥ 0 对 x ≥ 0 恒成立且 f(0) = 0，则需 f'(0) ≥ 0。
- **不等式证明的常见套路**：作差构造（h(x) = f(x) − g(x) 求最小值）；利用已证结论递推（第一问结论为第二问服务）；放缩（ln x ≤ x − 1、eˣ ≥ x + 1、eˣ ≥ ex 等）。
- **同构思想**：把待证式两边化成同一函数 f 的不同自变量形式，用单调性脱去 f，如 e^x − ln x > 2 可变形为 e^x + x > e^{ln x} + ln x 的形式处理。

### 1.2 极值点偏移与双变量问题

- **极值点偏移**：若 f(x₁) = f(x₂)（x₁ ≠ x₂），函数 f 的极值点为 x₀，则 x₁ + x₂ 与 2x₀ 的关系称为偏移。当 x₀ = 1 时，证明 x₁ + x₂ > 2 或 < 2 是经典考法。
- **方法一（对称构造）**：构造 F(x) = f(x) − f(2x₀ − x)（或 f(x) 与 f 的对称函数的差），利用单调性证明。这是最通用、最规范的方法，考试中优先使用。
- **方法二（对数平均不等式）**：对双变量条件取对数转化为 ln x₁ − ln x₂ 与 x₁ − x₂ 的关系，用对数平均不等式 √(x₁x₂) < (x₁ − x₂)/(ln x₁ − ln x₂) < (x₁ + x₂)/2 放缩。
- **方法三（消参转化）**：用条件把两个变量关系化为单变量（比值换元 t = x₁/x₂ 或差换元），转化为函数最值问题。
- **双变量问题的通法**：明确主元、消去一个变量、构造单变量函数，或把双变量不等式转化为两函数的最值比较。

### 1.3 圆锥曲线压轴题解题策略

- **题型概览**：圆锥曲线压轴题主要考查①求方程；②直线与曲线相交的弦长、面积问题；③定点、定值问题；④范围与最值问题；⑤存在性探究问题。运算量大，考查"设而不求"与整体代换能力。
- **设而不求三件套**：设直线（点斜式或 x = my + n 形式）、设交点坐标、联立消元后用韦达定理整体代换，不具体求出交点坐标。
- **设线的选择**：已知定点在 y 轴上，设 y = kx + b 较方便；已知定点在 x 轴上或需避免斜率讨论，设 x = my + n 更方便（m 为斜率的倒数，此时不需要讨论 x = my + n 垂直于 y 轴的情形之外的斜率不存在）。
- **面积的处理**：S = 1/2 |AB|·d（弦长 × 点到直线距离）或 S = 1/2 |x₁y₂ − x₂y₁|（叉积形式），根据图形特点选择；常转化为关于斜率或截距的函数求最值（二次函数配方法、基本不等式、对勾函数）。
- **定点定值问题**：先猜后证（找特殊位置猜定点），或把直线方程整理为"含参直线系"观察定点；定值问题通过设参、代入、化简消参得到常数。
- **判别式的约束**：用韦达定理建立的关系式与判别式 Δ > 0 对参数形成的约束必须同时满足，求范围问题尤其要检验。

### 1.4 定点、定值与存在性问题

- **定点问题的操作程序**：设直线 y = kx + m（含双参数 k、m）→ 由几何条件（如过定点、垂直、共线）建立 k、m 的关系式 m = f(k) → 代入直线方程整理为 k(x − x₀) + (y − y₀) = 0 形式 → 定点为 (x₀, y₀)。
- **定值问题的操作程序**：设参数（斜率、截距）→ 把目标量（斜率积、长度积、面积）用参数表示 → 利用韦达定理与几何条件化简 → 消去参数得常数。
- **存在性问题的答题规范**：假设存在 → 由条件列方程或方程组 → 求解或推出矛盾 → 分"存在，值/坐标为…"与"不存在"两种情况明确作答。
- **常见几何条件的代数翻译**：垂直 ⟹ 斜率积为 −1 或数量积为 0；共线 ⟹ 斜率相等或向量平行；角相等 ⟹ 斜率关系；点在直线上 ⟹ 坐标满足方程。
- 压轴题的得分策略：即使不能完整求解，也要写出"设直线、联立、韦达定理"等步骤分；用"先猜后证"争取定点定值问题的结论分。

### 例题

已知函数 f(x) = ln x + a/x（a ∈ R），若 f(x₁) = f(x₂)（x₁ ≠ x₂），证明：x₁ + x₂ > 2a。

（本题以 a > 0 为例，此时 f 有极小值点 x = a）

证明：f'(x) = 1/x − a/x² = (x − a)/x²，故 f 在 (0, a) 上单调递减，在 (a, +∞) 上单调递增，极小值点 x₀ = a。

不妨设 0 < x₁ < a < x₂。要证 x₁ + x₂ > 2a，即证 x₂ > 2a − x₁。注意到 2a − x₁ > a。

构造函数 F(x) = f(x) − f(2a − x)（0 < x < a），则

F'(x) = f'(x) + f'(2a − x) = (x − a)/x² + (2a − x − a)/(2a − x)² = (x − a)/x² + (a − x)/(2a − x)² = (x − a)[1/x² − 1/(2a − x)²]。

因为 0 < x < a，x − a < 0，且 x < 2a − x（因 x < a），故 1/x² > 1/(2a − x)²，即 1/x² − 1/(2a − x)² > 0。

所以 F'(x) < 0，F(x) 在 (0, a) 上单调递减，F(x) > F(a) = f(a) − f(a) = 0，即 f(x) > f(2a − x)（0 < x < a）。

取 x = x₁ ∈ (0, a)，得 f(x₁) > f(2a − x₁)。又 f(x₁) = f(x₂)，故 f(x₂) > f(2a − x₁)。

由 2a − x₁ > a 且 f 在 (a, +∞) 上单调递增，得 x₂ > 2a − x₁，即 x₁ + x₂ > 2a。证毕。

解析：这是极值点偏移问题的标准解法——对称构造：构造 F(x) = f(x) − f(2x₀ − x) 并利用单调性，把"证明 x₁ + x₂ > 2x₀"转化为比较 f(x₂) 与 f(2x₀ − x₁) 的大小。关键步骤：先判断 F'(x) 符号、再利用 f 的单调性脱去 f。此方法通用于各类极值点偏移问题，务必掌握书写规范。

## 本章小结与常见错误

1. 极值点偏移误用对数平均不等式：对数平均不等式放缩方向写反（如把 (x₁ − x₂)/(ln x₁ − ln x₂) 与 √(x₁x₂) 的大小关系记反），导致结论错误。
2. 恒成立求参数只做必要性不证充分性：由端点探路猜出范围后直接作答，未证明充分性；或分离参数时忽略端点处等号能否取到。
3. 圆锥曲线设直线后忘用判别式约束：求出参数范围后未与 Δ > 0 求交集，导致范围偏大。
4. 双变量问题消元方向错误：两个变量关系没有理清就强行换元，应明确谁是"被消去"的变量、用谁的式子代入，否则越算越复杂。

## 第2章 综合模拟与应试

### 2.1 高考真题结构分析

- **试卷结构（新高考卷）**：满分 150 分，考试时间 120 分钟。题型为：单选题 8 题（每题 5 分，共 40 分）、多选题 3~4 题（每题 5~6 分，部分选对得部分分）、填空题 3~4 题（每题 5 分）、解答题 5 题（约 13~17 分/题，共 70~77 分）。
- **解答题常考板块**：三角函数与解三角形、数列、立体几何、概率统计、解析几何（圆锥曲线）、函数与导数。前 4 题相对基础，后 2 题为区分题。
- **近年命题趋势**：注重基础与主干知识考查、情境化命题（数学建模、新定义）、跨板块综合（函数与不等式、数列与导数、向量与几何）、开放性与探究性问题增加。
- **难度分布**：容易题、中档题、难题的比例约为 7:2:1（或 6:3:1），抓住中低档题是高分基础，"会做的题不丢分"比"难题多得几分"更重要。
- 研究真题的方法：横向对比近年真题找高频考点，纵向分析每道题考查的知识点与能力层级，用真题检验复习效果。

### 2.2 答题规范与卷面要求

- **解答题的书写规范**：按"解：设—列—算—答"完整呈现；必要的文字说明（如"由题意得""根据正弦定理""当且仅当……时等号成立"）不可省略；结论要明确（"综上，a 的取值范围为……"）。
- **踩点给分的策略**：解答题按步骤给分，写清楚关键步骤（求导正确、单调区间正确、韦达定理正确等）即使最终答案错误也能得大部分分；不跳步、不省略"公式—代入—结果"。
- **避免的常见失分**：求定义域不写、分类讨论不完整（漏掉 a = 0、q = 1 等情形）、答非所问（题目求取值范围却只写端点）、把"解集"写成"不等式"。
- **选择题、填空题的规范**：看清题目要求（填序号、填范围、填最简结果）；填空答案要化简完全（如 1/2 不能写成 2/4，√2/2 不能写成 1/√2）。
- 卷面管理：字迹清晰、布局合理、箭头箭头方向明确、不用铅笔答解答题、胶带涂改严重者失分；答题卡上题号区域对号入座。

### 2.3 时间分配与应试策略

- **时间分配建议**：选择填空控制在 40~50 分钟（平均每题 2~3 分钟），解答题每道 10~15 分钟，留 10~15 分钟检查。具体视个人水平微调，但"选填超时"是常见失误。
- **先易后难、遇卡即过**：按题号顺序作答，遇到卡壳超过 3 分钟的题先跳过做后面，避免"一卡到底"；回头再做时往往有新的思路。
- **选填题的策略**：排除法、特值法（代特殊值验证）、数形结合、选项代入；多选题"宁少勿错"：不确定的选项不选（部分选对得部分分，选错全扣）。
- **解答题的策略**：基础题求"快而稳"，中档题求"规范分"，压轴题"抢步骤分"（第一问必做，第二问写关键步骤）。
- **检查策略**：重点检查计算易错点（符号、开方、约分）、填涂是否错位、是否漏题；用"代入检验"快速验证选填答案。
- 考后复盘：每套模拟卷后统计失分类型（知识性失分、计算性失分、规范失分、策略失分），针对性改进，做到"错题不二错"。

### 2.4 考前状态与心理调整

- **回归基础**：考前最后阶段不再盲目刷难题，回归教材与笔记，梳理公式、定理、结论（如三角函数公式、数列公式、导数公式、概率公式），做到"公式烂熟于心"。
- **限时训练保持手感**：每天保持一套选填或半套解答题的限时训练，控制时间、保持思维活跃度，但不宜过度疲劳。
- **作息与心态**：保证睡眠、规律作息；把模拟考当高考、把高考当模拟，通过积极暗示缓解紧张；考试中"我难人难、我易人易"的心态调整。
- **考试当天策略**：提前到场、检查文具；发卷后先浏览全卷（对难度分布心中有数）；开考后按既定节奏执行，不因他人翻卷而慌乱。

### 例题

某同学在一次数学模拟考试中的答题时间安排计划如下：单选题、多选题与填空题合计计划用时 45 分钟，解答题合计计划用时 65 分钟，最后预留 10 分钟检查。实际考试中，他做选填题实际用时比计划超出 20%，解答题实际用时恰好用完计划时间。

（1）求他实际的总答题用时（不含检查时间）；（2）若考试总时长为 120 分钟，他还需要从检查时间中压缩多少分钟，才能保证在 120 分钟内完成全部作答？

解：（1）选填实际用时 = 45 × (1 + 20%) = 54 分钟，解答题实际用时 = 65 分钟。

实际总答题用时 = 54 + 65 = 119 分钟。

（2）119 + 检查时间 ≤ 120，故检查时间最多只能留 1 分钟，需要从原计划 10 分钟中压缩 10 − 1 = 9 分钟。

解析：本题是"时间分配"主题下的应用小例，考查百分比与一元一次不等式的应用。核心是建立"选填用时 + 解答用时 + 检查用时 ≤ 120"的不等式。实际考试中更常见的做法是：发现选填超时后立即调整，把后续解答题和检查时间重新规划，避免整体失控。

## 本章小结与常见错误

1. 选填题耗时失控：遇到难题死磕 10 分钟以上，导致解答题时间不足、会的题没时间做；应坚持"3 分钟原则"先跳过。
2. 多选题贪多失分：不确定的选项强行全选，选错一个全题 0 分；应"宁少勿错"，只选有把握的选项拿部分分。
3. 解答题跳步丢分：求导后直接写单调区间、联立后直接写韦达定理结论而不展示过程，失去步骤分；关键公式与代入过程必须书写。
4. 考后不总结：只对答案不分析失分原因，同类错误反复出现；应建立"失分类型统计"，针对计算、规范、策略分别改进。

## 第3章 考前冲刺与查漏补缺

### 3.1 选填题快解技巧

- **特殊值法**：对"对一切实数/正数恒成立"类问题，代入 x = 0、1、−1、e 等特殊值快速排除选项；对数列题取特殊数列（常数列、公差 1 的等差）验证。
- **数形结合**：函数零点、不等式解集、参数范围问题优先画图，利用图象的直观性（切线、交点、渐近线）快速判断。
- **选项代入与特值排除**：把选项逐个代入条件验证；或取满足条件的特殊情形排除 2~3 个选项，提高猜对概率。
- **等价转化**：把复杂条件等价变形为简单形式，如 a > b 型比较转化为研究函数单调性；抽象函数问题构造具体函数模型。
- **估算与极限思想**：对含 e、π、√2 的式子用近似值估算比较大小；考虑极端情形（x → 0⁺、x → +∞）判断图象走势。
- 快解技巧的前提是"扎实的基础知识"：技巧用于提高效率，不能替代通法；会做但求快的题才用技巧，完全不会的题"特值 + 排除"是最后手段。

### 3.2 新定义与情境应用问题

- **新定义题的特点**：给出一个教材之外的新概念（新运算、新函数、新数列），要求理解定义后按定义解决后续问题。解决的关键是"阅读理解"与"按定义转化"。
- **阅读理解策略**：逐句翻译定义（把文字语言转化为符号语言），圈出限制条件（定义域、参数范围、运算规则），从特例入手理解概念。
- **情境应用题的建模流程**：读题提取数据 → 确定变量与函数关系（建模）→ 用数学工具求解 → 回归实际问题解释结果（作答带单位）。
- **常见情境模型**：增长衰减模型（指数对数）、最优化模型（二次函数、基本不等式）、概率统计模型（抽样估计、独立性检验）、几何测量模型（解三角形）。
- 新定义题往往"新瓶装旧酒"：新概念背后是旧知识（如新定义的"对称函数"本质是奇偶性、新运算本质是指数运算），识别本质是关键。
- 应对策略：平时多做情境题培养阅读耐心，考试中遇到新定义题不慌乱，先拿"按定义直接计算"的送分小问，再攻需要转化的后问。

### 3.3 回归基础与错题管理

- **回归教材的内容**：教材中的公式定理推导（如两角和差公式、基本不等式）、例题与课后习题中的典型方法（如教材习题中的"糖水不等式"）、阅读材料中的数学文化（如祖暅原理）。
- **知识网络的查漏**：用"知识清单"逐条自查：集合、函数、三角函数、数列、不等式、向量、立体几何、解析几何、导数、概率统计、计数原理、复数，标注薄弱点。
- **错题本的使用**：分类整理（知识性错误、方法性错误、计算错误、审题错误），每道错题标注"错误原因 + 正确解法 + 同类题"，考前重点翻阅。
- **"二错题"管理**：对第一次错过的题反复重做，直到"闭卷限时能做对"为止；已经三遍做对的题可从错题本中移除，控制错题本规模。
- 高考前两周的复习重心：不追求新题难题，以"回归教材 + 错题回顾 + 公式默写 + 限时热身"为主，保持状态、增强信心。
- 公式默写清单：三角函数恒等变换公式、诱导公式、解三角形定理、等差等比公式、导数公式与法则、排列组合与概率公式、解析几何结论。

### 3.4 考前一周复习规划

- **第 1~2 天**：回归教材与笔记，通读各章"小结"，重点复习定义、定理、公式的适用条件（如基本不等式"一正二定三相等"、等比数列 q ≠ 1 讨论）。
- **第 3~4 天**：重做错题本中标记的"高频错题"与近三年高考真题的选择填空，保持运算熟练度，每天一套限时选填训练。
- **第 5~6 天**：回顾解答题的规范书写（把近期的优秀答卷重看一遍），熟悉各板块答题模板；不再挑战新压轴题，避免打击信心。
- **第 7 天（考前最后一天）**：只做轻量热身（如公式默写、两三个基础小题），整理考试用具与证件，按考试时间作息，保证睡眠。
- **考前一晚**：不熬夜、不刷题，复习一遍"易错清单"（自己常犯的错误汇总）即可；对第二天的考试流程做心理预演。
- 考前一周禁忌：忌熬夜突击、忌大量新题、忌纠结难题偏题、忌过度放松完全不做题——保持"适度紧张、正常节奏"最佳。

### 例题

（新定义题）若函数 f(x) 对定义域内任意 x₁、x₂（x₁ ≠ x₂）都满足 f((x₁ + x₂)/2) < (f(x₁) + f(x₂))/2，则称 f(x) 为"下凸函数"。已知 f(x) = x² + ax + 1 是"下凸函数"，求实数 a 的取值范围。

解：由定义，f 为"下凸函数"即对任意 x₁ ≠ x₂ 有 f((x₁ + x₂)/2) < (f(x₁) + f(x₂))/2。

代入 f(x) = x² + ax + 1：

左边 = ((x₁ + x₂)/2)² + a(x₁ + x₂)/2 + 1，右边 = (x₁² + x₂²)/2 + a(x₁ + x₂)/2 + 1。

化简比较：右边 − 左边 = (x₁² + x₂²)/2 − (x₁ + x₂)²/4 = (2x₁² + 2x₂² − x₁² − 2x₁x₂ − x₂²)/4 = (x₁ − x₂)²/4 > 0。

即不等式对任意 x₁ ≠ x₂ 恒成立，与 a 无关，故 a ∈ R。

解析：新定义题的解题套路是"先翻译定义，再代入验证"。本题中 a 的一次项在两边完全抵消，核心是二次项的凸性（x² 本身就是下凸函数）。注意"新定义"往往考查的是对定义的理解与符号运算，读懂定义即得一半分。对任意实数 a 都满足，答案不要受"求参数范围"的惯性误导写成某个区间。

## 本章小结与常见错误

1. 新定义题凭直觉乱套旧公式：不按定义逐步转化，直接套用相似旧结论导致错误；务必"用定义、按定义算"。
2. 情境题单位与范围丢失：建模后忘记自变量的实际范围（人数取整数、长度为正、时间非负），求解后不检验是否合理。
3. 错题只看不重做：翻阅错题时"一看就会"就不再动笔，考场重现仍然做错；必须"遮住答案重做一遍"。
4. 考前突击难题：考前两三天还在钻研压轴新题，既耗费精力又影响心态；此时应以回归基础、保持手感为主。
