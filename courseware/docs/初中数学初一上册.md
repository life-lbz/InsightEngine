# 初中数学初一上册课程讲义
课程编号：junior_math_g7s1　适用学段：初中　年级：初一　学期：上学期

本讲义依据人教版《义务教育教科书·数学》七年级上册编写，内容涵盖有理数、整式的加减、一元一次方程三个章节，帮助学生完成从小学算术到中学代数的过渡，建立用字母表示数、用方程解决问题的基本意识。

## 第1章 有理数

### 1.1 正数与负数

- 像 3、1.5、1/2 这样大于 0 的数叫做**正数**；像 -3、-1.5、-1/2 这样在正数前面加上符号"−"（负号）的数叫做**负数**。0 既不是正数，也不是负数。
- 正数和负数可以表示具有**相反意义的量**，如收入与支出、上升与下降、向东与向西、零上与零下等。例如：收入 50 元记作 +50 元，则支出 30 元记作 -30 元。
- "0"的含义扩展：0 不仅表示没有，还表示基准（如 0℃、海平面高度 0 米、正负数的分界）。
- 在小学学过的数（0 除外）前面添上负号，就得到相应的负数。所有正整数、零、负整数统称为**整数**；正分数、负分数统称为**分数**。整数和分数统称为**有理数**。

### 1.2 数轴、相反数与绝对值

- **数轴**：规定了原点、正方向和单位长度的直线叫做数轴。任何有理数都可以用数轴上的一个点表示，正数在原点右边，负数在原点左边，0 在原点处。
- **相反数**：只有符号不同的两个数互为相反数。如 3 与 -3，a 的相反数是 -a，0 的相反数是 0。在数轴上，互为相反数的两个点位于原点两侧，且到原点的距离相等。
- **绝对值**：数轴上表示数 a 的点与原点的距离叫做数 a 的**绝对值**，记作 |a|。正数的绝对值是它本身，负数的绝对值是它的相反数，0 的绝对值是 0，即 |a| = a（a≥0），|a| = -a（a<0）。
- 绝对值具有非负性：|a| ≥ 0。利用绝对值可以比较有理数大小：正数大于 0，0 大于负数，正数大于负数；两个负数比较大小，绝对值大的反而小。

### 1.3 有理数的加减乘除运算

- **加法法则**：同号两数相加，取相同的符号，并把绝对值相加；异号两数相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值；互为相反数的两个数相加得 0；一个数同 0 相加，仍得这个数。加法满足交换律与结合律。
- **减法法则**：减去一个数，等于加上这个数的相反数，即 a - b = a + (-b)。减法可以转化为加法，体现了转化的数学思想。
- **乘法法则**：两数相乘，同号得正，异号得负，并把绝对值相乘；任何数与 0 相乘都得 0。几个不等于 0 的数相乘，积的符号由负因数的个数决定：负因数有奇数个时积为负，有偶数个时积为正。
- **除法法则**：除以一个不等于 0 的数，等于乘以这个数的倒数，即 a ÷ b = a × (1/b)（b ≠ 0）。两数相除，同号得正，异号得负，并把绝对值相除；0 除以任何一个不等于 0 的数都得 0。注意：0 不能作除数。

### 1.4 有理数的乘方与混合运算

- **乘方**：求 n 个相同因数的积的运算叫做乘方，记作 a^n，读作 "a 的 n 次方"，其中 a 叫底数，n 叫指数。正数的任何次幂都是正数；负数的奇次幂是负数，负数的偶次幂是正数；0 的任何正整数次幂都是 0。
- 常见的幂：任何不等于 0 的数的 0 次幂都等于 1，即 a^0 = 1（a ≠ 0）。
- **运算顺序**：先乘方，再乘除，最后加减；同级运算从左到右依次进行；有括号时，先算括号里面的（按小括号、中括号、大括号的顺序）。
- 简便运算中常利用加法的交换律、结合律以及乘法的分配律，如 (-1/2 + 1/6 - 3/4) × (-12) 可用分配律展开计算。

### 例题

计算：(-2)³ + |−5| − 6 ÷ (-1/2) × 2 - (-1)^4。

解：原式 = (-8) + 5 − 6 × (-2) × 2 − 1

= -8 + 5 + 24 − 1

= 20。

解析：先算乘方 (-2)³ = -8，(-1)^4 = 1；再处理绝对值 |−5| = 5；除法 6 ÷ (-1/2) 转化为乘倒数得 6 × (-2) = -12，再乘以 2 得 -24，即 -24 前面的减号要正确处理为 -6 ÷ (-1/2) × 2 = -(-24) = +24。最后按从左到右的顺序做加减法。

## 本章小结与常见错误

1. 容易混淆相反数与倒数：3 的相反数是 -3，而 3 的倒数是 1/3；互为相反数的两个数和为 0，互为倒数的两个数积为 1。
2. 乘方符号判断失误：如 (-2)² 等于 4，而 -2² 等于 -4，两者含义不同，前者底数是 -2，后者底数是 2 前面有负号。
3. 混合运算顺序错误：常见的是先算乘除却忽略了"除以一个数等于乘以它的倒数"，或跳步直接"约分"导致符号错误。
4. 绝对值化简丢符号：当 a < 0 时，|a| = -a，如 |2 - 5| = 3，不能直接写成 2 - 5 的结果。

## 第2章 整式的加减

### 2.1 单项式与多项式

- **单项式**：由数或字母的积组成的式子叫做单项式，单独的一个数或一个字母也是单项式，如 3x、-5、ab²。单项式中的数字因数叫做这个单项式的**系数**，如 3x 的系数是 3；一个单项式中所有字母的指数的和叫做这个单项式的**次数**，如 ab² 的次数是 1 + 2 = 3。
- **多项式**：几个单项式的和叫做多项式。每个单项式叫做多项式的项，不含字母的项叫做**常数项**。多项式里次数最高项的次数，叫做这个多项式的次数。如 2x² - 3x + 1 是二次三项式。
- **整式**：单项式与多项式统称整式。判断一个式子是否为整式，关键是看它是否只含乘、乘方、加、减运算，分母中不能含有字母。
- 用字母表示数体现了从特殊到一般的思想，字母可以参与运算，如交换律、结合律、分配律对字母同样适用。

### 2.2 同类项与合并同类项

- **同类项**：所含字母相同，并且相同字母的指数也相同的项叫做同类项。几个常数项也是同类项。判断同类项只需看"两相同"（字母相同、相同字母的指数相同），与系数大小、字母排列顺序无关。
- **合并同类项**：把多项式中的同类项合并成一项，叫做合并同类项。法则：把同类项的系数相加，所得结果作为系数，字母和字母的指数不变，即"系数相加、字母部分照抄"。
- 合并同类项的依据是分配律 ab + ac = a(b + c)。例如 3x²y + 2x²y = (3 + 2)x²y = 5x²y。
- 合并时要注意：系数为负数时相加要连同符号一起相加，如 -4a + 3a = -a；系数为 1 或 -1 时通常省略"1"，如 1·x 写成 x。

### 2.3 去括号法则与整式加减

- **去括号法则**：如果括号外的因数是正数，去括号后原括号内各项的符号与原来的符号相同；如果括号外的因数是负数，去括号后原括号内各项的符号与原来的符号相反。即 a + (b + c) = a + b + c，a - (b + c) = a - b - c。
- 当括号前有数字因数时，用分配律先乘再合并，如 3(2x - 1) = 6x - 3，-2(x - y) = -2x + 2y。
- **整式加减的运算步骤**：先列式（如有括号），再去括号，然后合并同类项，最后结果按某个字母的降幂（或升幂）排列。
- 求整式的值时，一般先化简（去括号、合并同类项），再代入数值计算，这样可以简化运算、减少错误。

### 例题

先化简，再求值：3(x² - 2xy) - 2(x² - xy + 1) + 2，其中 x = -1，y = 1/2。

解：原式 = 3x² - 6xy - 2x² + 2xy - 2 + 2

= (3x² - 2x²) + (-6xy + 2xy) + (-2 + 2)

= x² - 4xy。

当 x = -1，y = 1/2 时，原式 = (-1)² - 4 × (-1) × (1/2) = 1 + 2 = 3。

解析：先去括号（注意 -2 乘括号内每项要变号），再合并同类项，最后代入求值。化简后再代入可以避免直接代入带来的繁琐计算。

## 本章小结与常见错误

1. 去括号时符号错误：如 -2(x - 3) 常被误写为 -2x - 3，正确应为 -2x + 6，负号要乘括号内每一项并变号。
2. 同类项判断出错：如认为 2x²y 与 2xy² 是同类项，实际上相同字母的指数不同，不是同类项，不能合并。
3. 合并系数时漏掉符号或"1"：如 -a + a 的结果是 0 而不是 1a；系数相加时要把符号一并考虑。
4. 化简不彻底：只合并了部分同类项就代入求值，导致计算复杂且易错；应先彻底化简再代值。

## 第3章 一元一次方程

### 3.1 方程与等式的性质

- **方程**：含有未知数的等式叫做方程。判断一个式子是不是方程，看两点：一是等式，二是含有未知数。
- **一元一次方程**：只含有一个未知数（元），未知数的次数都是 1，等号两边都是整式的方程叫做一元一次方程，一般形式为 ax + b = 0（a ≠ 0）。例如 3x + 5 = 14。
- **方程的解**：使方程左右两边相等的未知数的值叫做方程的解。只含一个未知数的方程的解，也叫它的根。解方程就是求出方程的解的过程。
- **等式的性质**：性质 1，等式两边加（或减）同一个数（或式子），结果仍相等；性质 2，等式两边乘同一个数，或除以同一个不为 0 的数，结果仍相等。这两条性质是解方程的依据。

### 3.2 移项与解一元一次方程

- **移项**：把等式一边的某项变号后移到另一边，叫做移项。依据是等式的性质 1。移项要"变号"，这是最容易出错的地方。
- 解一元一次方程的一般步骤：**去分母、去括号、移项、合并同类项、系数化为 1**。具体到每一步，依据分别是等式的性质 2、去括号法则、等式的性质 1、合并同类项、等式的性质 2。
- 去分母时，方程两边同乘各分母的最小公倍数；分子是多项式时要先加括号再乘，防止漏乘不含分母的项。
- 检验解的方法：把解代入原方程左右两边，看是否相等。

### 3.3 一元一次方程的实际应用

- 列方程解应用题的一般步骤：**审题、设未知数、找等量关系、列方程、解方程、检验并作答**。其中找等量关系是核心。
- 常见问题类型：和差倍分问题、行程问题（路程 = 速度 × 时间）、工程问题（工作量 = 工作效率 × 工作时间）、利润问题（利润 = 售价 - 进价，利润率 = 利润 ÷ 进价 × 100%）、数字问题、分配问题等。
- 设未知数时可"直接设"也可"间接设"，选择便于列方程的方式；单位要统一，结果要检验是否符合实际意义。

### 例题

一列火车匀速行驶，通过一条长 1000 m 的隧道需要 60 s，隧道的顶上有一盏灯，垂直向下发光，灯光照在火车上的时间是 15 s。求火车的长度。

解：设火车的长度为 x m。

火车通过隧道行驶的路程为 (1000 + x) m，速度 = (1000 + x)/60；

灯光照在火车上时，火车行驶的路程等于车长 x m，速度 = x/15。

火车匀速行驶，速度相等，列方程：(1000 + x)/60 = x/15。

去分母，得 1000 + x = 4x，移项得 3x = 1000，解得 x = 1000/3 ≈ 333.3。

答：火车的长度约为 333.3 m。

解析：关键是把"通过隧道"理解为车头上隧道到车尾离开隧道，路程为"隧道长 + 车长"；"灯光照在车上"的时间对应路程恰好等于车长。利用速度相等建立等量关系。

## 本章小结与常见错误

1. 移项忘记变号：如解 3x + 5 = 14 时把 5 移到右边写成 3x = 14 + 5，正确应为 3x = 14 - 5。
2. 去分母漏乘：只乘了含分母的项，没有乘整数项；或分子是多项式时去分母后未加括号，导致符号错误。
3. 系数化为 1 时除错：解 -2x = 8 时应两边同除以 -2 得 x = -4，常误写为 x = 4；去分母乘的数是公倍数而非局部。
4. 应用题不检验：求出的解不符合实际意义（如人数为负数、速度为负数）仍作答；作答前务必检验解的合理性。
